Per-task TLS base smoke test (portability program phase 03).

Proves the SetTlsBase primitive end to end:

  1. the cell is admitted as an FFI-class Tier 2 cell (kernel marker),
  2. each thread sets its own user thread pointer and reads back its own previous value (the kernel’s per-task record),
  3. on riscv64/aarch64 the register itself is read back, so the value is proven per-task rather than merely remembered,
  4. a sentinel written through the base survives forced context switches (the thread re-reads its own block after yielding repeatedly),
  5. a second thread’s base never becomes visible to the first.

Markers (integration-test contract): [tls-test] thread 0 base=0x… previous=0x0 [tls-test] thread 0 register-ok [tls-test] thread 0 sentinel-ok rounds=… TLS-TEST: PASS
