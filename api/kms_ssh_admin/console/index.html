Module console 

Source
Expand description

The terminal side of the cell: a small Console trait over the foreground session, and the two readers that sit on a typed/pasted event stream.

The key block reader is its own reader (the ssh passphrase reader refuses paste): it accepts typed text and bracketed or unbracketed paste, Backspace, Enter, and ends at the END marker line. Escape (or Ctrl-C, end of input) cancels. If a paste is still running when the reader stops, the rest of the paste is consumed and dropped: left in the input queue it would reach the shell as typed commands.
