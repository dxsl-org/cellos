kms_ssh_admin

Expand description

Exit codes, the fixed output text and the KMS error mapping (k7-cp1-draft §3.3).

Every message here is a literal or is built from nonsecret facts only: the key name the operator typed on the command line, KMS status fields (custody, fingerprint of the public key, posture) and the length and a SHA-256 prefix of the blob the cell itself decoded. No key text byte and no blob byte is ever formatted.
