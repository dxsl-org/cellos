Crate kms_ssh_admin

Expand description

/bin/kms-ssh-admin (KSSH K7): the admin surface for the single KMS-custodied SSH identity. Dedicated cell, launched only by the shell’s reviewed path edge, holding the kernel-attested CALLER_FLAG_KMS_SSH_ADMIN and never the sign right.

kms-ssh-admin status [NAME]   leaf status, or one key's facts           (op 19)
kms-ssh-admin import NAME     armored key on the echo-off lease         (ops 15, 16*, 17; 18)
kms-ssh-admin delete NAME     typed confirmation, then                  (ops 19, 20)

Exit codes: 0 ok, 1 refused by the key service (or unreachable), 2 usage or key text that is not one armored OpenSSH private key, 124 key service timeout, 125 no terminal or session lost, 130 cancelled. DEV_POSTURE: anyone at the foreground session is the admin.

console 🔒
The terminal side of the cell: a small Console trait over the foreground session, and the two readers that sit on a typed/pasted event stream.
delete 🔒
kms-ssh-admin delete NAME: status first (op 19) for the stored public key, print what is about to go, require the operator to type delete + Enter (Escape or any other word cancels), then op 20 with the public key and the name. Without the confirmation no op 20 is ever sent.
import 🔒
kms-ssh-admin import NAME: read the armored key on the echo-off lease, decode it strictly, and drive Begin / Chunk x n / Commit (ops 15-17, Abort 18 on failure).
kms 🔒
The key-service calls the admin cell makes: exactly opcodes 15-20. The trait is the seam between the commands and the K6 KmsClient; host tests implement it with a scripted fake and with a bridge to the real service state machine.
report 🔒
Exit codes, the fixed output text and the KMS error mapping (k7-cp1-draft §3.3).
secret 🔒
Fixed-capacity byte buffer for key material: allocated once, never reallocated, wiped (volatile, whole allocation) on drop. Growing a Vec would leave an unwiped copy of the key text behind, so the capacity is fixed at construction and push_slice refuses to exceed it.
status 🔒
kms-ssh-admin status [NAME]: leaf status (no name) or one key’s facts (op 19).
