Module ring_channel 

Source
Expand description

Zero-trap fastpath SPSC ring channel for SAS inter-cell communication. User-space abstractions for zero-trap fastpath SPSC Ring Channels.

Provides non-blocking, spinning, and yielding send/recv primitives for inter-cell communication within the Cellos SAS.
