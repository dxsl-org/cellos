Module frontend 

Expand description

SessionV1 frontend attachment records (selectors 23–28). A frontend is an input-owned, holder-bound capability: the holder (for example the GUI Terminal) registers it, binds it to the shell child it launches, and the shell creates its own controller session for it. References are selectors, never capabilities; the input service authenticates every use by the attested caller principal.

Every record here is a request or result body (the 24-byte header is separate). Decoders require the exact length; reserved fields must be zero.
