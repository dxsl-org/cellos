Module block_route 

Expand description

Per-device block routes (RegisterBlockDriver = 416, LookupBlockRoute = 432).

Each storage device the kernel has seen a block Driver Cell register for has one route slot, bound to that device for the boot. Only the Cell that owns the device (its PCI BDF lease or its exact MMIO window) may (re)publish the slot’s provider, so a restarted driver regains its own route and never another device’s.

ViBlockRouteV1 is a class K record (docs/abi-boundary-records.md): syscall 432 plus exact length, version exactly 1, kind in {1, 2}, flag bits outside FLAGS_KNOWN refused, provider fields zero unless FLAG_PROVIDER_LIVE, little-endian in declared field order. Producer: kernel. Consumers: VFS, init.
