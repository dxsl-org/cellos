QUARANTINE_OVERFLOW
The bounded pin quarantine overflowed and pages were leaked. Forces Unproven.
SHM_UNTRACKED
The incarnation owned SHM frames: USER mappings in the shared root with no borrower record. Forces Unproven.
TRACKED_QUARANTINE
Pins, VFS leases or quarantined pages remain bounded. Gives Quarantined.
WRITABLE_BORROW
The incarnation died holding writable grantee references to a live peer’s grant. Reported only, never classified: the grant owner must treat that memory’s invariants as unproven and never unlock or reuse a lock inside it.
