Module service_flags

Expand description

RegisterService flags (a2): kernel rights a registry row grants the Cell incarnation it names. Only the namespace owner (trusted init or a SupervisorCap holder) may set them; a set bit outside ALL is refused. A hot-swap commit carries the row’s flags to the replacement.

Constants§

ALL
Every defined flag.
OWNER_WATCH
The provider may watch the root death of the principal it is serving (WatchCellOwner/WatchCellOwnerRecord). Only while the row is Active: a hot-swap quiesce grants no new watch.
RETAINS_OUTER_CALLER
The provider keeps its outer caller (grant leases, owner resolution, owner-death watches) across the nested IPC it makes while serving; only its next wildcard receive or its reply ends that context. Holds while the row is Active or Paused, so requests already in flight finish.
