Expand description

Embed a syscall allowlist into the current Cell’s ELF binary.

Places a u64 bitset into the __ViCell_syscalls ELF section. The kernel reads it at spawn time and enforces it on every syscall — any call whose bit is not set is rejected with PermissionDenied before the handler runs.

Cells that do not call this macro default to permit-all (backwards compatible). Cells that call it are restricted to exactly the listed syscalls plus always-permitted ones (Yield, Exit, ForceExit, …).
