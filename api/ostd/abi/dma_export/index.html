Module dma_export 

Expand description

Client-memory DMA export and mapping records (ExportDmaRange = 437, MapDmaExport = 438, RevokeDmaExport = 439); ADR-0033, CP1 §5.

ViDmaExportV1 is a class K record (docs/abi-boundary-records.md): syscall 438 with an exact out length of DMA_EXPORT_RECORD_LEN (48 bytes), version exactly 1, little-endian in declared field order, every reserved byte and unknown flag bit zero. Producer: the kernel. Consumer: the Driver Cell that holds the lease and owns the BDF.

Every refusal of 437-439 returns one of the ERR_* sentinels below; a successful 437 returns an export id in 1..=isize::MAX, which never collides with them.

DMA_EXPORT_RECORD_LEN
Exact out_len syscall 438 accepts and bytes it writes.
DMA_EXPORT_VERSION
The only record version 438 writes and a v1 consumer accepts.
ERR_BUFFER_TOO_SMALL
Reserved for the record family; 438 refuses a short buffer as invalid input.
ERR_FILE_NOT_FOUND
No live provider (437), or an unknown, revoked or owner-dead export (438), or a caller that is neither owner nor holder (439, no existence oracle).
ERR_INVALID_INPUT
Malformed arguments: alignment, length, flags, service or BDF bits, out_len != 48, non-zero reserved registers.
ERR_NOT_SUPPORTED
No translating remapper for the export or the BDF: exports never fall back to identity DMA.
ERR_OUT_OF_MEMORY
Lease table, IOVA window space, page tables or the holder’s DMA quota.
ERR_PERMISSION_DENIED
Holder not eligible, range not owned, caller not the lease holder, or 438 without allowlist bit 48 / PcieDriverCap / BDF ownership.
ERR_TRY_AGAIN
439: the window invalidation was not acknowledged; the lease stays Revoking with the owner range locked and the kernel retries.
ERR_UNKNOWN
438: the window was published but its invalidation was not acknowledged; only revoke or death cleans it.
EXPORT_DEVICE_WRITE
flags bit: device is granted write access to the exported memory. If clear, the export is device-read-only (R-only VT-d leaves).
EXPORT_FLAGS_KNOWN
All known flag bits in version 1.
EXPORT_MAX_BYTES
Maximum bytes a single export may cover: 4 GiB (2^32).
