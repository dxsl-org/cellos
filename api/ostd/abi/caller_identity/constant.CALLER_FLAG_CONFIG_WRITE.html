Expand description

The calling Cell may write the shell key namespace of service-config (ConfigRequest::Set / Delete; Phase 01 Q right, CP1 2026-10-25).

Mirrors the kernel-only CapSet::config_write of the sender’s Cell, requested by install path (/bin/cellbox only) and bounded by the reviewed launch/boot ceiling. service-config answers a write without it, or a write to a key outside the shell namespace, with ConfigResponse::Err(CONFIG_ERR_DENIED) before any mutation.
