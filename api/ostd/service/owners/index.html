ostd::service

Module owners 

Source
Expand description

Owner-death watches for services that keep state on behalf of their callers.

A service subscribes to the root death of each caller Cell incarnation (WatchCellOwner) while serving that caller’s message, the only moment the kernel grants it. The death later arrives as a message without an identity trailer whose sender is the dead Cell’s root tid; OwnerWatches::take_death maps it back to the (cell_id, generation) the service keys its state by. CellIds are reused, so a new generation of a watched CellId also retires the old one: its death record may never have arrived.

Syscall-free behind WatchSys, so host tests drive it with a scripted kernel.
