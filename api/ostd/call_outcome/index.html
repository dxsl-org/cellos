Typed outcome of one request/reply exchange: reply, refused, or uncertain. What one request/reply exchange did, as far as the caller can know (Phase 11 CP1 §3).

An exchange ends in exactly one of three ways:

  • a reply arrived;
  • the request was refused, and the provider never executed it;
  • the result is uncertain, and the request may have run.

Callers that only need an error code collapse the outcome with [CallOutcome::into_result]. Callers that retry, reconcile or report must match on it.
