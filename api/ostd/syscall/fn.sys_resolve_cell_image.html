pub fn sys_resolve_cell_image(

Expand description

The kernel-measured image identity of the exact live (cell_id, generation). Answered for the registered VFS Cell, and for a SupervisorCap holder when the subject was launched from a kernel-resolved /bin install; None for every other caller, for a stale generation, and for a malformed record.
