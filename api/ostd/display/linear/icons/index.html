ostd::display::linear

Module icons 

Source
Expand description

CellOS Linear icon set: a 16x16 grid drawn only with 1px strokes on whole pixels — no fills, no anti-aliasing — so every icon stays sharp at any position and keeps the weight of the window chrome. Circles use even diameters: an odd one degenerates into an octagon at this size.

Lives in ostd so the compositor draws the same app icons on Cell Tabs that ViUI apps draw in their own UI.
