Module linear 

Source
Expand description

Linear-style raster primitives shared by the compositor and ViUI.

Contract: every stroke is exactly one device pixel wide and every edge lands on the pixel grid (no anti-aliasing), so window chrome, boxes and icons stay sharp at any position, scale step and background. A rounded shape derives its fill and its outline from the same per-row inset function, so the outline is exactly the 4-connected boundary of the fill.

Buffers are 32-bit BGRA rows with a byte stride. Opaque colors are copied; translucent colors blend with the destination, as does the drop shadow (Shadow).

Modules§

icons
CellOS Linear icon set: a 16x16 grid drawn only with 1px strokes on whole pixels — no fills, no anti-aliasing — so every icon stays sharp at any position and keeps the weight of the window chrome. Circles use even diameters: an odd one degenerates into an octagon at this size.

PANEL_RADIUS
Corner radius of window frames, panels, cards and popovers (CellOS Linear). The compositor rounds floating Panel surfaces with this radius, so a shell that outlines its panel with the same radius gets an unbroken border.
