Expand description

Queue one request with blocking Send, then bound only the reply wait.

This transport is for permanent services that may temporarily receive from a nested dependency and therefore cannot admit TrySend. A gone target fails the send; a service that accepts but does not reply before timeout_ticks returns IpcError::Recv. After that receive error, callers must poison the service generation because an uncorrelated late reply can still arrive.
