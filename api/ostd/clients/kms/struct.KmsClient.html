pub fn ssh_key_status( &self, name: &[u8], ) -> Result<SshKeyStatusPayload, KmsClientError>

Public facts of the stored identity (opcode 19). An empty name is the leaf query, which succeeds with key_present == 0 when nothing is stored; a named query that does not name the stored key is a service error, so a named reply without a key is a protocol violation here.

pub fn ssh_sign_userauth( &self, public_key: &[u8; 32], session_id: &[u8; 32], username: &[u8], ) -> Result<SshSignResponsePayload, KmsClientError>

Ask KMS to sign the userauth challenge for username over session_id with the stored identity named by public_key (opcode 21). KMS reconstructs the RFC 4252 section 7 input itself; the reply echoes the payload id.

Source

pub fn ssh_stage_secret( &self, public_key: &[u8; 32], secret: &[u8], ) -> Result<(), KmsClientError>

Stage secret (the passphrase of the wrapped identity, 1..=1,024 bytes) for the next Self::ssh_sign_userauth: Begin, then ceil(len / 96) ordered chunks. Every reply is verified (handle, index, cumulative length). On any failure the slot is aborted (best effort) and the error returned. The caller owns secret and wipes it.

Admin only (K7): import blob (a binary OpenSSH private key, at most 64 KiB) as name: Begin, canonical chunks, Commit, with every reply verified. Aborts the import (best effort) on any failure before the commit.
