Module vmm

Expand description

VMM syscall wrappers (220-227) for HypervisorCap cells. VMM syscall wrappers (220-227) for cells holding HypervisorCap.

One safe function per kernel VMM call, shared by the silo and hypervisor services and the hypervisor ABI smoke test. Every function returns the raw kernel result register: an id, a byte count or 0 on success, and a value the caller compares against its documented error sentinels (0 and/or usize::MAX) on failure. The kernel gates every call on HypervisorCap and returns an error to a cell without it.

Guest-memory invariant behind every call: guest RAM is a run of frames the kernel carves from its own frame allocator at CreateVm (Stage2Table::carve_guest_ram), and stage 2 maps only that carve. No byte of the calling cell’s memory is guest-visible, and the cell never holds a pointer into guest RAM — it moves bytes only through kernel copies that bounds-check the cell side (validate_user_buf + the caller copy view) and the guest side (check_guest_range). The only cell memory the kernel writes is the out-parameter of the call in progress, which the wrapper borrows exclusively.
