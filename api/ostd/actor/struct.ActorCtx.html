pub fn now_ticks(&self) -> u64

Monotonic scheduler ticks (10 ms slices) — the same clock the kernel uses for RecvTimeout deadlines.

This is GetTime op 4, not op 0: op 0 returns the raw architected counter (10 MHz mtime on QEMU RV64), whose units are not ticks, and a budget or window compared against it silently never engages.

The cell must declare GetTime; 0 means the clock was unavailable, and callers must treat that as “no time has passed” rather than as a stall.

pub fn call<Req, Resp>(&mut self, to: usize, req: &Req) -> ViResult<Resp>
where Req: Serialize, Resp: DeserializeOwned,

Typed request/reply exchange with to.

The receive is masked to to (Spec 17 §2) and expects the peer’s reply in the same envelope, so a queued input event or a child exit can never be mistaken for the answer.

pub fn spawn(&mut self, path: &str) -> ViResult<usize>

Spawn a cell from a path. Returns its tid.

Requires SpawnCap; the kernel authorizes the exact (caller, route, path) edge (SpawnFromPath, op 12).

Source

pub fn watch(&mut self, tid: usize) -> ViResult<()>

Ask the kernel to deliver this child’s exit reason to our mailbox.

One-shot and SpawnCap-gated: after a delivery the supervisor must arm it again for the respawned child (NotifyOnExit, op 204).

Source

pub fn force_exit(&mut self, tid: usize) -> ViResult<()>

Terminate tid with the fault sentinel reason (ForceExit, op 61).

Requires SpawnCap; self-kill and critical driver cells are refused.
