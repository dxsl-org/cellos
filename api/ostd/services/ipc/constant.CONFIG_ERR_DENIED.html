Expand description

ConfigResponse::Err code: permission denied.

service-config returns it for a Set/Delete whose caller is unattested, lacks CALLER_FLAG_CONFIG_WRITE, or names a key outside the shell namespace. The store is untouched. Clients report it as “permission denied”, never as “config unavailable”. Same value as NET_ERR_DENIED.
