Module machine_pin 

Expand description

Machine pin frame: cellbox ↔ init over service::MACHINE_PIN (ADR-0029 §3).

Class C record (docs/abi-boundary-records.md). Fixed little-endian frames, identified by magic, version exactly FRAME_VERSION; unknown operations, kinds, states and codes, non-zero reserved bytes and non-zero bytes past the frame are refused before any effect. A request fits init’s 64-byte receive payload; caller identity never comes from the frame but from the kernel’s attested receive trailer.

Request (REQUEST_BYTES): 0 magic MACHPINQ · 8 version · 9 op (1 Status, 2 Confirm) · 10 reserved [6] · 16 digest [32] (zero for Status). Response (RESPONSE_BYTES): 0 magic MACHPINR · 8 version · 9 kind (1 Status, 2 Recorded, 3 Refused) · 10 code (PinState for Status, Refusal for Refused, zero for Recorded) · 11 reserved [5] · 16 digest [32] (Status: current; Recorded: the new pin; Refused: zero) · 48 digest [32] (Status: pinned, zero when none; otherwise zero).
