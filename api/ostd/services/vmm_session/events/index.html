ostd::services::vmm_session

Module events 

Expand description

Launcher -> hypervisor resize request and hypervisor -> launcher events.

Events are posted (never sent): a launcher that stops receiving must not park the hypervisor’s vCPU loop. Every frame starts with its opcode byte.
