Opcodes for messages from cells to the compositor cell.

Constants§

ATTACH_GRANT
Attach an app-owned Grant buffer to a surface slot.
CLOSE_RESPONSE
Accept or reject the matching [WindowCloseRequest] serial.
COMMIT_GROUP_CONFIGURE
Commit staged group configuration after all member ACKs.
CONFIGURE_ACK
Acknowledge the matching [WindowConfigure] serial.
CREATE_SURFACE
Request a new surface of (w: u32, h: u32) pixels and a SurfaceRole. Payload: [w: u32 LE, h: u32 LE, role: u8]; the legacy nine-byte form defaults to SurfaceRole::Interactive; reply: cap (u32 LE, zero-padded to 8 bytes).
CREATE_VIEW
Create a new session view inside a frame (or new frame if frame_id == 0). Payload: [CreateViewRequest] (64 bytes). Reply: [ViewOpResponse] (20 bytes).
DAMAGE_NOTIFY
Notify the compositor that a region of a Grant-backed surface is dirty.
DAMAGE_SURFACE
Mark a rect of a legacy (Owned) surface as damaged. Payload: [cap: u64, Rect: 16 bytes]
DESTROY_SURFACE
Destroy a surface and release its capability. Payload: [cap: u64] Reply: [0x00]
DESTROY_VIEW
Destroy a session view and release its surface. Payload: [frame_id: u32, frame_generation: u32, view_id: u32, view_incarnation: u32] (16 bytes).
DETACH_GRANT
Detach the Grant from a surface slot before the app frees the Grant.
DETACH_REPLACED_GRANT
Acknowledge that the retired Grant named by [DetachReplacedGrant] can be released without detaching the newly active Grant.
DETACH_VIEW
Detach a session view into a new floating frame at (x, y).
DUMP_FB
Dump raw framebuffer (debug only). Reply: pixel data of whole screen
GET_SCREEN_SIZE
Query screen dimensions. Payload: empty Reply: [w: u32, h: u32]
GROUP_VIEW
Move a session view into a target frame.
MAXIMIZE
Request that an owner surface be maximized.
MINIMIZE
Request that an owner surface be minimized.
MOVE_SURFACE
Move a surface to a new screen position. Payload: [cap: u64, x: i32, y: i32]
RAISE_SURFACE
Raise a surface to the top of the z-order. Payload: [cap: u64]
RESTORE
Request that an owner surface be restored from a managed state.
SELECT_VIEW
Select/activate a tab view within a frame. Payload: [frame_id: u32, frame_generation: u32, view_id: u32, view_incarnation: u32] (16 bytes).
SET_TITLE
Replace the UTF-8 title of an owner surface.
SNAP_FRAME
Snap a window frame into one of the 6 screen zones. Payload: [frame_id: u32, frame_generation: u32, zone: u8, _pad: [u8; 3]] (12 bytes).
STAGE_GROUP_CONFIGURE
Stage an atomic group resize across all member views of a frame.
TOGGLE_FULLSCREEN
Toggle content-only fullscreen mode for a frame. Payload: [frame_id: u32, frame_generation: u32, enable: u8, _pad: [u8; 3]] (12 bytes).
WRITE_PIXELSDeprecated
Write pixels into a surface (DEPRECATED — use ATTACH_GRANT + DAMAGE_NOTIFY).
