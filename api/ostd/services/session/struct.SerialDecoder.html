Struct SerialDecoder 

Source 
pub struct SerialDecoder { /* private fields */ }
Expand description

Incremental bounded serial/SSH grammar. Returns complete normalized frames (sequence/epoch zero). Paste markers are framing: the owner must stage and validate the entire paste before delivery. All timestamps are nanoseconds.
