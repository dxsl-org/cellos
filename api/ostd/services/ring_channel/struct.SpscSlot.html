Expand description

A single message slot within the SPSC ring buffer.

Fields§

§state: Atomic<u32>

Slot status: 0 = EMPTY, 1 = WRITING, 2 = READY

§len: Atomic<u32>

Number of valid data bytes in this slot.

§seq: Atomic<u32>

Message sequence number.

§flags: Atomic<u32>

Application flags.

§data: [Atomic<u64>; 8]

Atomic 64-bit payload words.
