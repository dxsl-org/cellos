Module ssh_completion 

Expand description

cellbox.ssh.completion v1 (command-contracts §4.3): the cellbox ssh lifecycle record, carried from the ssh Cell to the shell over the foreground child’s write-only completion endpoint (child-context slot 5).

The child writes one fixed FRAME_LEN-byte frame at every phase or dispatch change (write-ahead: may_have_run before the request frame exists) and a final one; the newest whole frame wins (last_frame). Nonsecret lifecycle metadata only: no credential, key byte or command text.

Frame: version:u8=1, mode:u8, phase:u8, dispatch:u8, outcome:u8, flags:u8 (bit 0 stdout_complete, bit 1 stderr_complete, bit 2 remote_status present), signal_len:u8, error_len:u8, remote_status:u32 LE, signal:[u8;32], error:[u8;32], reserved:[u8;4]=0. A text field of length 0 is null; text is graphic ASCII.
