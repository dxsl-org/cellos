Hot-migration helpers — stash / restore / clear wrappers and the ViStateTransfer opt-in trait for cells that serialize state across a live hot-swap. Hot-migration state helpers for Cells.

Provides safe wrappers over the kernel’s state-stash primitives (syscalls 410/411/412) and the [ViStateTransfer] opt-in trait for cells whose state survives a supervisor-orchestrated hot-swap.

§Sequence contract

  1. Old cell — receives the supervisor’s Snapshot envelope (AppEvent::Snapshot, or Handler::on_snapshot under serve) → stashes its bytes under [hotswap_key](swap_id).
  2. Kernel — keeps the bytes, readable only by the replacement.
  3. New cell — receives the Restore envelope → restore(key), applies the bytes, clear(key), then sys_hotswap_ready.

stash and restore are independent of each other’s call site — the kernel is the rendezvous point. Multiple calls to stash under the same key overwrite the previous value; restore leaves the entry in place for retry.
