driver_vmxnet3

Module rings 

Source
Expand description

DMA layout, generation-bit rings and descriptor encoding (pure; host-tested).

Every vmxnet3 ring is owned by whichever side’s generation bit a slot carries: a producer writes a slot with its current generation and flips the generation each time its index wraps, and a consumer accepts a slot only while the slot’s bit equals its own generation. Both sides start at 1, so a zeroed ring is empty for the device’s command rings and free for its completion rings. Descriptor bit positions follow FreeBSD’s if_vmxreg.h (vmxnet3_txdesc, vmxnet3_rxdesc, vmxnet3_txcompdesc, vmxnet3_rxcompdesc; ISC, see NOTICE).
