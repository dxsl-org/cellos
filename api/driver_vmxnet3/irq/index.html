Module irq 

Source
Expand description

MSI-X wake-ups for bounded bring-up, link and TX-completion waits (H-S3-4 b).

An interrupt is only a hint to re-read the device: every park is bounded by PARK_TICKS, every return re-reads the condition, and every wait has its own park budget, so a lost or revoked interrupt degrades to slow polling, never to a hang. RX is not interrupt-driven: the net service asks for frames (OP_RX), so the RX vector stays masked (rx=request-driven).

Vectors (shared::IntrPlan): TX queue 0 → 0, RX queue 0 → 1 (masked), events (link change, queue errors) → 2. DriverShared.automask is 0, so the device sends a message for every cause while its vector is unmasked and the cell never has to re-arm a vector.
