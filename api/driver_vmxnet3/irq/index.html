Module irq 

Source
Expand description

MSI-X vector routing for the bounded bring-up, link and TX-completion waits (H-S3-4 b); the waits themselves are nic_driver::irq::BoundedWait.

RX is not interrupt-driven: the net service asks for frames (OP_RX), so the RX vector stays masked (rx=request-driven).

Vectors (IntrPlan): TX queue 0 → 0, RX queue 0 → 1 (masked), events (link change, queue errors) → 2. DriverShared.automask is 0, so the device sends a message for every cause while its vector is unmasked and the cell never has to re-arm a vector.
