impl NicIrq

Source

pub(crate) fn setup(bdf: u32) -> Self

Ask 435 for WANT_VECTORS MSI-X entries of the owned function bdf. MSI is not accepted: per-queue vectors need MSI-X.

Source

pub(crate) fn vectors(&self) -> Option<u8>

MSI-X entries held (None when polled).

Source

pub(crate) fn wait_for( &mut self, parks: u32, polls: u32, ready: impl FnMut() -> ViResult<bool>, ) -> ViResult<bool>

Wait (bounded) until ready holds: a short spin, then up to parks interrupt parks with MSI-X, or polls spins when polled. The device is re-read after every return. Ok(false) means the budget ran out.

Source

fn park(&mut self) -> bool

Park on this task’s MSI-X lines for at most PARK_TICKS. false means the wait was refused and the cell is now polled.
