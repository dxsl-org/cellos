driver_vmxnet3

Module regs 

Source
Expand description

vmxnet3 register map and the command handshake.

Offsets and command codes follow FreeBSD’s sys/dev/vmware/vmxnet3/ if_vmxreg.h (ISC licence, attribution in NOTICE; H-S3-14). The device has two register BARs:

  • BAR0 “PT” — per-vector interrupt masks and the TX/RX producer doorbells;
  • BAR1 “VD” — revision selection, the driver-shared address, the command register, the MAC registers and the event-acknowledge register.

A command is a 32-bit write of its code to VD_CMD; a query command’s result is the following read of VD_CMD.

RegisterFile is the only path to the device: MmioRegion implements it for the cell, and the host tests implement it with a fake.
