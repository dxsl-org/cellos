pub(crate) fn handle<'o>(
    store: &mut ConfigStore,
    request: Option<ConfigRequest<'_>>,
    caller: Option<&CallerIdentity>,
    out: &'o mut [u8],
) -> Option<&'o [u8]>
Expand description

Answer one request into out and return the encoded reply.

request is None when the payload did not decode. caller is the kernel-attested identity (None = unknown). Admission (rights::admit) runs before the store is read or written, so a refused Set/Delete leaves the store untouched.
