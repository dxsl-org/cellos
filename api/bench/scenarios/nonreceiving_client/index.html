Expand description

Non-receiving client witness (architecture remediation Phase 11, CP1 §4.1).

A client sends a request by raw Send to the supervisor, config or compositor and then never receives. The service’s reply must not park it: a second client’s bounded call is answered within SECOND_CALL_TICKS. Before services replied without parking, the service sat in Sending until the first client exited, and the second call timed out.
