Module native_stateful 

Source
Expand description

Native stateful workload: 1,000 deterministic increments of the supervised hotswap-demo service, a checkpoint every 100 operations in /srv/checkpoint.log, a v1 -> v2 hotswap at operation 300 with a cached-TID increment as operation 301, a VFS restart at operation 600, and a failed hotswap that must leave the live provider intact.

The shell drives it in steps, because only the shell-launched hotswap CLI may ask the supervisor for a swap, and a shell-launched bench reaches /srv only through its cwd handle (run it from cd /srv): bench native-stateful prime ops 1-300, checkpoints 1-3, cached sender armed hotswap hotswap-demo /bin/hotswap-demo-v2 bench native-stateful restart op 301 reconciled, ops 302-600, checkpoints 4-6, then VFS killed through the supervisor (init restarts it; this launch ends with it) bench native-stateful finish checkpoints 1-6 survived the restart, ops 601-1000, checkpoints 7-10 hotswap hotswap-demo /bin/hotswap-demo-nonexistent (must fail) bench native-stateful live v2 still serves counter 1000
