Module native_stateful_log 

Source
Expand description

The native-stateful checkpoint log, checkpoint.log in the bench’s working directory (the lane runs it from /srv).

A shell-launched Cell is path-sealed by VFS: it reaches files only through the cwd handle its launch context grants. VFS has no append through a handle, so each checkpoint rewrites the whole log; the log’s content is the record list either way.
