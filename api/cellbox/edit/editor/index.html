cellbox::edit

Module editor 

Source
Expand description

edit key handling, prompts and conditional saves, with no terminal or VFS access of its own: storage is a Store, screen size comes from the caller.

Save semantics (command-contracts §3.3): a save publishes the exact buffer bytes only if the destination still matches the observation it is bound to (taken when the file was opened, or when Save As asked about overwriting). A confirmation is never re-bound to a fresh observation and a failed save is never retried. Anything short of a committed publication leaves the buffer, its history and its dirty state exactly as they were.
