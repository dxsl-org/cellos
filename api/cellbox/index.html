run_frontend_shell 🔒
A context carrying an input frontend (a GUI Terminal or another FrontendHost launched this shell with sh) makes the shell create and control its own session for that frontend and run the serial controller path, relaying output to the holder’s writers: it never calls create_serial, never touches the physical UART and never reads legacy fd 0. A context that cannot be bound is refused, not downgraded to the serial path.
