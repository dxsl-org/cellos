pub fn oneshot_stdout(bytes: &[u8]) -> Result<(), Status>
Expand description

Write bytes to the one-shot stdout with a finite deadline. After the first failure (closed, revoked, deadline) nothing more is written: a committed prefix is never replayed. Returns that failure. Not installed: Err(WrongSession).
