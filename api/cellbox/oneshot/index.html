/bin/cellbox <command>: one catalog command without an interactive shell (Phase 10 S10-0, CP1 2026-10-26, DS0-1..DS0-6).

The launch context’s argv (which never carries the program path) selects the entry once, in main, through classify:

  • ssh … is the ssh client child (checked first, unchanged);
  • a context with a terminal frontend runs cellbox sh for []/["sh"] and refuses every other argv (2);
  • without a frontend, sh still needs a terminal (125), an empty or option-like argv is a usage error (2, -h/--help print the usage with 0), a name in the closed TABLE runs or is refused by its class (2), and anything else, including an absolute path or a retained worker name, is an unknown command (127).

The table covers every executor::BUILTINS name plus [, . and the six typed stage words exactly once. Only Class::Run names execute, through the executor’s closed dispatch_catalog: a one-shot never launches a child (no spawn_external, no exec, no hv, no ssh launch), so its authority is a strict subset of cellbox sh, whose ELF, path and launch edges it shares.

argv is used verbatim: no parsing, expansion, globbing, redirection or |. Output goes to the context’s Stdout/Stderr grants, captured before anything is written; a context without both writes nothing anywhere and exits 1. Stdin is read only by the stdin-consuming rows, on the command’s own first demand (so only when it got no file operand), to EOF and bounded by typed::MAX_SINK_BYTES.

Inside cellbox sh, a simple command whose first word is cellbox or /bin/cellbox goes through the same table in process (prefixed): a Run name (and ssh, the shell’s own builtin) drops the prefix; every other answer is the one-shot’s refusal.
