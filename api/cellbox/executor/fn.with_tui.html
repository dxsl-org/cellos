pub fn with_tui<R>(
    run: impl FnOnce(&mut TerminalSession, TuiSink<'_>) -> R,
) -> Result<R, Status>
Expand description

Run an in-process TUI on this shell’s session: take the session guard once, relay everything still queued in the rings, then hand run the session and a TuiSink. Afterwards, when the device may still be in a TUI screen mode (a restore was lost, or any write failed), one SOFT_RESET follows. Nothing inside run may write through the shell’s terminal sinks (shell_*, terminal_*): the guard is not reentrant, so diagnostics are written after this returns.
