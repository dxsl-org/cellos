Struct OwnerPrompt

struct OwnerPrompt {
    drawn: bool,
    failed: bool,

Expand description

Input-owner notices while a foreground child runs. The input owner captures the answer itself and routes TrustPrompt/TrustPromptEnd to this controller’s own control ring, never the child’s. Each notice is acknowledged only after it is drawn: input arms its capture on the prompt’s acknowledgement and keeps the session’s input from the child until the end’s acknowledgement. While the prompt is drawn or an acknowledgement is being retried, the child’s output is not relayed (it waits in its rings). The prompt ends on TrustPromptEnd or on foreground restoration (the kernel flushes the controller’s ring there).

The handshake failed and the foreground child must be cancelled: retried each turn with this backoff until the cancellation is in or the foreground is restored.

fn poll(&mut self, session: &mut TerminalSession)

Draw and acknowledge the pending notices. When the handshake cannot complete (a notice unreadable, undrawable or never acknowledged), input still holds this child’s input, so a cancellation of the foreground child becomes pending (cancel_turn): its restoration ends the quarantine and the confirmation.

Source

fn give_up(&mut self, status: Status)

Stop prompting for this child and make its cancellation pending. A prompt that is (even partly) on screen is ended with \r\n before any child output is relayed again.
