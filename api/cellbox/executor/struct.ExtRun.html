Expand description

One run of consecutive external stages inside one pipeline Operation.

Neighbouring stages share a kernel stream (4096-byte ring) the shell never touches; the shell holds only the ends that cross the segment boundary: the writer feeding stage 0 (input), the reader of the last stage’s stdout (output) and the reader of one stderr ring all children share (errors). The Operations are laid out by Pipeline (see libs/terminal/src/pipe_child.rs): a stage that exits early makes the kernel stop only the stages upstream of it, never a stage downstream or the shell’s own endpoints. Every endpoint and child is released on every exit path (Drop cancels and reaps), and conclude is the orderly way to do it.

fn start( commands: &[StageIn], with_input: bool, latch: &Rc<InterruptLatch>, ) -> Result<ExtRun, StartFailure>

Start commands (at least one). Stages are committed last to first, so an unknown program is discovered before any upstream producer has run. with_input gives stage 0 a shell-fed stdin; without it stage 0 reads end of file. On failure everything started is cancelled and reaped, one diagnostic is printed and the failing stage with its status (127 not found, 126 otherwise) is returned. A Cancelled spawn of a stage that has a consumer in the segment is not a failure: the consumer already exited and the kernel closed the pipeline, so that stage and the ones before it are left unstarted (not_started, status 141).

fn feed_step(&mut self) -> Result<bool, StreamStop>

Move pending feed bytes into stage 0’s stdin (serializing more rows when the buffer is empty); close the stream when everything was delivered so stage 0 sees end of file. A stage that stopped reading (BrokenPipe, or its Operation cancelled/retired by the kernel) ends the feed and stops the row producer: its status and the kernel’s pipeline teardown tell the story.

Source

fn forward_terminal( &mut self, bytes: &[u8], diagnostic: bool, ) -> Result<(), StreamStop>

Forward one child chunk without hiding Ctrl-C behind a full host ring. The retry loop keeps the exact unsent suffix; cancellation abandons only that suffix and lets the normal conclude/reap path stop this pipeline. Every chunk handed to the terminal is followed by the screen-mode tracker.

Source

fn drain_errors(&mut self) -> bool

Child diagnostics go to the shell’s stderr sink, never into data. End of the ring (or a revoked one) retires the reader.

Source

fn poll_interrupt(&mut self)

Look at the session event queue (through the job latch) without blocking. Ctrl-C marks the run interrupted; everything else typed meanwhile is discarded (scrubbed). An input service failure stops polling: the pipeline then runs to completion.

fn read_output(&mut self, out: &mut [u8]) -> Result<Option<usize>, StreamStop>

Next bytes of the last stage’s stdout (at most 512), pumping the rest of the segment while it is empty. Ok(None) is end of output (every writer closed).

fn close_consumer(&mut self)

The consumer needs no more output: upstream writers see BrokenPipe, and conclude cancels and reaps what is left.

fn settle(&mut self) -> Result<(), StreamStop>

After end of output: stop feeding and wait for every stage to close its stderr.

Source

fn conclude(&mut self) -> Vec<i32>

Release the run and return one status per stage. A run whose output ended normally is awaited; anything else (consumer closed early, interrupt, failure) is cancelled first so the reap cannot block on a live stage.

Source

fn reap(&mut self, cancel: bool)

Close every shell-held endpoint, reap every stage (terminal record of its root task via QueryChild) and release the pipeline Operation. Idempotent.
