Module executor

Shell AST executor — runs parsed commands, handles pipes and redirects.

Byte pipelines between built-in commands are implemented via an in-memory capture stack (shell_state): each stage’s output is captured into a Vec<u8>, then passed as stdin to the next stage. CaptureGuard (RAII, Law 8) pops the capture on every exit path, including early returns.

Typed pipelines (ps --records | where … | take N | to jsonl) never touch that stack: typed::admit statically admits the WHOLE pipeline (stages, redirects, background, stateful built-ins) before any stage runs or any file is opened, and typed::run_rows pulls rows through a bounded chain.

While a terminal session owns the shell, spawned cells join typed and byte pipelines as external stages: ExtRun (end of file) starts them inside one pipeline Operation, joins neighbouring stages with kernel streams, pumps the bytes that enter or leave the external segment, drains every child’s stderr to the shell’s own stderr sink, keeps servicing the session event queue (Ctrl-C cancels the whole pipeline) and reaps every stage on every exit path. Child bytes relayed to the terminal (that pump, and the serial foreground drain) are followed by screen_reset: a child that left the alternate screen, a hidden cursor or bracketed paste on is followed by one cellos-vt1 soft reset.

All shell state lives in shell_state behind locks; this module holds no mutable statics of its own.
