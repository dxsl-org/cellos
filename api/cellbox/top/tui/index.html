Module tui

Expand description

The interactive top session loop (Phase 06 S6-4).

Order of effects: the seed capture runs before anything reaches the terminal, so a telemetry failure renders exactly as in batch mode (status 1, no screen bytes). Then the REPL’s earlier output is flushed, type-ahead is drained (q/Ctrl-C/EOF typed before the first frame are honoured), and the TUI is entered through executor::with_tui on a viewport capped at MAX_VIEW. The only wait is TuiSession::next_event(deadline). Every exit path restores the screen and releases the raw lease before a diagnostic is written.
