cellbox::top

Module view 

Source
Expand description

Pure state and drawing of the interactive top view (no syscalls; host-tested).

ViewState turns input events into a Step for the session loop (tui.rs) and draws one frame into a Ratatui buffer. Every number, unit and quality marker on screen comes from text_engine::top::text, the code that prints batch text. The reducer has no lifecycle action: observing grants no right over what is observed.
