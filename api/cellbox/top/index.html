Shell adapter for top and ps: captures TelemetrySnapshot and drives the frames.

Option parsing, the sampler, records and the text table model are pure and live in text_engine::top. Here: the syscall capture, the blocking delay, the batch writer (render) and the interactive Ratatui view (view state and drawing, tui session loop).

Structs§

TelemetryReader
One reusable snapshot buffer. It starts at header + 64 Cells (+ 64 tasks when task rows are requested); after a capture without COMPLETE it grows once to the header totals, capped at [MAX_SNAPSHOT_BYTES], and captures again, so a frame beyond the cap is reported as truncated, never silently cut.
