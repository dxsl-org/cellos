Expand description

A typed segment serialized incrementally for an external consumer: items are pulled only when the consumer’s stdin has room, so memory stays bounded by one fill (not by the stream) and an endless producer (top --records) never runs ahead of the stage reading it.

pub fn new( source: Box<dyn RowSource>, category: Category, first_stage: usize, stages: &[Stage], default_sink: DefaultSink, ) -> Result<RowFeed, RunFailure>

Build the chain over source (row stages applied, nothing pulled yet). The serializer is the explicit trailing to; without one, the search text for DefaultSink::SearchText and typed JSONL otherwise (a pipe is never a table).

Source

pub fn fill( &mut self, out: &mut Vec<u8>, want: usize, ) -> Result<bool, RunFailure>

Append encoded items to out until it holds at least want bytes or the items end. Ok(false) means the end of the items was reached and the closing bytes of the serializer are in out; the chain is then already closed. An error closes the chain and names the stage that failed.
