Module typed 

Source
Expand description

Typed (record) pipeline admission, bounded execution and display.

This module owns no grammar: the parser still produces Cmd stages, and the stage vocabulary (select, where, sort-by, take, to, from) is parsed by text_engine::pipeline::parse_stage. What lives here is

  • admission — admit classifies every expanded stage and either accepts the pipeline as legacy byte composition, as a TypedPlan, or refuses it with a one-line reason. It is pure: no syscall, no VFS access, no redirect open. The executor calls it before ANY stage runs or file is touched;

  • execution — run_rows drives a pull chain of RowSources, moving each row once (no intermediate String, no global stdin/sink), and closes the whole chain when the consumer is done (take, error, end of input). A sink that needs a whole bounded buffer (a redirect, a byte consumer, an enclosing capture) collects with run_rows; the live terminal streams with stream_rows (one row buffered, Ctrl-C polled between rows);

  • display — the terminal table renderer. Rows that are not explicitly serialized reach a terminal as a table and a redirect/non-terminal sink as typed JSONL; the choice never changes the data type or authority.

  • external stages — while a terminal session owns the shell, spawned cells may join a pipeline through shell-owned byte streams: rows → to → external, external → from → rows, external | external, cat F | external and an external last stage. admit decides which shapes are legal; the executor owns the processes and endpoints. StreamRows turns the bytes of an external stage into rows incrementally so take can stop an endless producer.
