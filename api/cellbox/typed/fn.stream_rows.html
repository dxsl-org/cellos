Like run_rows for a sink that is the terminal: each encoded item is written to sink as soon as it is pulled, so memory stays bounded by one item however long the source runs, and the sink is polled for an interrupt before every pull. The chain is closed on every exit path (a satisfied take, Ctrl-C, an error).

Explicit serializers (to jsonl|json|text|...), the typed JSONL default and the search text default stream item by item. The default table is the one exception: it buffers rows to align the columns — the whole stream for Rows, one frame for Frames — bounded by MAX_TABLE_ROWS and MAX_TABLE_HEAP_BYTES (refusing with the usual one-line error), then streams the rendered lines; a frame is written at its End.

Unlike run_rows a failure can arrive after bytes were delivered: the rows before it have been shown, then the failure is reported.
