Struct Table 

Source 
struct Table {
    columns: Vec<String>,
    rows: Vec<Vec<(usize, String)>>,
    widths: Vec<usize>,
}
Expand description

Rows of a terminal table held while the column widths are unknown: this is a genuine whole-set buffer, so it is bounded by rows (MAX_TABLE_ROWS), by cell text (MAX_SINK_BYTES) and by its estimated heap (MAX_TABLE_HEAP_BYTES).
