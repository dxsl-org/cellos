pub fn reaped_status(exit: Option<i32>, reason: u32, cancelled: bool) -> i32
Expand description

Status the shell records for a stage it reaped. exit is the code wait returned (None when the kernel refused the wait) and reason the kernel’s stop reason (0 when the stage ended by itself). A stage the kernel stopped because its consumer closed (reason 3) reports 141; one stopped for any other reason, or cancelled by the shell with a nonzero exit, reports 130 (unless it had already exited cleanly); a refused wait on a stage nobody cancelled is 125 (status unavailable, never guessed).
