Expand description

The local terminal side: trust through the VFS, the password under the input owner’s echo-off lease, then raw (PTY) or canonical (exec) input.

fn confirm(&mut self, key: &HostKey) -> (Trust, bool)

Challenge (VFS), begin (input owner, on this session at its current epoch), then poll VFS for the stored outcome while the owner holds the terminal. Returns the answer and whether this confirmation stored the key.

fn confirm_unknown(&mut self, key: &HostKey) -> Trust

First trust (S9-4c): VFS registers a challenge for this exact key and session; the input owner prompts and captures the answer itself (this client reads no input meanwhile) and VFS stores an accepted key. Only a stored key continues.
