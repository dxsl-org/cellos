Expand description

The local side of a pipeline stage (publickey exec): host trust through the VFS, then the stage’s own stdin, stdout and stderr streams, byte for byte. There is no terminal: nothing is prompted, an unknown host key is refused (host_key_no_frontend) and a wrapped identity was refused by the preflight (unlock_needs_terminal).
