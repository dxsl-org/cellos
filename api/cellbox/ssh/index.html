cellbox ssh (Phase 09, command-contracts §4).

The shell builtin validates argv and re-launches this same ELF from its second install path /bin/cellbox-ssh with argv ["ssh", ...] (D79-9 as revised): only that kernel-resolved path edge carries the outbound client rights, so the shell itself never holds network authority. The child entry below runs in that Cell.

Host trust comes from the VFS store (S9-3). An unknown key is offered for first trust (S9-4c): VFS registers a challenge with the input owner, which itself prompts on this session and captures the answer; this client only begins the confirmation and polls VFS for the stored result, never reading the answer. Nothing beyond KEX is sent before the key is trusted.
