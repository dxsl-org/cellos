Expand description

One signature: for a passphrase-wrapped identity first ask for the passphrase (once, no re-prompt), stage it and wipe it; then sign. A plain identity skips the unlock. An empty passphrase is not representable on the wire (secret_len is 1..=1,024), so it is unlock_failed locally, without a key-service call. A staged secret is consumed by the sign (success or failure), so nothing is aborted afterwards.
