Expand description

top --records: the first pull seeds the baseline, waits one delay and captures; every later frame waits and captures. Each capture becomes one Frame (Begin, rows, End). Ctrl-C during a wait (the job latch, S10-3b) ends the stream; the consumer reports 130.
