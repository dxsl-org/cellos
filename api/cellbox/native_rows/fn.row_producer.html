Registry entry for native row producers. None means argv is not a native record producer (no --records flag or another command); Some(Err(2)) reports bad arguments after the usage line has been written to stderr. rg and top poll the job’s interrupt latch while they work (rg while it walks, top while it waits between frames); ps/ls ignore it.
