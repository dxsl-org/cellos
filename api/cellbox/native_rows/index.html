Module native_rows 

Source
Expand description

Native record producers (ps --records, ls --records, top --records) and the exact-byte file reader behind cat byte stages.

Producers are pull-based [RowSource]s. Construction only validates argv — every syscall, VFS request and sampling delay happens on the first pull, so pipeline admission has no effect and close() stops all further work (a closed top never captures again).

ps and ls produce finite Rows; top --records produces Frames (spec §1), one frame per telemetry capture, so truncation (complete/dropped) travels with the data.

PsSource 🔒
ps --records: one capture of every task (D62-1: cumulative cpu_ns, Null cpu_tenths, quality new), top.task.v1 rows in TID order. An incomplete capture is an error.
TopSource 🔒
top --records: the first pull seeds the baseline, waits one delay and captures; every later frame waits and captures. Each capture becomes one Frame (Begin, rows, End). Ctrl-C during a wait (the job latch, S10-3b) ends the stream; the consumer reports 130.
