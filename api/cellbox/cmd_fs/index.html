Module cmd_fs 

Source
Expand description

Filesystem-oriented shell built-ins: wc, head, tail, mkdir, rm, rmdir, touch.

VFS-write operations (mkdir, rm, rmdir) send IPC to the VFS service cell resolved via sys_lookup_service. Read operations use the kernel’s sys_open/sys_read path, gated by bootfs_fallback_allowed so a VFS refusal is never bypassed.

bootfs_fallback_allowed 🔒
Whether the kernel BootFS (VIFS1) route may serve path. That route skips the VFS caller/path policy, so it is used only when the VFS itself permits the read or answers “no such entry” (IO); a VFS refusal, or no VFS answer at all, never falls through.
