machine pin [--confirm]: the console client of the machine-pin cell (ADR-0029 §3 as amended in Phase 13, the ADR-0028 CLI pattern). The shell holds no pin authority: it asks the service::MACHINE_PIN provider with the [wire::machine_pin] frame and prints the answer. The cell honours Confirm only in safe mode and only from the console shell init started (init hands it that shell’s tid), identified by the kernel-attested sender tid, so the request is sent from this task: the builtin runs in process, never as a spawned child.

Output: the cell’s answers on stdout (a refusal too, so it follows the current= line); usage and transport failures on stderr. Exit status: 0 on a status report or a recorded pin, 1 on a refusal or a failure, 2 on a usage error.

One bounded exchange with the machine-pin cell from this task. The reply buffer holds any reply the kernel can return, so a terminal is never retained for want of space; the frame decoder refuses one longer than a response. An unsettled call is cancelled and its terminal taken, releasing the slot; a reply that wins the cancel is still used.
