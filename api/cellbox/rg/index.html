Module rg 

Source
Expand description

rg: ripgrep-derived search over the Cellos VFS as a typed row producer (Phase 07 S7-3, phase-07-s3-proposal.md).

  • args parses the frozen argv surface at admission (status 2 before any effect);
  • producer / stdin_producer compile the matcher and globs and return a pull-based [RowSource] of cellbox.search.line records. Nothing touches the VFS until the first pull;
  • tree adapts ostd::clients::VfsClient to vigrep::walk::ViSearchTree (per-directory reopen with one cached parent handle);
  • source drives vigrep’s resumable file search one bounded segment per pull (8 rows / 32 KiB queued at most), reports per-entry diagnostics and one end summary, and exposes the 0/1/2 completion status;
  • text is the streaming plain-text renderer with terminal-safe escaping.

Memory: RG_PROFILE tightens the contract ceilings so a search fits the cellbox arena next to the shell (DV7-10, D76-3 M2); the bounds are measured by the host heap test in tests.rs.
