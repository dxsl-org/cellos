Streaming plain-text rendering of cellbox.search.line rows (proposal §3.6; D74-3, D76-11, D76-12).

One row renders as ESCAPED_PATH (':' | '-') LINE (':' | '-') ESCAPED_LINE '\n', : for a match and - for context, <stdin> for a Null path. The path is the record’s absolute canonical path. Escaping keeps printable valid UTF-8 and writes everything else as ASCII escapes, so the output is ASCII plus valid UTF-8 and never carries a terminal control byte (in particular no ESC).
