rg argv (proposal §3.2, command-contracts.md §1 and §2.1).

Words are scanned left to right until -- or the first operand; a bare - is an operand. Every other - word before -- must be an exact supported spelling: no combined short options, --name=value, abbreviations or upstream-only flags. Value options consume exactly the next word. Parsing is pure and runs at admission, so every error here is status 2 before any effect.
