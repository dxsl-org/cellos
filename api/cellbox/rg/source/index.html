cellbox::rg

Module source 

Source
Expand description

The rg row producers (proposal §3.5).

A pull runs at most one bounded search segment: vigrep’s resumable file search hands rows to RowSink, which queues them and asks for a pause once the queue holds Limits::queue_rows rows or Limits::queue_bytes bytes (always at least one row). The next pulls drain the queue; only an empty queue advances the search, so the queue never exceeds the cap plus one row.

Errors of one entry, file or ignore file are reported as they happen (one rg: PATH: reason line on stderr, escaped like the text renderer) and the walk continues; rows already delivered stay delivered. At the end one summary line is reported when anything failed or was skipped as a mount. The completion status is 0 (a matching line, no error), 1 (no matching line, no error) or 2 (any error); an interrupt ends the producer with no status.
