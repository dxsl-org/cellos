struct RowSink<'a> {
    matcher: &'a RegexMatcher,
    path: Option<&'a [u8]>,
    rows: &'a mut Rows,
    quiet: bool,
    limits: Limits,
}
Expand description

The searcher’s sink: one record per match/context line, queued; Ok(false) accepts the row and pauses the search (vigrep’s resumable contract).
