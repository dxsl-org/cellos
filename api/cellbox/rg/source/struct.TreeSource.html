fn completion(&self) -> Option<i32>

The producer’s completion status (rg: 0 matched, 1 no match, 2 error), read by the driver after the chain is closed. None when the producer reports none (the default) or did not run to completion (e.g. interrupted). Stages forward their upstream’s value.
