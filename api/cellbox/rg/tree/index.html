VfsTree: vigrep::walk::ViSearchTree over the VFS streaming client (OpenRootDir, ListDirPage, OpenFileAt, ReadFileHandle, FileState).

Every directory is reopened by path (H1, D74-5). Files are opened through one cached parent directory handle (D76-14), so consecutive siblings cost one OpenFileAt each. CloseDir revokes every handle derived from the directory, so the cached parent is evicted only while no file opened through it is open; the walker never holds two files at once. Peak: one listing directory, the cached parent and one file. Authority is exactly the caller’s VFS table: no BootFS fallback, no grant, no seal.
