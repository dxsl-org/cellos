libdrm-lite witness for x86_64 Tier-2 (runtime plan R6).

The checks live in c/witness.c and print DRM-LITE: <name> OK|FAIL markers, then DRM-LITE: <pass>/<total> pass; the Cell exits 0 only when every check passed. They drive libdrm-lite and the mlibc fd provider route against the test-only fake provider; the iGPU G3 transport replaces it.

Running it needs a launch row for /bin/drm-lite-x86 (owner H-1); the runner is cells/tests/drm-lite-x86/run-qemu-x86.sh.
