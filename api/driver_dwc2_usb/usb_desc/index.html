Module usb_desc

Expand description

USB descriptor parsing (USB 2.0 §9.6).

A configuration descriptor is a flat blob of length-prefixed sub-descriptors that must be walked, not indexed: interface, endpoint, and class descriptors (HID’s 0x21 / 0x22) all live inside it in device-chosen order. The walker below is what makes composite devices — a wireless receiver’s keyboard interface plus its mouse interface — enumerable.

Every parser validates bLength before advancing. A truncated or hostile descriptor then ends the walk instead of driving an out-of-bounds read.
