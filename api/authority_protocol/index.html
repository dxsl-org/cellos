Crate authority_protocol 

Source
Expand description

Closed private AP↔STM32 protocol for the terminal DEV_REFERENCE lane.

The carrier is untrusted. Exactly fourteen typed operations exist; runtime provisioning, unseal, reset, arbitrary execution, and caller-selected keys are intentionally unrepresentable.
