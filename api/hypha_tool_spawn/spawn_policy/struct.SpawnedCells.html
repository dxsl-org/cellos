Struct SpawnedCells

pub struct SpawnedCells { /* private fields */ }
Expand description

Tids this tool-spawn instance started and has not yet killed.

Invariant: kill_cell acts only on a tid in this set. Tids are never re-issued within one boot, so an entry can never come to name a cell this session did not start.
