hypha_tool_fs

Module workspace 

Source
Expand description

Workspace confinement for tool-fs.

WHY: every path tool-fs receives was chosen by LLM output that crossed the network, and the cell holds VfsMutate. Unconfined, read_file/write_file are an arbitrary read/write of the whole VFS (/bin, policy, keys). Every request is therefore confined to one workspace directory.

Invariant: an accepted path is WORKSPACE_ROOT or WORKSPACE_ROOT/<c1>/…/<cn>, where every component is non-empty, is not . or .., and the whole path is printable ASCII without \. The check is purely lexical and nothing is normalised afterwards, so the string checked is byte-for-byte the string VFS receives (minus at most one trailing /).
