pub(crate) fn now_ticks() -> u64
Expand description

Scheduler ticks (10 ms slices) — the clock the kernel itself uses for RecvTimeout deadlines, and the one every *_TICKS constant in this crate assumes.

sys_get_time() is GetTime op 0, the raw architected counter (10 MHz mtime on RV64), so a window compared against it is a thousand times too small: the restart budget rolled on every exit and init never gave up on a crash-looping service.
