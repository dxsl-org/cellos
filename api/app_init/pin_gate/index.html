Module pin_gate 

Source
Expand description

The machine-pin gate as seen from init (ADR-0029 §3, Phase 13 amendment).

Init launches the machine-pin Cell right after the VFS (x86 only), registers it as MACHINE_PIN, and asks it MachinePinRequest::Gate as a client. Init answers no request itself. Safe mode is init’s to apply: it starts only the static safe set (the input service and the cellbox console shell) and tells the pin Cell the shell’s tid one way (MachinePinRequest::ConsoleShell), the only sender whose Confirm the Cell honours. Without an answer the gate fails closed: safe mode.
