Machine pin gate, safe mode and re-confirmation (ADR-0029 §3).

Before any configured service starts, init compares the kernel’s machine facts (syscall 433) with the record stored at /srv/.cellos-machine/pin:

  • no record on a healthy store: first boot, record and continue;
  • the same bytes: continue;
  • anything else: print the field-level difference and enter safe mode.

The pin carries no authority. It never changes a profile, driver gate or DMA decision; safe mode only withholds services. In safe mode init starts the static safe set (the input service and the cellbox console shell) and answers MachinePinRequest::Confirm only from that shell, only for the current digest. A confirmed pin takes effect at the next boot.
