Module silo 

Expand description

Purpose-specific wire contract for the development AArch64 Silo provider.

This is not a general signing interface. The accepted operations are the Phase 1 TLS 1.3 client CertificateVerify operation, public status, and the Phase 3 purpose-bound enrollment triple (create/sign-CRI/destroy) over one pending generation key that never leaves the guest.
