The kernel’s own root, recorded when its paging is activated.

A trap taken from a Cell leaves that Cell’s private root installed, so the kernel can run under a root that does not map its own MMIO. Naming both values is what makes a kernel fault diagnosable, and asm/trap.S reads this one at trap entry to install the kernel root before any kernel code runs.

The name is fixed on purpose: trap entry runs before Rust, so the value has to be reachable without a call. Zero means “not recorded yet” — the assembly then keeps whatever root is live.
