Expand description

One parsed metadata value.

Scalar variants borrow nothing; MetadataValue::Str and the data of MetadataValue::Array are subslices of the parsed buffer.

Str(&'a str)

UTF-8 string metadata value, borrowed from the file.

§

Array

Homogeneous array metadata value.

data holds the raw little-endian element bytes, so it is count * elem_size bytes long for fixed-width element types; for string arrays it is the concatenated u64 length || bytes encoding of the elements. Element type and count are exposed so typed accessors can rebuild the values without copying the file.

Fields

§elem_type: u32

Raw GGUF element type id of the array.

§count: u64

Number of elements.

§data: &'a [u8]

Raw little-endian element encodings, borrowed from the file.
