Source
Expand description

Private Phase03 stdin/stdout filter fixture. Mode is argv[0] (the first word after the program name); bytes move through the real delegated stream endpoints in the child context (Stdin / Stdout grants), never through a terminal session (only tui-abandon touches one, for its raw-mode lease).

Modes (exact byte semantics, nothing is interpreted or re-framed):

  • cat copy stdin to stdout until end of stream, exit 0
  • upper like cat, ASCII a-z mapped to A-Z, every other byte unchanged
  • noread exit 0 at once without touching any endpoint
  • exit N exit with status N (any i32) without touching any endpoint
  • gen write the fixed 6 bytes 00 ff 41 fe 80 7a (NUL, non-UTF-8, no trailing newline) to stdout, exit 0
  • hex read stdin to end of stream and print p03-hex len=<total> hex=<first 64 bytes as lowercase hex>\n
  • endless write 512-byte blocks until the consumer closes (exit 141) or the operation is cancelled (exit 130)
  • rows write the fixed plain JSONL {"a":1}\n{"a":2}\n (an external head for from jsonl), exit 0
  • typed write the fixed typed JSONL records pid 7 and pid 9 in the cellbox encoding (an external head for from jsonl --typed)
  • net-probe send each rights-gated NetRequest (Resolve, TcpConnect, UdpCreate, UdpBind, TcpListen, MulticastJoin, L2Send) once to the live net service and print one NETPROBE <op> <result> line per request, then NETPROBE DONE; <result> is denied for Err(NET_ERR_DENIED) and other:<detail> for anything else. This Cell holds no network right (its launch edge has an empty ceiling), so every line is expected to read denied.
  • config-probe get KEY / config-probe set KEY VALUE / config-probe delete KEY send one ConfigRequest to the live config service and print CFGPROBE <op> <KEY> <result>; <result> is ok, denied (Err(CONFIG_ERR_DENIED)), value:<v>, notfound or other:<detail>. This Cell holds no Q right (its edge ceiling lacks config_write), so set/delete are expected to read denied; get is ungated (Phase 01 CP1).
  • tui-abandon simulate a killed TUI: write the vitui enter bytes ESC[?1049h ESC[?25l ESC[?2004h followed by p03-tui-abandon\n to stdout and exit 0 WITHOUT restoring anything. As the serial session’s foreground reader it first takes the raw-mode lease (best effort) and keeps it to exit; as a pipeline stage it is no reader (no session binding, stdin end of file) and the bytes alone are the observable.

Exit statuses: 0 ok; 2 missing grant / bad argument / unknown mode; 3 other stream failure; 141 stdout BrokenPipe; 130 Cancelled.

Never part of an ordinary image: reachable only through the exact phase03-filter-profile launch row.
