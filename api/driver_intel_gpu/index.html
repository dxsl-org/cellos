Intel integrated GPU (Xe2/Xe3) Driver Cell — Tier-1 Privileged Driver Cell.

Serves the Linux xe uAPI over Cellos IPC (ADR-0033) for Panther Lake and Lunar Lake integrated GPUs as service XE_GPU (21), which init registers for this Cell (CP1 D-G8). Bring-up: forcewake -> GT identity -> GuC firmware -> GGTT -> WOPCM -> GuC reset -> ADS/params -> upload -> CT -> serve. Client buffers are client memory exported to this driver (437) and mapped into its device domain (438); the driver revokes them (439) after clearing their GPU mappings.
