Source
Expand description

The running GPU as the xe backend sees it ([GpuHw]): per-client PPGTTs in driver memory, GuC contexts with their LRCs, ring submission, and the export leases of CP1 D-G1 option B.

Upstream reference (MIT): drivers/gpu/drm/xe/xe_guc_submit.c (register_exec_queue, submit_exec_queue, disable_scheduling_deregister, deregister_exec_queue, the G2H handlers), xe_lrc.c, xe_ring_ops.c, xe_pt.c, xe_vm.c (xe_vm_pdp4_descriptor), xe_guc_tlb_inval.c and xe_tlb_inval.c.

Bans come from the GuC (CONTEXT_RESET_NOTIFICATION, NOTIFY_MEMORY_CAT_ERROR, ENGINE_FAILURE_NOTIFICATION), read from the G2H ring whenever a queue is touched.
