Module guc_ct 

Source
Expand description

The GuC command transport (CT) as the driver runs it: two buffer objects in device memory, registered and enabled over MMIO, then H2G messages written into the H2G ring and G2H events drained from the G2H ring by polling.

Upstream reference (MIT): drivers/gpu/drm/xe/xe_guc_ct.c (xe_guc_ct_init object layout, guc_ct_ctb_h2g_register, guc_ct_ctb_g2h_register, guc_ct_control_toggle, __xe_guc_ct_start, h2g_write, __guc_ct_send_locked, g2h_read), abi/guc_communication_ctb_abi.h (descriptor and message formats). The ring arithmetic is intel_gpu_core::ct. Interrupts are not used: the driver drains the G2H ring whenever it needs an answer or touches a queue.
