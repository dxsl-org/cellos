pub fn encode_ggtt_pte(phys: u64, pat: PatIndex) -> ViResult<u64>
Expand description

Encode a 64-bit GGTT PTE for system memory (xelpg_ggtt_pte_flags).

GGTT entries have no write-enable bit: bit 1 is XE_GGTT_PTE_DM (device memory) and must stay clear on an integrated GPU. Only PAT indices 0..=3 are encodable.
