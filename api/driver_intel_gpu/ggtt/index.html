Global Graphics Translation Table (GGTT) management for Intel Xe integrated GPUs.

Upstream reference: drivers/gpu/drm/xe/xe_ggtt.c, xe_wopcm.c, xe_gtt_defs.h and xe_guc_tlb_inval.c (MIT).

The GGTT maps device-visible memory into the 32-bit global aperture the GuC and its firmware DMA use. Each 64-bit entry maps one 4 KiB page; the entries live in the GTT stolen memory (GSM) that graphics IP 12.50 and later expose 8 MiB into BAR0.
