Module bring_up 

Source
Expand description

GPU bring-up: forcewake -> GT identity -> GuC firmware -> GGTT -> WOPCM -> GuC reset -> log, ADS and parameters -> transfer setup -> RSA -> uCode DMA -> boot -> CT enabled.

Upstream reference: the xe_device_probe / xe_uc_init / xe_uc_load_hw order in drivers/gpu/drm/xe/{xe_device,xe_uc,xe_guc,xe_wopcm}.c (MIT). Every failure is a typed BringUpError; nothing short of a running GuC with an enabled CT is reported ready.
