Module guc

Expand description

Intel GuC firmware load: WOPCM partition, reset, parameter block, transfer setup, uCode DMA, boot wait, and the MMIO host-to-GuC channel.

Upstream reference (MIT): drivers/gpu/drm/xe/xe_guc.c (xe_guc_reset, guc_write_params, guc_prepare_xfer, guc_xfer_rsa, guc_load_done, guc_wait_ucode, __xe_guc_upload, xe_guc_mmio_send_recv, xe_guc_notify), xe_uc_fw.c (uc_fw_xfer), xe_wopcm.c (xe_wopcm_init), xe_uc.c (order: WOPCM at init, then sanitize/reset, then upload), regs/xe_guc_regs.h and abi/guc_errors_abi.h.

Every wait is bounded by time through Clock, with upstream’s limits: GDRST 5 ms, uCode DMA 100 ms, GuC boot polled every 10 ms for up to 3 s (GUC_LOAD_TIMEOUT_SEC of a non-debug build; a load above 200 ms is reported as slow), MMIO replies 50 ms.

transfer_rsa
guc_xfer_rsa: the boot ROM reads a key larger than the scratch registers from GGTT; a smaller one must fill all of them (xe_uc_fw_copy_rsa short copy is -ENOMEM).
upload_guc_firmware
uc_fw_xfer: DMA the CSS header plus uCode (size bytes at GGTT address src_ggtt) into WOPCM at dst_wopcm, waiting up to 100 ms for the engine.
wait_guc_ukernel_running
guc_wait_ucode: read GUC_STATUS every 10 ms until guc_load_done reports a terminal state, for at most 3 s. Returns how long the load took in microseconds.
write_params
