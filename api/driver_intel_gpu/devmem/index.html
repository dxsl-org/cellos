Module devmem 

Source
Expand description

Driver-owned device memory: GuC log, ADS, CT buffers, LRCs and page tables.

Memory comes from the kernel in large chunks (GrantAlloc + GrantDma, one pin each) because a Driver Cell holds a small, fixed number of pins (MAX_PINS_PER_TASK), and a DMA authorization cannot be undone before the Cell dies (ostd::dma has no unmap). Each chunk is mapped once into the GGTT so the GuC can reach any allocation in it; allocations are page runs inside chunks and go back to the pool, zeroed, when freed. This plays the part of xe_bo_create_pin_map(..., XE_BO_FLAG_GGTT) in upstream xe.
