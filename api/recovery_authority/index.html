recovery-authority: the demo provider’s state authority and its worker’s lifecycle parent (CP1 option B). It commits request bindings atomically with the state, fences writer epochs, restarts a crashed worker only after the kernel reports the old incarnation’s retirement contained, and publishes the replacement (Ready) only after it restored and validated the committed state.
