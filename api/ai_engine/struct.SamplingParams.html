Sampling parameters for one session.

Fields§

§max_tokens: u16

Hard cap on generated tokens.

§temperature_milli: u16

Temperature × 1000; 0 selects greedy decoding.

§top_k: u16

Top-k cutoff; 0 means the whole vocabulary.

§seed: u32

Deterministic sampling seed.
