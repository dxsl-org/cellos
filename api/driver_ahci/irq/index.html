Module irq 

Source
Expand description

MSI completion wake-ups (x86 phase 04b, CP1 cp1-04b-waitcompletion-irq.md §7).

Contract: an interrupt is only ever a hint to re-read PxCI. Every park is bounded by PARK_TICKS, every return re-reads the port, and every park spends part of the command’s poll budget (see controller::completion_tick), so a lost, masked or revoked interrupt degrades to slow polling inside the existing budget and never to a hang. A refusal by AllocPcieIrq (435) or by WaitCompletion(IRQ) (242) keeps the polled path and says why.
