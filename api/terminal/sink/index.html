Module sink

cellos-vt1 byte parser between the session’s output streams and the screen.

Incremental: state survives any chunk edge. Interpreted (spec §4): UTF-8 text; BEL (no effect), BS, HT, LF, CR; ESC 7/8; CSI A B C D E F G H f J K m s u r S T; DECSET/ DECRST ?7 ?25 ?1049 ?2004. Every other sequence is consumed and ignored.

Bounds: a control is at most MAX_CONTROL bytes and MAX_PARAMS parameters; a longer one is abandoned and the parser returns to ground, so the excess is ordinary text. More parameters make the sequence a no-op. OSC/DCS/SOS/PM/APC strings are discarded until BEL/ST or MAX_STRING bytes. Nothing here can answer the producer: the parser has no output path, so device queries get no reply, and no OSC has a side effect (title, clipboard, URL, file).
