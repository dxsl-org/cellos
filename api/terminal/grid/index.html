Module grid

Expand description

cellos-vt1 screen model of the GUI Terminal (spec §4 “Terminal profile”).

Cells carry a character (plus at most one combining mark) and the attributes the renderer draws: foreground/background colour, bold and inverse. The model has autowrap with a pending-wrap state, tab stops every 8 columns, scroll margins, primary and alternate screens (?1049 saves/restores the cursor and leaves the primary content untouched), cursor visibility and the bracketed-paste flag.

Width follows unicode-width width() (ambiguous = 1): combining marks join the previous cell, wide characters take a lead cell plus a trailing cell, and the cursor never rests on a trailing half. Every allocation is bounded: rows 1..=256, columns 1..=512, at most 131,072 cells per screen, scrollback at most 1,024 lines and 1 MiB.

Line feed also returns the carriage: CellOS sessions have no output line discipline (no ONLCR), so programs write bare \n and expect the next line to start at column 0.
