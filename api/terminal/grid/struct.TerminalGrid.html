fn enter_alternate(&mut self)

Source

fn leave_alternate(&mut self)

?1049l: back to the untouched primary screen and its saved cursor. A no-op on the primary screen, so a soft reset after an ordinary program changes nothing.

Source

pub fn reset_modes(&mut self)

Back to the profile defaults (a new shell starts, or the shell ended): primary screen, visible cursor, autowrap, full margins, default rendition, no paste mode.

Source

pub fn select_graphic_rendition(&mut self, params: &[u16])

SGR: 0 reset, 1 bold, 22 normal, 7/27 inverse, 30-37/90-97 and 40-47/100-107 colours, 38/48 5;n and 2;r;g;b, 39/49 defaults. Dim, italic, underline, blink, hidden and strike (and their resets) are accepted without effect; unknown codes are ignored. A malformed 38/48 ends the sequence.

Source

pub fn resize(&mut self, cols: usize, rows: usize) -> Result<(), ResizeError>

Resize both screens, keeping their content from the top-left. When the cursor line would fall off the bottom, the oldest lines leave the top instead (primary lines into scrollback). Out-of-bounds sizes and failed allocations change nothing.
