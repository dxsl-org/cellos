Module session 

Source
Expand description

GUI Terminal session: a terminal_sdk::FrontendHost attached to the real /bin/cellbox sh, with its output bytes folded into the monospace grid.

The shell is the controller of its own session (Phase 05 S5-3 annex option C); this Cell only holds the frontend capability the input service issued. Nothing here interprets commands or fabricates responses: keyboard input goes to the session as normalized events through the frontend attachment, and everything on screen is what the shell relayed (its own output and its children’s) to this Cell’s output rings.

Window close inside the live Cell releases the frontend (the shell keeps a Detached session); TerminalSession::reattach resumes the same shell on a new frontend.
