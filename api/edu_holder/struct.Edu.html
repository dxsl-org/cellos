Expand description

The probed device, its MMIO window, its interrupt and a holder-owned page.

Fields§

§bdf: u32§mmio: MmioRegion§irq: bool§scratch: DmaBuf

One holder-owned page of 0xEE, GrantDma-authorized (identity IOVA): the source of every “device writes garbage” transfer. None where GrantDma is refused (no remapper under a Required profile: the L5 boot).

§scratch_iova: Option<u64>

pub(crate) fn dma(&self, ram: u64, count: u64, to_ram: bool) -> bool

One edu transfer of count (≤ 4096) bytes; to_ram selects device buffer → ram, otherwise ram → device buffer. Waits for the command’s run bit to clear, parked on the MSI when one is held.

Source

pub(crate) fn write_garbage(&self, iova: u64, len: u64) -> bool

Make the device write one page of 0xEE at iova: scratch → device buffer, then device buffer → iova.
