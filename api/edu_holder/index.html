Crate edu_holder 

Source
Expand description

Export holder of the ADR-0033 CP1 §7 QEMU lanes (L1-L5): a Tier-1 PCIe Driver Cell for QEMU’s edu device (1234:11e8) under -device intel-iommu.

Init registers it under the test-only holder service [edu_export_proto::SERVICE_ID], which test-hooks kernels admit into DMA_EXPORT_SERVICES. It maps client exports with MapDmaExport (438) and drives the edu DMA engine at the returned window IOVA:

  • edu registers (QEMU hw/misc/edu.c): 0x80 source, 0x88 destination, 0x90 count, 0x98 command (bit 0 run, bit 1 device→RAM, bit 2 raise IRQ 0x100 when done), 0x24 interrupt status, 0x64 interrupt acknowledge; the device buffer lives at device address 0x40000 (4096 bytes; a transfer outside it aborts QEMU, so every transfer here is at most one page).
  • The lane runs edu with dma_mask=0x7fffffffff so 39-bit window IOVAs reach the remapper unclamped.

Every outcome is one [edu-holder] serial line the lane script asserts.
