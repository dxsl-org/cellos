driver_virtio_net

Module device 

Source
Expand description

NIC device state shared by both virtio transports.

The transport is chosen per architecture: virtio-MMIO on riscv64/aarch64 (crate::mmio) and virtio-over-PCI on x86_64 (crate::pci_x86). Both produce a NetDevice whose Tx/Rx/MAC surface is identical, so the dispatcher and the net service never see which transport is underneath.
