Private Phase 06 S6-5 load fixture (phase-06-s5-proposal.md §3). Packaged only by the private terminal runner, at the sandbox path /data/bin/top-load (EMPTY launch ceiling, DV-13); never part of an ordinary image.

top-load W (1 ≤ W ≤ 31) spawns W worker threads of this Cell, waits until every one is parked and prints TOPLOAD ready workers=W tids=t1,…,tW. It then reads one command per typed line from its session (canonical typed events: text, then Enter) and answers each with exactly one line on its delegated stdout, printed after the effect holds:

CommandEffectAcknowledgement
busy Kthe first K live workers spin, the rest parkTOPLOAD busy tids=… (spinners)
idleevery worker parksTOPLOAD idle
exit Kthe first K live workers return and are joinedTOPLOAD exited tids=…
pingnoneTOPLOAD pong live=L
bench NN timed GetTime(0), then N timed YieldTOPLOAD bench clock_ns=… yield_ns=… (per call)
quitthe root exits, the Cell retires (also end of input)TOPLOAD bye

Anything else (or a count out of range) prints TOPLOAD error and changes nothing; a state that does not settle within SETTLE_NS prints TOPLOAD error timeout.

A spinner runs a pure arithmetic loop (no syscall) and re-reads its command word every SPIN_CHUNK iterations; a parked worker sleeps in SetTimer(PARK_TICKS) (about 100 ms) between reads, so a park costs about no CPU. Workers run at the default priority (the CPU-monopoly watchdog only applies to RealTime tasks).

Exit statuses: 0 quit or end of input; 2 usage; 3 session, stream or spawn failure; 130 cancelled (Ctrl-C).
