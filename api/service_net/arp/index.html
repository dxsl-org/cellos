Module arp 

Source
Expand description

Ethernet/IPv4 ARP frames (RFC 826) for RFC 3927 link-local claiming.

smoltcp 0.11 has no probe API and silently drops ARP whose sender IP is 0.0.0.0 (every probe), so the link-local engine reads ARP straight off the device RX path and transmits frames built here through the same TX queue.
