pub(crate) fn probe(mac: [u8; 6], candidate: [u8; 4]) -> Self

RFC 3927 §2.2.1 probe: a request for candidate with sender IP 0, so no host updates its cache with an address we do not own yet.

pub(crate) fn reply_to_probe(mac: [u8; 6], ip: [u8; 4], prober: [u8; 6]) -> Self

Answer to another host’s probe for our claimed address. The prober has no address yet, so the target IP stays 0 and the frame is broadcast.

pub(crate) fn encode_frame(&self) -> [u8; 42]

Encode as a broadcast Ethernet frame from sender_mac. RFC 3927 §2.5: every ARP packet with a link-local sender address, replies included, is broadcast so the whole link sees a conflict.
