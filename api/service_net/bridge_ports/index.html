Module bridge_ports 

Source
Expand description

Guest bridge ports beside the host stack.

Each L2 client (a hypervisor Cell, one per guest) owns one port, keyed by its Cell owner generation and released when that generation exits. Frames from the NIC are demultiplexed by destination MAC: a port’s address goes to that port only, broadcast and multicast go to the host stack and every port, anything else goes to the host stack.

Invariant: a port’s address is a unicast station address that is neither the host stack’s nor another port’s. It is checked when a port opens and on every frame a guest sends, so host unicast never reaches a guest, one guest never receives another’s unicast, and no guest sends as the host.
