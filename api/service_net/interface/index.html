smoltcp Device adapter backed by a registered NIC Driver Cell.

Tx/Rx operations resolve the provider registered under service::NIC_DRIVER. A missed lookup remains retryable so a slow-starting driver can become available later; transport failures invalidate the cached TID so a restarted driver can be discovered.
