Module link_local

RFC 3927 IPv4 link-local address claiming: probe, announce, defend.

A pure state machine on a millisecond clock. The service loop feeds it the ARP packets the device tapped off its RX path plus the current time, and applies the Events it emits (frames to send, the address to configure or drop, log lines). Deadlines are checked once per loop turn, and a turn parks for at most 100 ms, so the second-scale RFC intervals stay within one turn.
