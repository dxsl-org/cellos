Module stack_entropy

Expand description

Boot entropy for the smoltcp stack: the interface RNG seed and the ephemeral-port cursor.

smoltcp draws TCP initial sequence numbers, DNS transaction ids, DNS source ports and IPv4 ids from Config::random_seed. Left at its default of 0, every boot replays the same sequence and an off-path peer can predict them (spoofed connections, RST/data injection, DNS poisoning). Connect-side source ports were a plain counter from 49152 for the same reason.

Both come from ViRng, the same fail-closed source TLS uses: a kernel that serves no entropy stops the service here rather than running a predictable stack. A development kernel built with dev-weak-rng still serves bytes.
