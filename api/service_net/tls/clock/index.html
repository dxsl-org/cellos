ViTlsClock — authenticated-time gate for relay mTLS.

The platform/QEMU RTC is not authenticated. Default/fleet builds refuse TLS until protected authenticated time is integrated. The explicit QEMU DEV profile trusts a local host companion to verify the independent time source and retain its floor outside guest snapshots; it does not protect host rollback.
