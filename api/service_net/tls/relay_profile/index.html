Module relay_profile

Expand description

Service-net relay profile validation: mount paths and manifest schema.

Symlink/metadata inspection is impossible without VFS stat support (deviation 8), so validation is strictly lexical plus schema-allowlist: absolute canonical paths only, and private-key material is rejected by field name before any file is ever opened.

SCHEMA 🔒
Manifest sections and the only keys each accepts. Private-key fields are permitted exclusively in the host-only [server] section; their appearance anywhere else is a hard rejection.
