service_net

Module rights 

Source
Expand description

Coarse per-Cell network rights, enforced before any effect.

The kernel exports the sender Cell’s reviewed net rights as CALLER_FLAG_NET_* bits of the attested caller trailer. Every request that creates network reach — a name lookup, an egress socket, an inbound port or group, a raw frame — needs its right. A request that only acts on a socket the caller already owns is not gated: owning one already required a gated request, and the socket table rejects a foreign cap with its existing error. GetLocalIp stays ungated (it discloses only the local address).

A denial is NetResponse::Err(NET_ERR_DENIED) and nothing else: the runtime answers it before the owner watch, both intercepts and dispatch, so no socket, DNS query, owner watch or frame exists because of a denied request.
