Module vmm_session 

Source
Expand description

Tier 3 Linux MicroVM App Session IPC contract.

Governs communication between a user-facing app launcher (cells/apps/chrome) and the hypervisor Cell it spawned (/bin/hypervisor app).

The launcher owns the window. It sends VmmLaunchRequest with the window’s content size; the hypervisor binds the session to that sender, boots the guest at that display size, and from then on posts events to the launcher: the guest scanout Grant (shared read-only), damaged rectangles, and the guest’s exit. The launcher forwards its window’s input with VmmInputForwardRequest, asks for a new display size with VmmResizeRequest, and ends the guest with VMM_OP_TERMINATE_APP. Only the bound launcher may do any of these.
