pub fn admit_net_reply<'b>(
    provider: &ServiceBinding,
    recv_ret: isize,
    buf: &'b [u8],
) -> Option<NetResponse<'b>>
Expand description

Decode buf as the NET provider’s reply, or refuse it.

provider is the binding the request was sent to, read from LookupServiceBound for this round trip; recv_ret is Recv’s raw return. Refuses a non-live binding, a failed Recv, any other sender, and a frame that does not decode.
