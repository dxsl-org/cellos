Module vfs_dir_page 

Source
Expand description

Packed entry format and flag bits of VfsResponse::DirPage.

Each entry is kind:u8, len:u8, name[len]. name is one directory component that passes crate::dir_name::validate_dir_component, so it is valid UTF-8, 1–255 bytes, and can be passed back to OpenDir/OpenFileAt unchanged. A page holds only whole entries.
