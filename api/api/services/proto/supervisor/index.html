Module supervisor 

Source
Expand description

Supervisor wire, carried inside the App SDK envelope (super::app_envelope): [MAGIC, KIND_MESSAGE, op, …].

  • OP_HOTSWAP: { target_service: [u8; 64], new_elf: [u8; 128] }, 193 B.
  • OP_SNAPSHOT: opcode only, 1 B.
  • OP_STATUS reply: [OP_STATUS, phase, result], 3 B.
  • OP_POWER: [OP_POWER, action], 2 B; action is the SystemPower a0.

OP_POWER has the same byte as the feature-gated hostile-backend KILL_REQUEST_OPCODE; the envelope keeps them apart, since kill requests are raw frames.
