Module input 

Source
Expand description

Input wires: producer frames into the input service, the event delivered to the focused cell, and input → producer control frames.

Producer frame: [kind][code u32 LE][value i32 LE], 9 B, from the kernel (sender 0), the UART relay or a registered producer. EV_DEVICE frames carry a device id first: [EV_DEVICE][device u32][kind][code u32][value i32]. These EV_* kinds are not the Linux evdev types of crate::services::vmm_session (there EV_KEY is 1).
