Module trust

SessionV1 first-trust confirmation records (selectors 29–31; D79-11, D79-13).

VFS registers one immutable host-trust descriptor with the input owner (RegisterTrustChallenge, admitted only from the live registered VFS service). The attested foreground child of the descriptor’s target principal begins the owner-run confirmation with its exact session, lease and epoch (BeginTrustConfirmation). From then on input itself captures that session’s typed/raw/paste input (it never reaches the child) and asks the session controller to render a fixed prompt built only from the descriptor (TrustPrompt / TrustPromptEnd control events, see api::services::session::event_kind). Only the registering VFS principal collects the decision (CollectTrustDecision).

Every record here is a request or result body (the 24-byte header is separate). Decoders require the exact length; text fields are length-prefixed (u16) graphic ASCII (0x21..=0x7e), so no control byte can ever reach the rendered prompt.

TrustChallengeV1
Selector 29 request (the canonical descriptor bytes): challenge:Ref (VFS-issued, nonzero), target:Principal (the client Cell that will confirm), expiry_ns:u64, then TrustPromptV1. Result: confirmation:Ref (input-issued, unique). CollectTrustDecision returns the SHA-256 of exactly these bytes.
TrustDecisionV1
Selector 31 result (request: confirmation:Ref): decision:u32, challenge:Ref, target:Principal, session:Ref, epoch:u64, descriptor_sha256:[u8;32]. session and epoch are the confirmation’s binding (zero before BeginTrustConfirmation). A final decision is returned once; a later collect is Stale.
TrustPromptV1
The displayed part of a descriptor and the exact payload of the TrustPrompt control event: port:u16, host_len:u16, host, algorithm_len:u16, algorithm, fingerprint_len:u16, fingerprint. port is nonzero.
