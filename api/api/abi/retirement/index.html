api::abi

Module retirement 

Source
Expand description

Cell incarnation retirement verdict ABI (QueryRetirement = 431). The kernel writes one ViRetirementV1 per retired incarnation root, after quiescence (NotifyOnExit still fires earlier, at exit_task). Class K record (docs/abi-boundary-records.md): syscall 431 plus exact length, version exactly 1, reserved fields zero, undefined state values and reasons bits refused, little-endian in declared field order. No record (unknown or evicted root) must be treated as RetirementState::Unproven.
