Expand description

Who the kernel says called.

Construct only from a kernel-written trailer (CallerIdentity::from_trailer) or, inside the kernel, from live scheduler state — never from request bytes.

Fields§

§flags: u32

Flag word unpacked from trailer bytes 4..8 (e.g. CALLER_FLAG_VFS_MUTATE).

§cell_id: u64

Owning cell of the calling task. A thread reports its parent cell here.

§generation: u64

Monotonic epoch assigned when the cell was created, inherited by its threads.

§sender_tid: u64

Task id that actually sent the message. Diagnostics only.

Source

pub fn from_recv_buf(buf: &[u8]) -> Option<Self>

Parse the trailer out of a recv buffer that opted in with RECV_ATTEST_CALLER.

Returns None when the buffer is too small to hold a trailer, when the tail is not a kernel-written trailer, or when the attested cell_id is 0. Every one of those is “identity unknown”, and the only correct response to an unknown identity is to deny the request.

Source

pub fn from_trailer(bytes: &[u8]) -> Option<Self>

Parse a trailer from exactly the trailer bytes.

Split out from Self::from_recv_buf so the kernel and host tests can round-trip the encoding without constructing a whole recv buffer.
