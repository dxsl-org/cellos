ProbeVirtioMmio (442) result encoding.

Success packs the slot’s VirtIO DeviceID (bits 0..16) and the low byte of its Status register (bits 16..24) into one word. Both fit: assigned device IDs are far below 2^16 and device status is an 8-bit field. The packed value stays below every error sentinel on RV32 as well.
