Module machine_facts 

Source
Expand description

Machine facts record (QueryMachineFacts = 433; ADR-0029 §3).

ViMachineFactsV1 is a class K record (docs/abi-boundary-records.md): syscall 433 plus an exact out length of MACHINE_FACTS_CAPACITY, version exactly 1, total_len equal to the bytes present, flag bits outside FLAGS_KNOWN refused, every reserved byte zero, little-endian in declared field order. Producer: the kernel. Consumer: init, which also persists the exact bytes as the machine pin (class P, /srv/.cellos-machine/pin).

The record carries no authority. It detects change: profile, ACPI root OEM, SMBIOS type 1, DMAR/VT-d state, hypervisor bit and the PCI function multiset. The trailing SHA-256 is a display and identity handle, not an integrity check: this crate has no hash, so ViMachineFactsV1::decode never verifies it, and consumers compare whole records byte for byte.

Layout (off, size): 0 version u16 · 2 flags u16 · 4 total_len u32 · 8 profile_source u8 · 9 slug_len u8 · 10 smbios_manufacturer_len u8 · 11 smbios_product_len u8 · 12 pci_count u16 · 14 reserved u16 · 16 acpi_oem_revision u32 · 20 reserved u32 · 24 acpi_oem_table_id [8] · 32 acpi_oem_id [6] · 38 reserved [2] · 40 smbios_uuid [16] · 56 slug [64] · 120 smbios_manufacturer [64] · 184 smbios_product [64] · 248 reserved [8] · 256 pci[n] 8 bytes each · 256+8n digest [32].
