CreateEnrollmentKey

Create the fresh non-exportable key for one pending generation.

The nonce is fresh admitted entropy per call so a destroyed key can never be regenerated from generation facts alone.

PromoteEnrollmentKey

Atomically promote the pending key to the active TLS signer and retire the previous active key inside the guest. The new serving (generation, policy/profile digest) tuple is bound into promotion so status and TLS authorization follow the promoted key dynamically.
