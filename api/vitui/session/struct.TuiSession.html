impl<'s, W: ByteSink> TuiSession<'s, W>

Source

pub fn enter( session: &'s mut TerminalSession, sink: W, ) -> Result<Self, SessionError<W::Error>>

Takes the raw-input lease, enters TUI_SCREEN and clears it. sink is normally session.stdout(). The size is the session’s current one. Nothing stays changed when entry fails.

Source

pub fn enter_bounded( session: &'s mut TerminalSession, sink: W, max: Size, ) -> Result<Self, SessionError<W::Error>>

TuiSession::enter with the drawn area clamped to max at the top-left (a fixed Ratatui viewport). The backend keeps the session’s exact size, a Resize re-applies the clamp and repaints, and the screen outside the drawn area stays cleared. frame.area() is the drawn area; terminal().size() is the session size.

Source

pub fn terminal(&mut self) -> &mut Terminal<CellosBackend<W>>

Source

pub fn next_event( &mut self, deadline_ns: u64, ) -> Result<Event, SessionError<W::Error>>

Next input event; deadline_ns follows RawInput::next_event (0 polls, u64::MAX waits). A Resize is applied to the backend (and to a bounded viewport) before it is returned, so the next draw clears and repaints at the new size.

Source

pub fn exit(self) -> Result<(), SessionError<W::Error>>

Restores the screen, then releases the raw-input lease; reports the first failure. Dropping does the same without reporting.
