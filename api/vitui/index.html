Crate vitui 

Source
Expand description

Ratatui on Cellos terminal sessions.

backend::CellosBackend implements ratatui_core::backend::Backend over a backend::ByteSink (a session’s stdout endpoint); event::EventAdapter turns the SDK’s typed input and control frames into event::Events; session::TuiSession scopes the raw-input lease and the TUI screen mode. theme is style data on Ratatui types (truecolor palette with 256/16-colour fallbacks, border sets, styled bars, list highlight, key hints, block-element chart markers). ratatui re-exports the pinned Ratatui crates under one path.
