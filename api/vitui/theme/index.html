Module theme 

Source
Expand description

Style data for Ratatui apps on Cellos sessions: a truecolor palette with 256- and 16-colour fallbacks, border sets and a few styled building blocks (title bar, status line, selectable-list highlight, key-hint footer). Pure data on Ratatui types; nothing here renders or talks to a session.

§Colour mode

The session capabilities (terminal_sdk::session::Capabilities: frontend, size, mode, event and feature masks) advertise no colour mode, so an app passes ColorMode explicitly. The GUI Terminal’s cellos-vt1 screen renders 38;2/48;2 truecolor, so ColorMode::TrueColor is right there; the fallbacks serve frontends that only map the 256-colour or 16-colour palettes.

§Glyphs

The GUI Terminal draws the bundled JetBrains Mono, which covers every box-drawing (U+2500–257F) and block-element (U+2580–259F) character but no Braille pattern (0/256 of U+2800–28FF): a Braille cell renders as the missing-glyph box. The marker defaults (CHART_MARKER, CANVAS_MARKER) and HIGHLIGHT_SYMBOL therefore use block elements only.
