Struct CellosBackend 

Source 
pub struct CellosBackend<W: ByteSink> { /* private fields */ }
Expand description

Ratatui backend writing cellos-vt1 bytes to W.

Output is buffered and handed to the sink in ByteSink::MAX_WRITE chunks as soon as a chunk is full and on [Backend::flush] (which Terminal::draw calls once per frame). Dropping the backend flushes and restores the screen mode baseline ([TerminalMode::CANONICAL]), best effort.
