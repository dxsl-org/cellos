Command descriptor block builders (SPC-4 / SBC-3).

Every multi-byte CDB field is big-endian. All flag bits (EVPD, FUA, DPO, IMMED, PMI, group number) are zero and CONTROL is zero: the disk layer only needs plain, synchronous semantics.
