Struct ScsiDisk

pub struct ScsiDisk<E> { /* private fields */ }
Expand description

One direct-access LUN, ready for I/O. Built by ScsiDisk::probe.

Each read/write/flush issues exactly one command; the layer never retries, so the caller decides what to do with Retry-class sense.

Reads buf.len() / block_size() blocks starting at lba into buf. An empty buf issues no command.

§Errors

ScsiError::Misaligned, ScsiError::TooLarge, or ScsiError::OutOfRange before any command is issued; ScsiError::ShortTransfer when the device moved fewer bytes than requested (buffer contents then unspecified); otherwise any command error.

Writes buf (buf.len() / block_size() blocks) starting at lba. An empty buf issues no command. Data may sit in the device’s volatile cache until ScsiDisk::flush.

pub fn probe( exec: E, target: u8, config: ProbeConfig, ) -> Result<Self, ScsiError<E::Error>>

Finds the first direct-access disk LUN on target and readies it.

Steps: REPORT LUNS on LUN 0 (an ILLEGAL REQUEST response or an empty list falls back to probing LUN 0 alone); INQUIRY on each LUN in order, skipping LUNs whose INQUIRY fails with a SCSI status or malformed data; TEST UNIT READY with up to config.tur_retries reissues on Retry-class sense; READ CAPACITY(16).

§Errors
  • ScsiError::Transport from any command, immediately.
  • ScsiError::NoDisk when no LUN is a connected disk.
  • ScsiError::NotReady when TEST UNIT READY retries run out.
  • ScsiError::TransferLimitBelowBlockSize when config.max_transfer_bytes cannot hold one block.
  • Any other ScsiError from REPORT LUNS, TEST UNIT READY, or READ CAPACITY(16).
