Crate scsi_block 

Source
Expand description

SCSI block command layer (ADR-0031 phase 05; reused by PVSCSI in phase 09).

Transport-independent: a driver cell implements ScsiExecutor for its request queue (virtio-scsi, PVSCSI) and gets ScsiDisk, which discovers the first direct-access LUN on a target and issues READ(16) / WRITE(16) / SYNCHRONIZE CACHE(10). Everything the device returns (data-in, sense, residuals) is untrusted: malformed input becomes a ScsiError, never a panic.
