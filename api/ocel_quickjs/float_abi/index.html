Module float_abi 

Source
Expand description

The engine’s C99 math, behind an integer-only boundary.

Rule H1 (docs/guides/tier1b-c-zig.md, “x86_64 C and the float boundary”): no float/double crosses between this cell’s Rust and its C by value. On x86_64 the engine’s C is hard-float SSE2 and every Rust Cell target is soft-float, so the two sides pass an f64 in different registers — the engine would read its own argument back as the result. The C side (vendor/include/math.h) therefore hands each double over as its IEEE-754 bit pattern and gets the result back the same way; the bit pattern is exact, so every architecture computes the same libm result.

Contract with math.h: one export cellos_qjs_<name>_bits per function it declares, taking and returning uint64_t bit patterns, except lrint (int64_t result) and modf (fractional part only; math.h takes the integral part from trunc).
