Module ffi 

Source
Expand description

C ABI of the vendored engine, plus the shim symbols it needs that the Tier-A C ABI (api::services::posix) does not export.

Everything else the engine links against — malloc/free/realloc, mem*/str*, snprintf/vsnprintf/fprintf/fputc/fwrite, stdout/stderr, abort, and the C99 math set — comes from libs/api, which every cell already links. This file therefore carries only the declarations of upstream quickjs.h that the engine driver uses, and the three bodies upstream expects from an OS: the clock and the epoch conversion behind Date.
