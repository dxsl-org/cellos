Intel e1000 (8254x) NIC Driver Cell — Tier-1 Privileged Driver Cell.

This cell owns one 82540EM or 82545EM PCIe endpoint exclusively. Through the shared nic_driver skeleton it:

  1. Calls sys_find_pcie_device_by_vendor(8086, id) (opcode 424) for each ID in identity::QUERY_DEVICE_IDS. The class triple 02:00:00 is shared with /bin/igb, /bin/e1000e and /bin/virtio-net, so the cell names its controllers exactly instead of using the class query (H-S3-6). Absent, it exits silently.
  2. Confirms the identity (identity::classify) before it touches MMIO.
  3. Claims exclusive MMIO via sys_request_mmio.
  4. Initialises the controller (TX/RX ring setup, EEPROM MAC read).
  5. Calls sys_register_nic_driver() to announce itself to the kernel.
  6. Serves Tx/Rx/GetMac IPC from the net cell. RX is request-driven (the net service asks for frames), so the cell stays polled.

This cell is granted PcieDriverCap by init via direct TCB write at spawn time — NOT via a manifest flag (all 8 flag bits in v1 are occupied).
