driver_virtio_scsi

Module ring 

Source
Expand description

Split-virtqueue geometry (virtio 1.2 §2.7) and the cell’s DMA region map. Pure: offsets and index math only, host-tested.

One DMA allocation of DMA_PAGES pages holds everything the device touches:

offsetcontents
0descriptor table, avail ring, used ring
REQ_OFFvirtio_scsi_req_cmd device-readable header
RESP_OFFvirtio_scsi_resp_cmd device-writable part
DATA_OFFdata-in / data-out bounce buffer
