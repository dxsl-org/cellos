virtio-scsi Driver Cell — Tier-1 Privileged Driver Cell (x86_64).

Claims the first QEMU virtio-scsi-pci controller (modern 1af4:1048, then transitional 1af4:1004), brings it up over the cell-side virtio PCI transport with a polled request virtqueue in authorized DMA memory, finds the first direct-access disk LUN through scsi-block, publishes the block route of its BDF via sys_register_block_device(BlockDevice::Pci { .. }) and serves the DrvRequest sector-I/O protocol (same wire format as the virtio-blk/NVMe cells) to the registered VFS only.

Interrupts are not routed (phase 04b deferred): completion is polled with a time budget.

§Law 4 exception

src/dma.rs (DMA memory) and src/config.rs (device configuration reads) use unsafe; every block carries a // SAFETY: comment.
