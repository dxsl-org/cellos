pub fn decode_resp(resp: &[u8]) -> Result<Completion, VscsiError>

Decodes virtio_scsi_resp_cmd (RESP_FIXED + sense_size bytes in resp) into a Completion. Sense is decoded from min(sense_len, sense bytes present) bytes when sense_len > 0.
