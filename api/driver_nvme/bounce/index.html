The one-page DMA buffer every sector read/write goes through (audit 08 S-11).

A timed-out command is not aborted: the device may still DMA a late READ into the page, or fetch a late WRITE’s payload from it. Reusing that page for the next request would let the stale transfer overwrite the next result or write the next payload to the old LBA, so a page with a command outstanding is retired - kept allocated and authorized for the driver’s lifetime, never freed - and a fresh page takes its place.
