Module deadline 

Source
Expand description

Time budgets for the driver’s waits (Phase 10 S10-3c, D3c-1 A).

Every wait used to end after a fixed number of polls. A poll is one volatile read and the loop yields every POLL_YIELD_EVERY polls, but a yield returns at once when nothing else is runnable, so the same count lasted a few seconds in an idle guest and much longer during a busy boot: a Flush (a host fsync) could outlast it. The budgets are now milliseconds on the kernel’s monotonic clock (GetTime), read only at the yield cadence. Without a clock the old poll count stays the bound.
