pub(crate) fn request_ids(owner: usize) -> Option<[usize; 4]>
Expand description

Ask the owner for the four grant ids over the protocol channel.

This is the in-band handoff: the ids are kernel-assigned after the owner started, so no launcher can put them on this cell’s command line. The interactive lane avoids the question by reading the owner’s HANDOFF line and typing the ids at the shell; the AArch64 boot order has no console round trip to spend, so it gets them here instead — same Send/Recv ABI, no new call.
