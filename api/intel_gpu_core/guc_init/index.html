GuC boot parameters (GUC_CTL_*) and the WOPCM partition, computed before the firmware transfer.

Upstream reference (MIT): drivers/gpu/drm/xe/xe_guc.c (guc_ctl_log_params_flags, guc_ctl_feature_flags, guc_ctl_debug_flags, guc_ctl_ads_flags, guc_ctl_devid, guc_init_params_post_hwconfig, guc_write_params), xe_guc_fwif.h (GUC_CTL_* bit layouts), xe_guc_log.h (buffer sizes of a non-debug build) and xe_wopcm.c (xe_wopcm_init, __check_layout, __wopcm_regs_locked, __wopcm_init_regs).
