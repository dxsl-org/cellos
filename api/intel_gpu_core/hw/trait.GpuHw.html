Expand description

Device effects of the xe uAPI.

Every method that reports success has completed its effect on the device side (leaves written, H2G message published); nothing is queued for later.

Write XE_PTE_NULL leaves for [va, va + len): reads return zero, writes drop.

Source

fn vm_unmap(&mut self, vm: HwVm, va: u64, len: u64)

Clear every present leaf in [va, va + len) and invalidate the GPU TLBs, so the range is unreachable when this returns.

Source

fn vm_destroy(&mut self, vm: HwVm)

Free the PPGTT’s tables. The caller has unmapped every range and destroyed every queue that used the VM.
