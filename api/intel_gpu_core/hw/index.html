What the hardware-independent xe backend asks of the GPU and of the kernel.

crate::backend::XeSession keeps the uAPI bookkeeping (handles, VMs, queues) and calls a GpuHw for every effect that reaches the device: PPGTT leaves, GuC contexts, ring submission, and the client-memory export leases of CP1 D-G1 option B. The driver Cell implements it over MMIO, its DMA pool and syscalls 438/439; host tests implement it with recording fakes. Keeping the effects behind one trait is what lets the uAPI rules be tested byte for byte without a GPU.
