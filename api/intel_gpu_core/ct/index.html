Module ct 

Source
Expand description

GuC command transport (CT): message headers from drivers/gpu/drm/xe/abi/guc_communication_ctb_abi.h and abi/guc_messages_abi.h, ring arithmetic from h2g_write / g2h_read in drivers/gpu/drm/xe/xe_guc_ct.c (all MIT).

The rings are dword arrays shared with the GuC. The caller owns the shared memory and the descriptor (head/tail/status words) and must order its writes: message dwords become visible before the descriptor tail that publishes them.
