DRM and Linux Xe ioctl definitions and request decoding.

Upstream reference: include/uapi/drm/drm.h, include/uapi/drm/xe_drm.h and include/uapi/asm-generic/ioctl.h (MIT / GPL-2.0 WITH Linux-syscall-note). Struct sizes are the LP64 layouts every Cellos target uses.
