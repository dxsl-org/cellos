Module uapi 

Source
Expand description

The Linux xe uAPI subset Mesa anv issues for compute (ADR-0033 G1), decoded at the uapi struct offsets over one open DRM file’s XeSession and Syncobjs.

Upstream reference: include/uapi/drm/drm.h, include/uapi/drm/xe_drm.h, drivers/gpu/drm/drm_ioctl.c and the xe_*_ioctl argument checks in drivers/gpu/drm/xe/{xe_bo,xe_vm,xe_exec_queue,xe_exec}.c (MIT). Requests are matched on the full Linux encoding (direction, type, number, struct size). The driver Cell’s IPC service and the host harnesses run this one decoder, so a request means the same thing on both.
