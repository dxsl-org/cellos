Payloads of DRM_IOCTL_XE_DEVICE_QUERY for Mesa anv.

Upstream reference: drivers/gpu/drm/xe/xe_query.c and xe_drm.h (MIT). Every layout below is the uapi struct byte for byte. The values come from a DeviceInfo, which the driver Cell fills from the probed GT registers; the device has one GT and system memory only.
