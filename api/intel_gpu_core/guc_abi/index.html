Module guc_abi

Expand description

GuC host-to-GuC messages the driver sends and the GuC-to-host events it reads.

Upstream reference (MIT): drivers/gpu/drm/xe/abi/guc_actions_abi.h (action codes, HOST2GUC_SELF_CFG, HOST2GUC_CONTROL_CTB, TLB invalidation operands), abi/guc_messages_abi.h (HXG header fields), abi/guc_klvs_abi.h (self-config keys), abi/guc_scheduler_abi.h (engine classes, CONTEXT_REGISTRATION_FLAG_*, GUC_CONTEXT_ENABLE), xe_guc_submit.c (__register_exec_queue, submit_exec_queue, disable_scheduling_deregister, deregister_exec_queue), xe_guc_tlb_inval.c (send_tlb_inval_all), xe_guc.c (guc_self_cfg, xe_guc_mmio_send_recv) and xe_guc_ct.c (CTB layout, fences).

Every builder returns the action array exactly as upstream passes it to xe_guc_ct_send or xe_guc_mmio_send: action[0] is the action code, the transport adds its own header.
