pub fn gem_close( &mut self, handle: u32, hw: &mut impl GpuHw, ) -> Result<(), XeError>

DRM_IOCTL_GEM_CLOSE: clear every leaf of the object, then revoke its export.

Nothing outside the handle table keeps the object alive here (the client’s CPU mappings are its own pages), so the GPU loses the object with the handle.

pub fn vm_destroy( &mut self, vm_id: u32, hw: &mut impl GpuHw, ) -> Result<(), XeError>

DRM_IOCTL_XE_VM_DESTROY: every mapping is removed now; the page tables follow as soon as no exec queue’s context points at them.

Source

pub fn vm_bind( &mut self, vm_id: u32, ops: &[BindOp], hw: &mut impl GpuHw, ) -> Result<(), XeError>

DRM_IOCTL_XE_VM_BIND

Every op is validated before any is applied, so a refused array leaves the VM unchanged. A device failure while applying (no table memory) stops at that op; the ops before it stay bound, as their leaves are already live.
