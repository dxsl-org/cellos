Module backend 

Source
Expand description

Hardware-independent xe backend objects and session state: GEM buffer objects, GPU VMs, exec queues, and submission lifecycle (ADR-0033, G1/G2).

Upstream reference: drivers/gpu/drm/xe/{xe_bo,xe_vm,xe_exec_queue,xe_exec}.c (MIT) and include/uapi/drm/xe_drm.h.

Under CP1 D-G1 (option B) a GemObject is client memory the client exported to this driver (ExportDmaRange, 437) and the driver mapped into its device domain (MapDmaExport, 438): the object is the export’s IOVA window. Every device effect goes through a GpuHw. Teardown order is fixed: stop the contexts, clear the PPGTT leaves (with TLB invalidation), and only then revoke the export (439), so the GPU never holds a translation to a window the kernel is releasing.
