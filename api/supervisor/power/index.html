Module power 

Source
Expand description

Orderly shutdown for a PowerRequest (owner decision H-S2-8 (i)).

Contract: freeze (413) every Cell except this supervisor and the storage stack (the VFS and block-driver services and every live block-route provider), give the storage stack a bounded settle window to finish the requests it already holds, then call SystemPower (436). Nothing is flushed or synced, so the markers report only freeze counts and the window. A second power-button press ends the window at once. If 436 returns, every Cell this sweep froze is resumed and the 436 error is returned.
