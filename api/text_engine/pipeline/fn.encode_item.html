Serialize one item for a to sink. On error out is left unchanged.

In a Rows stream an item is a row and encodes as described for each format (Jsonl lines, one Json array element — first writes the opener, later rows a ,, close with finish_encoding — or LF-terminated Text). In a Frames stream only Jsonl/ JsonlTyped are admitted; each item becomes one {"frame":"begin"|"row"|"end",…} envelope line. A marker in a Rows stream or a frame in another format is a PipelineError::Sequence (admission and check_items already exclude both).
