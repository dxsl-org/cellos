Functions§

apply_row_stage
Wrap input with a row stage (Select/Where/SortBy/Take). Select/Where pass frame markers through unchanged. SortBy buffers at most MAX_SORT_RECORDS rows / MAX_SORT_PAYLOAD_BYTES (the whole stream, or one frame with --frame) then errors. Take closes upstream as soon as the nth row (or nth frame End) is delivered (n == 0 closes immediately without pulling). To/From are not row stages and are refused (the input is closed first).
check_items
Wrap a producer with the item-order guard for its category. Applied once at the producer; every stage and sink downstream relies on the order without re-checking it. A violation is a PipelineError::Sequence that closes the producer: any marker in a Rows stream; a Row outside a frame, a nested Begin or an End without a Begin; a stream that ends inside a frame; a sample_id that does not strictly increase.
