Struct InterruptLatch

Expand description

Sticky interrupt flag shared by every party of one typed job (one latch per job).

The job’s producer calls check (a Cell read, with one real poll every 16th call); sinks and external-stage pumps call poll_now at their own cadence. Whoever observes the interrupt first latches it, so no party can consume an interrupt the others then miss.
