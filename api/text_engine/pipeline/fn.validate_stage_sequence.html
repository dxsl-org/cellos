Static admission of a typed stage sequence fed by input. Returns what the sequence leaves at its tail. Frames (spec §1) are refused by every Rows-only stage before any producer exists: sort-by/take need --frame on Frames (and refuse it on Rows), and only to jsonl [--typed] can encode a frame stream (continuous; D63-4).
