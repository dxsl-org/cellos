Pure grep core: option parsing, pattern compilation, and record selection.

Nothing here touches stdin, the VFS, or the terminal — the caller loads the text (see LoadedInput) and prints Outcome::output. Pattern files (-f) are read through a caller-supplied reader so the parser stays pure.
