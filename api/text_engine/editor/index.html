text_engine

Module editor 

Source
Expand description

Pure edit state for cellbox edit (contract: command-contracts §3).

The document is its bytes. EditBuffer keeps them split into lines, each with its own terminator (LF, CRLF or none for the last line), so a file reopens byte for byte: mixed endings, a lone CR (ordinary content), tabs and a missing or present final newline all survive. Every mutation is a splice of the serialized bytes and is recorded as its exact inverse, so undo restores bytes rather than an approximation.

Positions are byte offsets that always sit on a UTF-8 scalar boundary and never inside a terminator. Display width is the caller’s: vertical motion takes a width function (the terminal SDK’s rules); tabs are 8-column stops here.

Limits are explicit and refused before mutation: 4 MiB, 262,144 lines, no NUL, 256 KiB clipboard and paste, and undo bounded by 1,024 groups and 1 MiB of retained payload across undo and redo.

Ideas, not code, follow Kibi (MIT OR Apache-2.0); no Kibi source is copied.
