Module highlight

Lexical highlighting for .toml, .sh and .rs only (contract §3.3).

Styling, never validation: spans cover byte ranges of one line’s text and nothing here changes text or evaluates anything. The only state carried between lines is a Rust block comment or a TOML triple-quoted string.
