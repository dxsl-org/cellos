text_engine::top

Module text 

Source
Expand description

The one text table model shared by batch top, the interactive view and text ps.

It prints the same sample values the records carry. A CPU rate that is not Quality::Ok is printed as a marker, never as 0.0. Every batch line fits MAX_WIDTH columns: an over-wide table first narrows the name column and then omits trailing columns whole (widths). The interactive view lays out the same Columns, labels and cell texts with its own width.

Column widths for columns of frame within max_width: each column is as wide as its label and its widest cell over all rows; an over-wide table drops trailing columns that cannot fit even with the name column at its minimum, then narrows the name column only as far as needed.
