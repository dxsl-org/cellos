Module blk_router 

Source
Expand description

Absolute-LBA block router for all disk-backed VFS backends, per device.

Every storage device a block Driver Cell registered (syscall 416) has a kernel route slot; the VFS reads the slots once at start (syscall 432) into its device table, and each backend addresses its device by DeviceRef. Requests go to the device’s provider over the DrvRequest IPC wire. This is the single place that speaks that wire, so FAT (block_stream) and CellosFS (disk_cellosfs) route identically.

The kernel block path (sys_blk_*) serves only DeviceRef::Kernel, the disk of boards where no Driver Cell registers a route (kernel-resident MMC).
