Module prepared_cwd

Expand description

Prepared cwd admission in the existing directory/owner/quota lifetime.

Entries are minted once, linked to the source, and sealed but unpublished. The kernel’s immutable issuer receipt is the only publication decision. Every ordinary ingress reconciles that decision before looking up a directory.
