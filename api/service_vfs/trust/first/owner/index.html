Functions§

collect
VFS → input: the decision of confirmation (InputOp::CollectTrustDecision), answered only to the registering principal. DECISION_PENDING is not consumed; a final decision is returned once (a later collect is Stale), and its lane (the confirmation Ref) is then retired. Compare every binding, including descriptor_sha256 against trust_descriptor_sha256 of the own record, before acting on it.
now_ns
Receiver-monotonic nanoseconds, checked rather than architecture-guessed.
register
VFS → input: register one first-trust descriptor (InputOp::RegisterTrustChallenge); returns the input-issued confirmation Ref the confirming client presents to BeginTrustConfirmation. Input admits only the live registered VFS task. The request lane is the single-use challenge Ref; it is kept only while the outcome is indeterminate (retry the identical descriptor to resolve it).
