SSH host trust (Phase 09 S9-3 lookup, S9-4c first trust in first; abi-vfs-telemetry §4).

The store is one file the VFS keeps under a path no caller may read or write (access::rules), seeded by the provisioner (D79-10). TrustLookup compares the caller’s configured host identifier, port, algorithm and complete key blob with it and answers one api::ipc::ssh_trust code; the store’s contents never leave the service. Only a caller holding the attested outbound-connect right may ask.

Store format v1 (UTF-8 text, LF line ends, no comments or blank lines):

cellos-ssh-trust v1
HOST PORT ALGORITHM BASE64-KEY-BLOB PROVENANCE

HOST is the canonical configured identifier (lowercase ASCII name or canonical IP literal), PORT decimal 1..=65535, ALGORITHM ssh-ed25519, the blob is the full SSH wire key (standard base64, padded) and PROVENANCE is preprovisioned or interactive. At most one line per (host, port); at most 1,024 entries, 4 KiB per blob and 1 MiB in total. Anything else makes the whole store unavailable, never a partial answer.
