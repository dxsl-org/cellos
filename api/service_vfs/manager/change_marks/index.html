Module change_marks 

Source
Expand description

Mutation marks for open handles (FileHandleState.modified, DirPage CHANGED).

Every mutating delegate of VfsManager reports here, so no request path can reach a backend without marking: the dispatchers for Write, WriteAt, Append, WriteGrant, WriteHandleGrant, Unlink/UnlinkAt, Rename, Mkdir, Rmdir and RmdirRecursive all end in these delegates.

A mutation that reached the backend marks even when the backend reported failure: FAT can fail after writing part of a file and CellosFS reports a possibly-accepted failure, so “failed” is not “unchanged”. The cost is one scan of the bounded handle tables (32 per holder) per mutation; no history is kept.
