Expand description

The request loop’s own state; the file system lives in GLOBAL_VFS.

Fields§

§idle_work: bool

Whether bounded preparations are still unsettled in the kernel. They can change without a message (they expire, commit or end), so only then does the loop poll and reconcile; otherwise every change arrives as a request or an owner death and the loop parks. Recomputed wherever state changes.

fn on_empty_poll(&mut self)

A poll found nothing: count it toward the reconcile cadence. VFS holds no SetTimer authority (see the allowlist), so the cadence counts empty polls instead of wall time; requests reconcile only the caller’s own reservations (dir_admission::admit).
