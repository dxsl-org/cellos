Expand description

Publish bytes at a service-owned dst (the SSH host-trust store) through the same staging, read-back seal and conditional publication (publish_if against expect) as a caller’s save. It runs on the service’s own authority: no caller access rule or quota applies, the destination’s own bounds do. Unpublished staging is removed.
