Module save

Expand description

D03 conditional save: a bounded table of staging transactions and the requests that drive them (Observe, SaveBegin … SaveAbort).

A transaction stages bytes in a backend-owned object, seals them (exact length and SHA-256 read back from storage, then the object’s identity), and publishes them at the destination named at SaveBegin only if that destination still matches the caller’s observation. The first commit’s outcome is recorded; a repeated commit or a query answers it and never runs the publication again.
