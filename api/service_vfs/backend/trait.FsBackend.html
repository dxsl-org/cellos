Expand description

Send bound (Law 7): backends live inside the GLOBAL_VFS static Mutex, which requires its contents to be Send for the static to be Sync.

Source

fn get_file_ptr(&self, path: &str) -> Option<(usize, usize)>

SAS zero-copy pointer to the file’s bytes. Only in-memory backends return Some — pointers must stay valid while the VFS cell lives. Disk backends return None; callers fall back to the copy path.

Source

fn list(&self, path: &str, out: &mut [u8]) -> usize

List directory entries as d:name\n / f:name\n lines into out. Returns bytes written; 0 when the path is missing or not a directory.

Source

fn list_page(&self, path: &str, start: u32, out: &mut [u8]) -> Option<ListPage>

Page the entries of directory path into out, starting at entry index start (see fill_page). Entry order is the backend’s own and must be stable while the directory is unchanged.

None when path is missing or not a directory, iteration failed, a name is not a valid component, or start is stale. Never a silent stop.

Source

fn stat(&self, path: &str) -> Option<(u64, bool)>

(size, is_dir), or None when the path does not exist.

Source

fn file_size(&self, path: &str) -> u64

File size for quota accounting. 0 when absent (callers charge net delta).

fn read_to_vec(&self, path: &str) -> Vec<u8>

Whole-file copy for the async-read handle table. Empty when absent.
