Expand description

Send bound (Law 7): backends live inside the GLOBAL_VFS static Mutex, which requires its contents to be Send for the static to be Sync.

fn list(&self, path: &str, out: &mut [u8]) -> Result<usize, FsError>

List directory entries as d:name\n / f:name\n lines into out. Returns bytes written (0 for an empty directory); an error when the path is missing, not a directory, or the listing could not be read.

Source

fn list_page( &self, path: &str, start: u32, out: &mut [u8], ) -> Result<ListPage, FsError>

Page the entries of directory path into out, starting at entry index start (see fill_page). Entry order is the backend’s own and must be stable while the directory is unchanged.

An error when path is missing or not a directory, iteration failed, a name is not a valid component, or start is stale. Never a silent stop.

Source

fn stat(&self, path: &str) -> Result<Option<(u64, bool)>, FsError>

Ok(Some((size, is_dir))), Ok(None) when the path does not exist, an error when existence could not be determined.

Source

fn file_size(&self, path: &str) -> Result<u64, FsError>

File size for quota accounting. NotFound when absent (callers charge net delta and treat that as 0).

Source

fn read_to_vec(&self, path: &str) -> Result<Vec<u8>, FsError>

Whole-file copy for the async-read handle table. A device failure part way through is an error, never the bytes read so far.

Source

fn write(&mut self, path: &str, content: &[u8]) -> Result<(), FsError>

Create-or-truncate write. Authorization is the dispatcher’s job (AccessTable); backends may still enforce structural rules.
