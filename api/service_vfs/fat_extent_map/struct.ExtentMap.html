pub(crate) fn build( extents: impl IntoIterator<Item = (u64, u64)>, ) -> Option<Self>

Merge (volume offset, length) extents in file order, up to the first zero-length one; None when the file is more fragmented than MAX_RUNS. fatfs File::extents walks the whole cluster chain and yields zero-length extents past the file’s size, forever on a chain that loops, so the size is what bounds the walk.
