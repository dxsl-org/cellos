Module fat_extent_map 

Source
Expand description

Where a FAT file’s bytes live on the volume, cached per file.

fatfs seeks by walking the cluster chain from the file’s first cluster on every seek (rust-fatfs File::seek), and the backend opens and seeks the file once per read: a read near the end of a 250 MB image walks ~60 000 FAT entries before it moves a byte. An ExtentMap walks the chain once and merges contiguous clusters into runs, so a later read maps its offset with a binary search and reads the device directly.

Invariant: a map is valid while its file’s cluster chain is unchanged. A write past a file’s mapped size can extend its chain, so the backend drops that file’s map; a removal or truncation frees clusters another file may reuse, so it drops every map.
