Module block_stream 

Source
Expand description

fatfs block streams over one block device of the VFS device table.

Two types are exported:

  • BlockStream: raw sector I/O, no caching. Used internally by PageCache.
  • CachedBlockStream: wraps BlockStream + PageCache; implement all fatfs traits. VFS mounts FAT32 through this type.

Every sector goes through blk_router to the stream’s own DeviceRef; a flush flushes only that device.
