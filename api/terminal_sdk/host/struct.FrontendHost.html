Struct FrontendHost

pub struct FrontendHost { /* private fields */ }
Expand description

Frontend host: one holder operation with the two output rings, at most one shell (and its frontend) at a time.

pub fn open(rows: u16, cols: u16) -> Result<Self, Status>

Create the holder operation and the output rings for a rows×cols terminal. Nothing is registered or launched yet.

Source

pub fn launch( &mut self, path: &str, argv: &[&str], environment: &[(&str, &str)], ) -> Result<(), Status>

Register a frontend and launch path (the shell) bound to it, under a fresh shell operation. One live shell per host: a previous shell must have been observed exited (Self::poll_child); its operation is released first. The shell starts without a cwd grant (a cwd grant would path-seal it).

One QueryFrontend; caches the attachment and the current resume capability.

Poll until the shell attached this frontend. Revoked when the frontend closed or was lost, Eof when the shell ended before attaching, TimedOut after timeout_ms.

pub fn poll_child(&mut self) -> Result<ChildPoll, Status>

The shell’s kernel terminal record (QueryChild, preparer only). Exited also when nothing was launched. Output written before the exit stays drainable.

Source

pub fn exit_code(&self) -> Option<i32>

Exit code of a shell that ended by itself; None while running, when cancelled or faulted, or before Self::poll_child observed the exit.

Source

pub fn cancel_child(&mut self) -> Result<(), Status>

Cancel the live shell’s operation. The exit is then observed by Self::poll_child.

Source

pub fn release(&mut self) -> Result<(), Status>

Detach this frontend (ReleaseFrontend). The shell keeps its session (Detached, Lost(4) to its reader); Self::reattach resumes it while this host lives.

Source

pub fn reattach(&mut self, rows: u16, cols: u16) -> Result<(), Status>

Register a fresh frontend of rows×cols and resume the Detached session with the holder-bound resume capability. The old attachment stays stale; the owner reissues resume, read back with QueryFrontend.

Source

pub fn close(&mut self) -> Result<(), Status>

Idempotent: cancels a live shell (bounded reaping), releases its operation, then the holder operation (the output rings with it).
