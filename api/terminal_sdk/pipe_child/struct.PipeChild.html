Struct PipeChild

pub struct PipeChild { /* private fields */ }
Expand description

A committed pipeline stage. Keep it alive until the stage is reaped and drop it before closing its stage Operation: it keeps a dynamically admitted cwd directory open, and dropping it lets VFS settle the child’s cwd receipt.

pub fn query(&self) -> Result<ChildStatus, Status>

One QueryChild (non-mutating, idempotent): the kernel’s current record of this child. Only the preparer may ask, and only until the pipeline Operation is closed. Kernel refusals surface as their own status (WrongOwner, Stale); a reply that is not exactly header plus 24 bytes is Malformed.

Source

pub fn wait(&self) -> Result<i32, Status>

Wait until the kernel’s terminal record of the child exists and return its exit code. Polls PipeChild::query (a few yields, then one-tick sleeps) while the child is live or retiring, for at most 30 seconds. Never guesses: Status::TimedOut when the budget ends first (the child may still run, so cancel the pipeline operation if it must stop), Status::Unsupported when the clock is unavailable, Stale/WrongOwner/other kernel statuses as reported. Transient WouldBlock/TimedOut answers are polled again. Idempotent: the record stays readable until the operation is closed.

Source

pub fn wait_status(&self) -> Result<ChildStatus, Status>

PipeChild::wait returning the whole terminal record: reason is nonzero when the kernel stopped the child (a cancelled Operation) instead of the child exiting by itself, and exit_code is then meaningless.
