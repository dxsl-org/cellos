pub fn close(self) -> Result<(), Status>

Release every Operation, children before parents, then the root (bounded retry on WouldBlock; correlation lanes are retired on success and on giving up). Drop every reaped PipeChild first: VFS settles a stage’s cwd receipt, which its Operation’s release waits for, only when the owner contacts it. The first failure is returned after every release was attempted.

Source

pub fn spawn( &self, stage: usize, spec: &PipeSpec<'_>, stdin: Option<Endpoint>, stdout: Endpoint, stderr: Endpoint, ) -> Result<PipeChild, Status>

Prepare and commit one child in stage Operation stage whose fd0/fd1/fd2 are delegated copies of the given endpoints (stdin with reader rights, stdout/stderr with writer rights). None for stdin gives the child an empty stream: its first read sees end of file.

The caller keeps its own endpoint copies and must close them; this never closes a caller endpoint. Failure before commit publishes nothing (the prepared child is aborted and every endpoint made here is closed). A failure at or after commit may have published a child, so it cancels the stage Operation (reason 5, the spawn_foreground reason) and returns the error; the Operation itself is released by Pipeline::close.
