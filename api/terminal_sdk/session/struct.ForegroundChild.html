pub fn read_completion(&self, out: &mut [u8]) -> Result<usize, Status>

Nonblocking drain of the child’s completion stream (see TerminalSession::spawn_foreground_with_completion): copies everything currently buffered, up to out.len(), and returns the byte count. Nothing buffered, writer end-of-stream, and a child spawned without a completion stream all read as Ok(0); only real stream errors fail. Read before TerminalSession::close_foreground, which releases the stream with the child operation.

Source

pub fn wait_status(&self) -> Result<ChildStatus, Status>

The kernel’s terminal record of this child (bounded QueryChild poll, preparer only, readable until TerminalSession::close_foreground). Unlike a TID wait it cannot miss a child that was already reaped.
