Module raw_input 

Source
Expand description

Raw-mode input for an interactive shell that is itself a session’s foreground child.

In canonical mode the input owner turns Ctrl-C into a cancellation of the committed foreground child’s Operation and emits no Interrupt event. A shell that runs as that child would therefore be cancelled by every Ctrl-C. A shell that holds the raw-mode lease receives Ctrl-C as the byte 0x03 on stdin instead, and decides for itself what to stop. RawInput is the SDK’s persistent form of that lease plus an event source that gives the shell the same Event stream the canonical path produces:

  • printable input -> Text; Enter/Backspace/arrows/… -> Key;
  • Ctrl-C (0x03) -> Interrupt;
  • a bracketed paste (the lease also requests the bracketed-paste bit) -> PasteBegin, one Text with the whole paste, PasteEnd, so pasted newlines stay inert text;
  • resize / end-of-input arrive on the control endpoint exactly as in canonical mode;
  • stdin end of file -> Eof; an undecodable sequence -> Lost.

No input-service change is involved: the lease is an ordinary SetMode the foreground reader is allowed to take, and it is restored by the owner if the holder dies.
