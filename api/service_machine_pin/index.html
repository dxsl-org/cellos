Source
Expand description

The ADR-0029 machine-pin Cell (Phase 13: the endpoint left init).

Trusted init launches /bin/machine-pin right after the VFS on x86 and registers it as MACHINE_PIN; the kernel accepts that registration only for init’s own child signed as machine-pin, and answers the machine facts (433) only to that live provider. The Cell runs the gate once, then serves MachinePinRequest frames: init asks Gate as a client and withholds the services itself; the console shell asks Status and Confirm.
