Machine pin gate (ADR-0029 §3, Phase 13 amendment).

Once trusted init has registered this Cell as MACHINE_PIN, the gate compares the kernel’s machine facts (syscall 433, answered only to the live provider) with the record stored at /srv/.cellos-machine/pin:

  • no record on a healthy store: first boot, record and continue;
  • the same bytes: continue;
  • anything else: print the field-level difference and decide safe mode.

The pin carries no authority. It never changes a profile, driver gate or DMA decision; safe mode only withholds services, and init does the withholding after asking this Cell (MachinePinRequest::Gate).
