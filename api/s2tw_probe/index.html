Crate s2tw_probe 

Source
Expand description

Private Phase04 S2-T/S2-W fixture (phase-04-s2tw-annex.md §6). One binary is packaged at a sandbox path (/data/bin/s2tw-probe, EMPTY launch ceiling) and at a private /bin/s2tw-probe fixture row (CapSet::LEGACY_OBSERVE_MUTATE); the output must differ only because of the path it was launched from.

It declares GetProcs, GetProcs2, TelemetrySnapshot, MemInfo and VfsMutate, tries each right once and writes, to its delegated stdout (the shell’s host stream, never the UART):

S2TW getprocs <r>
S2TW getprocs2 <r>
S2TW telemetry <r>
S2TW meminfo <r>
S2TW vfs-write <r>
S2TW DONE

<r> is denied for a refusal and other:<detail> for anything else:

  • telemetry: the syscall ABI encodes every refusal as the one generic error sentinel, and each call passes a valid, non-empty buffer, so an error return is the dispatch gate (check_allowlist) refusing it. telemetry is the Phase 06 S6-1 TelemetrySnapshot (X right, shared bit 55); an admitted snapshot must also decode, or it reads other:malformed-<why>;
  • vfs-write: WriteAt of /tmp/s2tw-probe-<tag> through the cwd directory handle the shell delegated, answered Err(ERR_DENIED) by the VFS. <tag> is the first argument (x when absent). The handle route keeps the request reachable for this path-sealed child, so the only denial left is the missing attested CALLER_FLAG_VFS_MUTATE.

With the first argument trunc it instead makes one capture with task rows requested into a 192-byte buffer (room for the header and one Cell row only) and writes one line, S2TW telemetry-trunc <r>: other:cells-E/T-tasks-e/U-complete-C counts the whole rows TelemetrySnapshot::parse decoded (E Cells, e tasks) against the header totals (T, U) with the COMPLETE flag (C = 1 or 0); denied or other:<detail> otherwise. On any multi-Cell system it is the provider reporting truncation explicitly (Phase 06 S6-5, D65-8 T-a).

Exit statuses: 0 every line written; 2 missing stdout grant or bad tag; 3 stdout failure. Nothing is retried. Never part of an ordinary image.
