Crate apple_rtkit 

Source
Expand description

Apple RTKit protocol, mailbox message packing, SART window management, and partition protection.

Provides the communication layer for Apple Silicon coprocessors (ANS2 storage, SMC, DCP) reached through the ASC mailbox interface (Phase 06, ADR-0032 §5).

Clean-room implementation referencing OpenBSD aplrtk.c, aplmbox.c, and aplsart.c (ISC).
