Crate dom_arena 

Source
Expand description

Gosub-style Arena-backed DOM tree, NodeId model, and JS Engine Abstraction.

Provides a safe, pointer-free DOM representation using continuous NodeId indices, batched DOM mutations for cross-tier IPC, and an engine-agnostic JsEngine trait.
