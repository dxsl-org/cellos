Syntax-highlighting roles and the per-palette colours that paint them. Code spans carry the role tags below (the Dark palette’s values); [CodePalette::resolve] maps them onto the document palette at paint time, so open code re-tints whenever the reader or system palette changes.
ink
Semantic text roles the document parsers stamp on spans. The values are tags, not paint: ink::resolve maps them to the painting theme, so a parsed document re-tints whenever the reader or system palette changes.
