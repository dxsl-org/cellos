Extensible service interface contracts.

Add new service traits, IPC message types, and driver abstractions here. Adding a new sub-module does not require a kernel recompile and does not require 2× confirmation — only changes to the abi crate do.

The contracts the kernel itself speaks (fs, block, IPC_BUF_SIZE, REACTOR_WAKE_OPCODE, the App SDK envelope, the power-button request and input producer frames) live in abi and are re-exported here at their service-contract paths.
