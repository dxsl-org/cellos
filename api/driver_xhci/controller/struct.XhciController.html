fn wr64(&self, off: usize, value: u64) -> ViResult<()>

Write a 64-bit register as two 32-bit halves, low dword first.

xHCI’s 64-bit registers take their side effect on the high dword write — CRCR initializes the command ring, ERSTBA the event ring — and the controller model dispatches an 8-byte access to the low-dword case only (qemu-xhci’s xhci_oper_write/xhci_runtime_write). Writing the halves explicitly is both model-correct and hardware-safe.
