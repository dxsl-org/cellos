Module irq 

Source
Expand description

MSI-X event-ring wake-ups (x86 phase 04b, CP1 cp1-04b-waitcompletion-irq.md §7).

Contract: an interrupt is only ever a hint to re-read the event ring. Every park is bounded by PARK_TICKS and every return re-reads the ring, so a lost, masked or revoked interrupt degrades to slow polling inside the wait’s own budget and never to a hang. A refusal by AllocPcieIrq (435) or by WaitCompletion(IRQ) (242) keeps the polled path and says why.
