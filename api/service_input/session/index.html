retained 🔒
The record an outcome retains for request. A secret-bearing request is sealed at the moment it is consumed: only the SHA-256 of the exact record is kept, never its plaintext, not even while the request executes (the body is read from the receive buffer, which the caller wipes). The digest still lets an identical re-send resolve to the retained (or pending) outcome and a changed body under the same ID be refused (annex: Malformed).
secret_bearing 🔒
Selectors whose request body can carry typed or raw secrets (SubmitEvents, WritePaste, SubmitRaw). Their results are only a sequence/count, so nothing beyond the status is ever replayable.
