Frontend kind (fe::FRONTEND_KIND_*), reported by QueryCapabilities.

§holder: Option<PrincipalV1>

Sel-25 sessions only: the frontend holder that owns resume, and the registered operation of its current (or last) frontend: holder liveness and request lane.

§holder_operation: ObjectRefV1§frontend: Option<ObjectRefV1>

The frontend record currently attached (sel 25/28).

§resume: ObjectRefV1

Holder-bound re-attach capability; ZERO once revoked.

§detached: bool

The frontend detached: the reader keeps its lease and input waits (no EOF).

§orphaned: bool

The holder died: no frontend can return; the reader gets Lost(4), then EOF.

§capture: Option<Capture>

Owner-run first-trust capture (sel 30): while set, the session’s typed, raw and paste input is consumed by input and never routed to the reader.

§notices: VecDeque<Event>

Owner notices (TrustPrompt/TrustPromptEnd) for the controller’s own control ring.
