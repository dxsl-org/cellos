fn release_quarantine(&mut self, i: usize)

Routing returns to the child. Every incremental input state that could still carry bytes typed during the quarantine is wiped first, so no partial sequence (escape, UTF-8, paste staging) completes afterwards: the capture line, any paste staging and the serial decoder.

fn armed(&mut self, i: usize) -> bool

Is the capture accepting an answer now? A passed deadline first ends it expired. While arming or ending (or with no capture) the caller drops the input.

Source

fn capture_item(&mut self, i: usize, item: Typed<'_>) -> bool

Source

pub(super) fn capture_events( &mut self, i: usize, bytes: &[u8], count: usize, ) -> Result<(), Status>

SubmitEvents / physical keys / decoded UART during a capture: the batch is validated exactly as routed input, then consumed here. It answers only while armed; whatever follows the deciding item, and everything while arming or ending, is dropped.

Source

pub(super) fn capture_raw(&mut self, i: usize)

SubmitRaw during a capture. Raw bytes carry no key/paste provenance, so they never answer: while armed they reject, otherwise they are dropped. Never routed.

Source

pub(super) fn refuse_paste(&mut self, i: usize) -> bool

Any paste during a capture is refused; while armed it also rejects the capture.

Source

pub(super) fn maintain_trust(&mut self)

Deadlines: expire captures and pending records; release uncollected final records.

Source

pub(super) fn drain_notices(&mut self, i: usize)

Write queued owner notices to the controller’s own control ring.
