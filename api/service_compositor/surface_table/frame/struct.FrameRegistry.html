pub fn create_view( &mut self, req: &CreateViewRequest, caller_tid: usize, surface_cap: u64, ) -> Result<ViewOpResponse, ViewOpResult>

Allocate a new view and optionally attach it to an existing or new frame.

Only the frame’s sole owner may add a view to it; a frame shared by several apps refuses everyone. A minimum size larger than the requested size is refused, so no frame carries an unsatisfiable minimum.
