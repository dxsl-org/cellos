service_compositor::stacking

Module closing 

Source
Expand description

Closing tabs of a stack: the shown tab hands over to its neighbour, and “Close all tabs” asks each tab in turn.

Functions§

advance_close
Ask the next queued tab of frame that is still open: it is shown, then asked, and the tab beside it is shown while it answers. Tabs that cannot be asked are skipped. Returns the area to repaint.
ask_to_close
Ask the owner of cap to close it (it may refuse). The window leaves the screen while asked. Returns the area to repaint, or None when it could not be asked (already closing, being configured, or undeliverable).
close_all
“Close all tabs” of the stack showing cap: queue every tab in tab order and ask the first. Each further tab is asked once the one before answered (advance_close), so every owner decides about its own tab.
show_next
The shown tab cap just started closing: show the live tab beside it (after it, else before it). Returns that tab and the area to repaint.
