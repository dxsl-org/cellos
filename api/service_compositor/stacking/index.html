Module stacking 

Source
Expand description

Stack glue between the frame registry, the surface table and z-order.

A frame (stack of Cell Tabs) has no geometry of its own: its shown window is the frame. Every other member sits at the shown window’s origin, hidden (SurfaceState::set_behind_tab) but still Normal, so the reconciler can configure it to the shown window’s size and state one request at a time. This module is the only writer of the behind-tab flag.

detach
Pull the shown window cap out of its stack into a window of its own, at at or else a little below and right of where it was, kept on the screen. The stack shows the tab beside it in its place. Returns the area to repaint.

Forget the window cap, which is about to be removed from the table. When it was the shown tab, the tab beside it is shown instead. When it was the tab “Close all tabs” was waiting on (closing, unanswered), the next queued tab is asked now.

select
Show the window cap in its frame because the user picked its tab. It takes the previous window’s place in z-order and is asked to take its size and state. Returns the screen area to repaint.
