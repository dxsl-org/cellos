Module stack_drag 

Source
Expand description

Haiku’s tab gestures. Win (Meta, Haiku’s Option key) + drag of a tab: drop it on another window’s tabs to stack it there, next to another window’s edge to tile it there, anywhere else to pull it out of its stack and tile group (or just move a lone window). Shift + drag of a lone tab slides it along the frame’s top edge.
