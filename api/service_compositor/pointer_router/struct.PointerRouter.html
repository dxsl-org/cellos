Expand description

Tracks keyboard focus, selected decoration, pointer capture, hover and the window menu.

Fields§

§focused_owner: usize§selected_cap: Option<u64>§capture: Option<Capture>§menu: Option<OpenMenu>§last_title_press: Option<(u64, u64, i32, i32)>

Last title press (cap, ms, x, y), for double-click detection.

§hover: Option<MenuButtonHover>§stale: Option<Rect>

Screen area left stale by a menu closed without a damage sink (its window went away); taken by the main loop.

§modifiers: Modifiers

Modifier keys held, as of the last key event (Win/Shift tab drags).

§feedback: Option<DragFeedback>

Ghost and target of a Win+drag in progress.
