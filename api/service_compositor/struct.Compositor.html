Expand description

The compositor’s state between receives, served by [serve].

Fields§

Surfaces and views are keyed by the creating thread tid, while a death names the Cell incarnation: the threads that created state for each owner.

pub(crate) fn record_creator(&mut self, owner: Owner, tid: usize)

Remember that tid creates state on behalf of owner, so its death reclaims it. Mirrors what serve can watch: never the kernel’s own identity, at most owner_watch::MAX_WATCHED_CELLS owners and owner_watch::MAX_TIDS_PER_CELL tids each; beyond that the state is served but not reclaimed on death.

fn on_unattributed(&mut self, _sender: usize, _payload: &[u8])

A message without a valid identity trailer that is no watched owner’s death: sender 0 is the kernel, other senders are raw producers. Dropped by default.
Source§

fn on_empty_poll(&mut self)

A Wait::Poll found nothing queued: park the way the service needs (a completion wait on its device), bounded below half the heartbeat. Yields by default.
Source§

fn on_snapshot(&mut self) -> Option<Vec<u8>>

The supervisor is swapping this service out: the state its replacement restores, stashed by serve under the swap’s key. None carries nothing, so the replacement never signals Ready and the swap rolls back. Off by default.
Source§

fn on_restore(&mut self, _state: &[u8]) -> bool

This incarnation is the replacement: apply state, the bytes the previous incarnation’s Handler::on_snapshot returned. true makes serve release the stash and signal Ready (sys_hotswap_ready); false leaves the supervisor to roll back. Off by default.
