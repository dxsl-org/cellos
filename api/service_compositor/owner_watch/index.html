Module owner_watch 

Source
Expand description

Owner-death reclaim for the compositor: which cells own windows, and what the receive loop does when the kernel reports one of them dead.

Everything here is syscall-free so the host test target can exercise it (ostd syscalls are real Linux syscalls on the host). main.rs supplies the two kernel calls through WatchSys.

Surfaces and views are keyed by the creating thread tid, while the kernel reports the death of the cell root tid. A watched cell therefore carries the set of thread tids that created state on its behalf; the death reclaims every one of them. A cell is watched from its first CREATE_SURFACE or CREATE_VIEW, since no other request creates owned state.
