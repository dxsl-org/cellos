Module owner_watch 

Source
Expand description

Owner-death reclaim for the compositor: which requests create owned state, and what the compositor removes when the owning cell dies.

The death watch itself lives in ostd::service::owners: serve watches a caller’s cell while serving its first CREATE_SURFACE or CREATE_VIEW (no other request creates owned state), and reports its death, or its retirement by a newer generation of the same CellId, through Handler::on_owner_death.

Surfaces and views are keyed by the creating thread tid, while a death names the cell incarnation. The compositor therefore records the thread tids that created state on each owner’s behalf; the death reclaims every one.

Syscall-free so the host test target can exercise it (ostd syscalls are real Linux syscalls on the host).
