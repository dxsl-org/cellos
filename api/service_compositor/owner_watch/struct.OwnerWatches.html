pub(crate) fn admit( &mut self, identity: &CallerIdentity, sender: usize, sys: &mut impl WatchSys, ) -> Admission

Record that sender (a thread of identity’s cell) is about to create owned state, subscribing to the cell’s death on first sight. Must run before the request is dispatched: the kernel only grants the watch while the cell’s message is the one being served.

A refused watch never denies the request: without it a dead client’s windows are simply not reclaimed, which is the behaviour before the watch existed. The next create from the cell retries.

Source

pub(crate) fn take_death(&mut self, root_tid: usize) -> Option<Released>

The watched cell whose root tid is root_tid, removed (the kernel consumed its token with the death). A worker tid, 0 or an unwatched root never matches.
