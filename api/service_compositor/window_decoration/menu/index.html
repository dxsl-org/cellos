Module menu 

Source
Expand description

Window menu: the compositor-owned popup opened from a Cell Tab’s app icon.

Items come in sections, a hairline between them: the window’s own actions, closing (always the third row, where the hand expects it), then grouping (stack onto a nearby window, detach this tab, untile). Which items show depends on the frame; nothing unavailable shows.
