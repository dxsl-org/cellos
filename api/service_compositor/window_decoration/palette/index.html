Chrome colours per system palette (CellOS Linear, contracts.md “Appearance”).

The tab and frame copy Haiku’s geometry, not its colours: every value here derives from the CellOS Light / Dark / Paper tokens. Hairlines sit a step darker (lighter on Dark) than the border token so a window separates from any wallpaper; tab text keeps >= 4.5:1 and control glyphs >= 3:1 (WCAG non-text contrast) against their background in every state.
