Module tiling 

Source
Expand description

Tile groups on screen: frames glued edge to edge move, raise and hide together, and the edge two of them share resizes both (Haiku’s Stack & Tile). The registry knows only which frames are glued along which side; every edge is read off the windows’ own geometry, so the shared edges are the “tabstops” of the group and cannot drift from the windows.
