The Cell initial stack, v1 (CP1 cp1-cell-initial-stack-auxv.md, AX-2…AX-5).

The loader writes this block just below the top of every Cell’s root user stack and enters the Cell with sp at its first byte. Layout, low to high address, all words 64-bit little-endian:

sp →  argc = 0
      argv terminator (NULL)
      envp terminator (NULL)
      auxv pairs: AT_PHDR, AT_PHENT, AT_PHNUM, AT_PAGESZ, AT_BASE, AT_ENTRY,
                  [AT_RANDOM], then AT_NULL
      program-header copy (phnum × 56 bytes, 8-byte aligned)
      [16 entropy bytes]
      padding up to the stack top

sp is 16-byte aligned on every architecture. AT_PHDR and AT_RANDOM hold absolute addresses inside the block. AT_BASE carries the Cell’s load base (Cellos has no interpreter). Pointers are computed from top, so the block is position-dependent on the stack it is written to and nothing else.
