Directory capabilities, exercised from a cell’s own side.

This cell is the first to migrate, and it migrates completely: it acquires the directories it needs, works entirely through handles, and then gives up the ability to name a path at all. The last part is the point. Traversal assertions on the handle operations prove only that the new interface is tight; a cell can pass every one of them while still sending absolute paths through the old interface. The assertion that matters is the one after sealing, where a plain Write { path } comes back refused.

Runs last, because sealing is one-way and every scenario before it needs the path-string operations.
