httpd — minimal HTTP/1.0 file server for ViCell.

Usage: httpd <vfs_path>

Listens for TCP connections on . For each connection, reads the HTTP request (discards it), reads <vfs_path> fresh from VFS on every request (no caching), and responds with HTTP/1.0 200 OK + current file content. Returns HTTP 404 when the file is absent, and HTTP 200 with an empty body when the file exists but has zero length. Loops forever, serving one connection at a time.
