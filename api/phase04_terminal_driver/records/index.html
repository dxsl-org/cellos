Pure readers for the Phase 06 S6-5 top-load scenarios: top --records … | to jsonl envelope lines (top.cell.v1/top.task.v1 rows, Begin meta, End), the fixture’s TOPLOAD acknowledgement lines, the s2tw-probe trunc line, and the comparisons the scenarios make on them. Host-tested; nothing here touches a host or a syscall.

The JSON reader only looks up a key of one envelope line. Every key it is used with is unique within its line ("tasks": never matches "total_tasks":: the quote is part of the key), and no value it reads contains an escaped quote.
