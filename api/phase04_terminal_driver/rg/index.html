Expand description

Phase 07 S7-3 (phase-07-s3-proposal.md §7.2): fixture-free rg checks. Every check asserts structure (rows PATH:LINE:TEXT, <stdin> for standard input, escapes) and the $? status, never diagnostic wording. The trees live under /tmp (RamFS) and are built here with mkdir/echo >; the ESC bytes come from /bin/p03-filter tui-abandon redirected to a file (the shell has no printf and echo -e has no ESC escape), the CR from echo -e piped through /bin/p03-filter cat.
