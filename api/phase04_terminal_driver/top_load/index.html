Phase 06 S6-5 (phase-06-s5-proposal.md §4): top against a real multi-thread Cell under known load. The fixture /data/bin/top-load (EMPTY sandbox launch, DV-13) runs in the foreground of its own host shell (L1, L2); top runs in another (O); & is never used (D65-4 H1). The fixture is steered by typed lines and answers each with one TOPLOAD line once the effect holds (D65-5 C1); every check keys on those lines and on data (tids=, top --records rows, the grid model), never on wall-clock guesses. Every compared value is printed as P04 INFO top-load <marker> key=value … (D65-9).

Thresholds (D65-6, TCG with one vCPU): idle ≤ 20 tenths; one spinner: Cell ≥ 600, the spinner ≥ 80 % of its Cell’s task sum, the parent shell < 500; two spinners: each ≥ 250 and within 2× of each other; Σ Cells ≤ online_cpus × 1000 + Cells, ≥ 800 while busy.
