Struct Frame

pub struct Frame<'a> {
    s: &'a Screen,
    pub w: usize,
    pub h: usize,
}
Expand description

The drawn TUI area (w x h, top-left of the session): title bar row 0, status row 1, the bordered block rows 2..h-2 (table header row 3, data rows 4..h-3, highlight column x = 1..2), key hints row h-1.
