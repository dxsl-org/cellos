Crate phase04_terminal_driver 

Source
Expand description

Private Phase04 slice S3 driver. It links the same FrontendHost the GUI Terminal uses and drives a real cellbox sh through it: the shell controls its own GUI-kind session and this Cell is only its frontend (Phase 05 S5-3 annex option C; keyboard in via submit_* on the frontend attachment, bytes out via drain_* of the rings the shell relays to), printing P04 PASS|FAIL <name> observations. The host runner supplies the independent verdict from serial output. Not part of any ordinary image: init starts it only from the runner’s private autoload plan, and the kernel carries its -> /bin/cellbox launch edge only under phase04-driver-profile.

Secrets: the driver never reads, stores or prints any. Every typed command is a fixed script, the shells it launches get an empty environment, and a FAIL line carries only a status name or a short printable slice of the scripted (non-secret) transcript. The one token it types into read -s is a fixed fixture constant; that scenario’s FAIL lines carry statuses and counts only, so the runner can require the token absent from the UART.
