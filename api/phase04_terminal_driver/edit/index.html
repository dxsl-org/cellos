Phase 08 S8-5 (phase-08-s0-proposal.md §3.4): edit on the target through a real frontend host. Host t runs the editor; the main session a writes the concurrent changes and reads the stored bytes back. Every check judges stored bytes, the drawn status/message rows and $?, never exact wording beyond the stable fragments the editor prints for each outcome. Files live on the CellosFS /srv of the fixture disk (D03) and, for the refusal, on the FAT32 /mnt/sd.
