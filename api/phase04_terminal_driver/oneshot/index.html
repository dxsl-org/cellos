Phase 10 S10-0 (phase-10-s0-proposal.md §2 S10-0.8): /bin/cellbox <command> launched directly with a prepared context, as stock_negative_grants launches /bin/echo, on this fixture’s reviewed -> /bin/cellbox edge. Every one-shot payload carries the p04os- token, which the runner requires absent from the UART; FAIL lines print observed bytes as hex only.
