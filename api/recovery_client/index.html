recovery-client: the Phase 09B evidence driver. One shell command per group, each printing RECOVERY-CLIENT <group>: PASS or a FAIL line: recovery-client core E1–E7, E10, E6, E12, E11 (needs fault-inject cells) recovery-client foreign <id> E4 second principal recovery-client lease E8 (needs the recovery-fixture VFS) recovery-client export E9 (terminal: the provider stays down)

Modules§

common 🔒
IPC and timing helpers shared by the three recovery-demo Cells; each Cell uses a subset.
cycles 🔒
E6 restore refusal (RecoveryFailed, no Ready), E11 identity across replacements, and E12 ten crash/restore cycles with resource reconciliation.
driver 🔒
Client-side calls. Results are what a consumer observes: worker replies, service lookups, the authority’s status and the kernel verdict it relays.
extra 🔒
Separate client invocations: E4 foreign principal, E8 missing borrower acknowledgement (needs the recovery-fixture VFS), E9 untracked export (terminal for the boot: the provider then needs node recovery).
faults 🔒
E1–E5, E7 and E10: crash points around the commit, conflicting bindings, a fenced live writer, whole-Cell retirement and an abandoned lock word.
