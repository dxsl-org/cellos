IPC and timing helpers shared by the three recovery-demo Cells; each Cell uses a subset.

A request expecting an answer is one exact operation (call, call_raw); its answer goes back through the Incoming captured when the request was received (reply). One-way messages are posted.

Structs§

Received
One received frame. identity is the kernel-written trailer; None means the kernel attested no live sender (a death notification or a forgery).
