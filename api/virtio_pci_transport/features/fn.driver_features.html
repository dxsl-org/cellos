pub fn driver_features(
    device: u64,
    requested: u64,
    policy: AccessPlatform,
) -> Result<u64, InitFailure>
Expand description

The feature word the driver writes, given what the device offers, what the device-specific driver asked for, and the access-platform policy.

Returns requested restricted to device (a driver must never accept an unoffered feature), plus VERSION_1, plus ACCESS_PLATFORM when the device offers it.

§Errors

InitFailure::Version1NotOffered when device lacks VERSION_1; InitFailure::AccessPlatformMissing when policy is AccessPlatform::Required and device lacks ACCESS_PLATFORM.
