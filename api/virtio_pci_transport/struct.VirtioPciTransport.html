Expand description

Virtio 1.x PCI transport for a function described by a 434 record.

Interrupts are never routed: msix_config and every queue vector are set to crate::NO_VECTOR, so drivers poll.

pub fn new( record: &ViPcieFunctionV1, mapper: &mut impl BarMapper, policy: AccessPlatform, ) -> Result<Self, TransportError>

Builds a transport for the function record describes.

Maps each BAR that holds a virtio structure exactly once through mapper, then resets the device and waits (bounded by crate::RESET_SPIN_BUDGET) for the reset to complete: a previous owner may have left it running on stale rings, and it must be quiesced before this cell’s DMA grant re-enables bus mastering. Finally reads the device’s upper feature word to enforce policy.

§Errors

Identity errors from crate::device_type_for, capability errors from crate::parse_caps, TransportError::MapFailed, TransportError::MisalignedRegion (common/device structures need 4-byte alignment, notify 2-byte), TransportError::ResetFailed, and TransportError::AccessPlatformMissing.

fn write_driver_features(&mut self, driver_features_requested: u64)

Writes driver_features amended by crate::features::driver_features (re-reading the device’s offer, checked against the construction-time crate::AccessPlatform policy). On InitFailure::Version1NotOffered or InitFailure::AccessPlatformMissing nothing is written and the failure is recorded, which turns the following FEATURES_OK write into FAILED.

fn notify(&mut self, queue: u16)

Writes queue to the queue’s notify address. Nothing is written while a failure is recorded, nor for queues whose notify address lies outside the notify region (their queue_set recorded InitFailure::NotifyOutOfRange).

Source§

fn set_status(&mut self, status: DeviceStatus)

Writing an empty status resets the device and waits, bounded by crate::RESET_SPIN_BUDGET, for the reset to complete (spec: before reinitialising, device_status must read 0). A completed reset clears any recorded failure and the notify cache; one that never completes (or reads the device as gone) records InitFailure::ResetFailed. After a failure every other write becomes FAILED. A FEATURES_OK write is read back: a cleared bit records InitFailure::FeaturesRejected; an accepted one routes the configuration-change interrupt to NO_VECTOR.

Source§

fn queue_set( &mut self, queue: u16, size: u32, descriptors: PhysAddr, driver_area: PhysAddr, device_area: PhysAddr, )

Programs and enables the queue with interrupts disabled (NO_VECTOR) and caches its notify offset. While a failure is recorded the queue is left untouched. A queue whose notify address falls outside the notify region is neither programmed nor enabled, and InitFailure::NotifyOutOfRange is recorded.
