pub fn device_type_for(

    device_id: u16,
) -> Result<DeviceType, TransportError>
Expand description

Maps a PCI function’s IDs to the virtio device type its driver serves.

Transitional IDs are accepted because transitional devices also expose the modern capabilities; whether they do is checked by crate::parse_caps.

§Errors

TransportError::InvalidVendor unless vendor_id is VIRTIO_VENDOR_ID; TransportError::UnknownDevice for IDs outside both ranges, unassigned transitional IDs, and modern IDs whose virtio type the driver library does not define.
