2//! Frozen kernel ABI — stable contract between kernel and Cells.
3//!
4//! ⚠️ **FROZEN** — every item here is part of the stable ABI between the Cellos
5//! kernel and Cells.  Changes force a full kernel recompile and require
6//! **2× explicit user confirmation**.  See `docs/specs/15-kernel-boundary.md`.
7//!
8//! Rules:
9//! - Never remove or rename existing items.
10//! - Never change `repr`, discriminant values, or field layouts.
11//! - Only add at new explicit discriminant/offset values.
12//! - Even additions require 2× confirmation (they change the build contract).
13//!
14//! Besides the syscall ABI, this crate owns the service contracts the kernel
15//! speaks itself (`fs`, `block`, `kernel_ipc`, `app_envelope`,
16//! `supervisor_power`, `input_producer`); `wire` re-exports them at their
17//! service-contract paths.
