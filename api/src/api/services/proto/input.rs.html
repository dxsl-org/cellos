2//! Input wires: producer frames into the input service, the event delivered
3//! to the focused cell, and input → producer control frames.
4//!
5//! Producer frame: `[kind][code u32 LE][value i32 LE]`, 9 B, from the kernel
6//! (sender 0), the UART relay or a registered producer. `EV_DEVICE` frames
7//! carry a device id first: `[EV_DEVICE][device u32][kind][code u32][value i32]`.
8//! These `EV_*` kinds are not the Linux evdev types of
9//! [`crate::services::vmm_session`] (there `EV_KEY` is 1).
