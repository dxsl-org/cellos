1//! `vigrep`: ripgrep's search components for Cellos, as `no_std` + `alloc`.
2//!
3//! This crate is an adaptation of five crates from ripgrep 15.2.0
4//! (commit `e89fff89ac9af12e8d4ce9d5fd07beb408ca730f`, MIT chosen from
5//! `Unlicense OR MIT`, copyright (c) 2015 Andrew Gallant) plus a serial
6//! walker written for Cellos. The `std` boundary of the upstream crates is
7//! replaced by [`io`] (a core-only reader) and by byte paths; nothing here
8//! touches a filesystem, the environment, threads or memory maps.
9//!
10//! # Upstream → module mapping
11//!
12//! | Upstream crate (version) | Upstream files | Module |
13//! |---|---|---|
14//! | grep-matcher 0.1.9 | `src/{lib,interpolate}.rs` | [`matcher`] |
15//! | grep-regex 0.1.14 | `src/{lib,ast,ban,config,error,literal,matcher,non_matching,strip}.rs` | [`regex`] |
16//! | grep-searcher 0.1.17 | `src/{lib,macros,line_buffer,lines,sink}.rs`, `src/searcher/{mod,core,glue}.rs` | [`searcher`] |
17//! | globset 0.4.19 | `src/{lib,glob,pathutil,fnv}.rs` | [`glob`] |
18//! | ignore 0.4.29 | `src/{gitignore,overrides,pathutil}.rs`, error types of `src/lib.rs`, precedence logic of `src/dir.rs` | [`ignore`] |
19//! | — (Cellos) | — | [`io`], [`walk`] |
20//!
21//! Dropped upstream code: `searcher/src/searcher/mmap.rs`, encoding/BOM
22//! transcoding and the path/file entry points of the searcher; globset's
23//! serde support; ignore's `walk.rs`, `types.rs`, `default_types.rs`, global
24//! and git-exclude discovery, repository detection and environment lookups.
25//! The per-file upstream SHA-256 values are listed in `PROVENANCE`.
26//!
27//! # Host tests
28//!
29//! The workspace pins a bare-metal default target, so run
30//! `cargo test -p vigrep --target x86_64-unknown-linux-gnu`.
31
32#![cfg_attr(not(test), no_std)]
33#![forbid(unsafe_code)]
