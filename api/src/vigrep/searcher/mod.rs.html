6/*!
7This crate provides an implementation of line oriented search, with optional
8support for multi-line search.
9
10# Brief overview
11
12The principle type in this crate is a [`Searcher`], which can be configured
13and built by a [`SearcherBuilder`]. A `Searcher` is responsible for reading
14bytes from a source (e.g., a file), executing a search of those bytes using
15a `Matcher` (e.g., a regex) and then reporting the results of that search to
16a [`Sink`] (e.g., stdout). The `Searcher` itself is principally responsible
17for managing the consumption of bytes from a source and applying a `Matcher`
18over those bytes in an efficient way. The `Searcher` is also responsible for
19inverting a search, counting lines, reporting contextual lines, detecting
20binary data and even deciding whether or not to use memory maps.
21
22A `Matcher` (which is defined in the
23[`grep-matcher`](https://crates.io/crates/grep-matcher) crate) is a trait
24for describing the lowest levels of pattern search in a generic way. The
25interface itself is very similar to the interface of a regular expression.
26For example, the [`grep-regex`](https://crates.io/crates/grep-regex)
27crate provides an implementation of the `Matcher` trait using Rust's
28[`regex`](https://crates.io/crates/regex) crate.
29
30Finally, a `Sink` describes how callers receive search results produced by a
31`Searcher`. This includes routines that are called at the beginning and end of
32a search, in addition to routines that are called when matching or contextual
33lines are found by the `Searcher`. Implementations of `Sink` can be trivially
34simple, or extraordinarily complex, such as the `Standard` printer found in
35the [`grep-printer`](https://crates.io/crates/grep-printer) crate, which
36effectively implements grep-like output. This crate also provides convenience
37`Sink` implementations in the [`sinks`] sub-module for easy searching with
38closures.
39
40# Example
41
42This example shows how to execute the searcher and read the search results
43using the [`UTF8`](sinks::UTF8) implementation of `Sink`.
44
45```
46use {
47    vigrep::matcher::Matcher,
48    vigrep::regex::RegexMatcher,
49    vigrep::searcher::Searcher,
50    vigrep::searcher::sinks::UTF8,
51};
52
53const SHERLOCK: &'static [u8] = b"\
54For the Doctor Watsons of this world, as opposed to the Sherlock
55Holmeses, success in the province of detective work must always
56be, to a very large extent, the result of luck. Sherlock Holmes
57can extract a clew from a wisp of straw or a flake of cigar ash;
58but Doctor Watson has to have it taken out for him and dusted,
59and exhibited clearly, with a label attached.
60";
61
62let matcher = RegexMatcher::new(r"Doctor \w+")?;
63let mut matches: Vec<(u64, String)> = vec![];
64Searcher::new().search_slice(&matcher, SHERLOCK, UTF8(|lnum, line| {
65    // We are guaranteed to find a match, so the unwrap is OK.
66    let mymatch = matcher.find(line.as_bytes())?.unwrap();
67    matches.push((lnum, line[mymatch].to_string()));
68    Ok(true)
69}))?;
70
71assert_eq!(matches.len(), 2);
72assert_eq!(
73    matches[0],
74    (1, "Doctor Watsons".to_string())
75);
76assert_eq!(
77    matches[1],
78    (5, "Doctor Watson".to_string())
79);
80
81# Ok::<(), Box<dyn std::error::Error>>(())
82```
83
84vigrep: upstream's `examples/search-stdin.rs` is not ported; there is no
85stdin, file or memory-map entry point. Search a slice with
86[`Searcher::search_slice`] or any [`crate::io::Read`] with
87[`Searcher::search_reader`].
88*/
