1//! Byte-level BPE tokenizer (GPT-2 family) built from GGUF metadata.
2//!
3//! A [`Tokenizer`] is built once from a parsed [`GgufFile`] and then owns everything it needs:
4//! the vocabulary strings, the merge table and the byte-level alphabet. The GGUF file it was
5//! built from is not referenced afterwards, so the engine may drop or move the model buffer
6//! while a tokenizer is alive.
7//!
8//! # Invariants
9//!
10//! * Construction succeeds only when `tokenizer.ggml.model` is `"gpt2"`; every other model
11//!   (notably `"llama"` SentencePiece) is refused with [`TokenizerError::UnsupportedModel`]
12//!   instead of being misread as byte-level BPE.
13//! * Every id returned by [`Tokenizer::encode`] is a valid index into `tokenizer.ggml.tokens`,
14//!   and `tok.decode(&tok.encode(text)) == text` whenever the vocabulary contains byte-level
15//!   tokens for every byte of `text` (which a GPT-2 vocabulary always does).
16//! * No input, however malformed or hostile, panics: failures are [`TokenizerError`] values,
17//!   out-of-range ids are skipped, bytes without a vocabulary token are skipped, and decoding
18//!   rejoins incomplete UTF-8 sequences lossily.
19//!
20//! # Memory
21//!
22//! The tables are owned, so a tokenizer costs roughly `len(vocab) + len(merges)` times a small
23//! constant: one `String` per vocabulary entry, one `u32` per vocabulary entry for the reverse
24//! index (the token strings are not duplicated to build it), and one map node per merge. For a
25//! 50k-token GPT-2 vocabulary with ~50k merges that is a few megabytes; [`Tokenizer::bytes`]
26//! reports the estimate and [`Tokenizer::merge_count`] the merge count, both of which the engine
27//! adds to its `resident_bytes()`. Sharing the tokenizer instead of cloning it is the intended way
28//! to avoid paying that cost twice.
29//!
30//! # Byte-level alphabet
31//!
32//! Text is treated as bytes. Each byte maps to one `char` through the canonical GPT-2
33//! `bytes_to_unicode` table: the printable ASCII range `0x21..=0x7E`, `0xA1..=0xAC` and
34//! `0xAE..=0xFF` map to themselves, and the remaining 68 bytes (`0x00..=0x20`, `0x7F..=0xA0` and
35//! `0xAD`) map to U+0100..=U+0143 in increasing byte order. Vocabulary entries are strings of
36//! mapped characters (so a space in text is the single char `Ġ`, U+0120); [`Tokenizer::token_bytes`]
37//! and [`Tokenizer::decode`] apply the inverse mapping.
38//!
39//! # Pre-tokenization
40//!
41//! Chunks are produced left to right with the same alternatives, in the same order, as the
42//! reference GPT-2 regex
43//!
44//! ```text
45//! 's|'t|'re|'ve|'m|'ll|'d| ?\p{L}+| ?\p{N}+| ?[^\s\p{L}\p{N}]+|\s+(?!\S)|\s+
46//! ```
47//!
48//! so contractions, an optional literal space plus a run of letters, a run of digits, a run of
49//! anything else that is not whitespace, and whitespace runs are grouped as in GPT-2. Two
50//! classes come from `core` instead of a regex engine, and that is the only divergence:
51//!
52//! * `char::is_alphabetic` is the Unicode `Alphabetic` property, which also holds for
53//!   `Other_Alphabetic` marks (e.g. U+0345 COMBINING GREEK YPOGEGRAMMENI) and for `Nl` letter
54//!   numbers (e.g. U+2167 ROMAN NUMERAL EIGHT) that are not `\p{L}`. Such a code point groups
55//!   with letters here, and with the `other` or `digit` alternative in the reference regex.
56//! * `char::is_numeric` is exactly `Nd | Nl | No`, i.e. `\p{N}`, and `char::is_whitespace` is
57//!   exactly `White_Space`, i.e. `\s`, so those two classes do not diverge.
58//!
59//! The whitespace alternative (`\s+(?!\S)|\s+`) is emulated exactly rather than approximated: a
60//! whitespace run followed by a non-whitespace character yields a chunk with everything but the
61//! final whitespace character, and that final character either becomes the optional leading space
62//! of the following group (when it is a literal U+0020 space) or a chunk of its own. A whitespace
63//! run at the end of the text is one chunk.
64//!
65//! # Merges
66//!
67//! Each chunk starts as one symbol per byte of its UTF-8 encoding, and byte symbols are merged by
68//! rank: the lowest-ranked adjacent pair is merged everywhere it occurs, and the scan repeats
69//! until no recorded merge applies. A merge is only usable when both operands and the
70//! concatenated result are in the vocabulary; unusable merges are ignored, and a pair recorded
71//! twice is refused as [`TokenizerError::DuplicateMerge`] because its rank would be ambiguous.
72//!
73//! # Unknown symbols
74//!
75//! The byte-level alphabet makes one symbol per byte, so the constituent byte tokens of a symbol
76//! are the symbol itself: a byte whose token string is absent from the vocabulary (a vocabulary
77//! that is not byte-complete) is skipped instead of panicking, and a character of a vocabulary
78//! entry that is not in the byte-level alphabet contributes no byte to decoding.

193/// Byte-level BPE tokenizer with owned tables.
194pub struct Tokenizer {
195    /// Token strings indexed by token id.
196    tokens: Vec<String>,
197    /// Token indices sorted by `(token string, id)`, the reverse index used for symbol lookup.

199    /// the owned tables affordable for a 50k-token vocabulary.
200    order: Vec<u32>,
201    /// Adjacent symbol pair to `(rank, merged token id)`, where `None` marks a merge whose
202    /// concatenated result is not a vocabulary token (recorded so that a duplicate pair is still
203    /// detected, but never applied).
204    merges: BTreeMap<(u32, u32), (u32, Option<u32>)>,
205    /// Canonical byte to code point table.
206    byte_to_char: [char; BYTE_ALPHABET],
207    /// Beginning-of-sequence token id, when the model declares one.
208    bos: Option<u32>,
209    /// End-of-sequence token id, when the model declares one.
210    eos: Option<u32>,
211    /// Whether the model declares that BOS should be inserted before the prompt.
212    add_bos: bool,
213    /// Whether the model declares that EOS should be appended after the completion.
214    add_eos: bool,
215    /// SentencePiece tables, `None` for a byte-level BPE vocabulary.
216    spm: Option<SpmTables>,
217    /// Control and user-defined tokens, longest first.
218    ///
219    /// These are matched **before** the family encoder runs: a chat template like
220    /// `<|im_start|>user\n…<|im_end|>` is one token per marker in the model's own vocabulary, and a
221    /// tokenizer that splits them into characters feeds the model nonsense (measured: the
222    /// instruction-tuned checkpoint answered with repeated newlines until this was implemented).
223    specials: Vec<(String, u32)>,
224}

240impl Tokenizer {
241    /// Build a tokenizer from a parsed GGUF file.
242    ///
243    /// `tokenizer.ggml.model` selects the family: `"gpt2"` (byte-level BPE) or `"llama"`
244    /// (SentencePiece BPE). Anything else returns [`TokenizerError::UnsupportedModel`] rather than
245    /// being guessed at. All tables are copied out of the file, which is not borrowed afterwards.
246    pub fn from_gguf(file: &GgufFile<'_>) -> Result<Self, TokenizerError> {
247        let model = file
248            .metadata_str(KEY_MODEL)
249            .ok_or(TokenizerError::UnsupportedModel)?;
250        if model != MODEL_GPT2 && model != MODEL_SPM {
251            return Err(TokenizerError::UnsupportedModel);
252        }
253        let tokens = file
254            .metadata_str_array(KEY_TOKENS)
255            .ok_or(TokenizerError::MissingTokens)?;
256        // A byte-level vocabulary needs a merge list; a SentencePiece vocabulary needs scores.
257        // Either way the missing table is reported by name instead of producing an encoder that
258        // silently tokenizes everything as single characters.
259        let merges = if model == MODEL_GPT2 {
260            file.metadata_str_array(KEY_MERGES)
261                .ok_or(TokenizerError::MissingMerges)?
262        } else {
263            Vec::new()
264        };
265        let scores = if model == MODEL_SPM {
266            file.metadata_f32_array(KEY_SCORES)
267                .ok_or(TokenizerError::MissingScores)?
268        } else {
269            Vec::new()
270        };
271
272        let mut owned = Vec::with_capacity(tokens.len());
273        for token in tokens.iter() {
274            // Token ids are u32 on the wire; entries beyond that are unaddressable and dropped.
275            if owned.len() >= u32::MAX as usize {
276                break;
277            }
278            owned.push(String::from(*token));
279        }
280        let vocab_len = owned.len();
281        let mut order: Vec<u32> = (0..vocab_len as u32).collect();
282        // Sorted by `(token, id)`, so a token string repeated in the vocabulary resolves to its
283        // lowest id.
284        order.sort_unstable_by(|&left, &right| {
285            let left_token = owned.get(left as usize).map(String::as_str).unwrap_or("");
286            let right_token = owned.get(right as usize).map(String::as_str).unwrap_or("");
287            left_token.cmp(right_token).then(left.cmp(&right))
288        });
289        let mut table: BTreeMap<(u32, u32), (u32, Option<u32>)> = BTreeMap::new();
290        for (rank, merge) in merges.iter().enumerate() {
291            // A merge is recorded as `"left right"`; mapped symbols never contain a literal
292            // space (U+0020 maps to `Ġ`), so the split is unambiguous. Entries without a
293            // separator are malformed and cannot apply to any symbol.
294            let Some((left, right)) = merge.split_once(' ') else {
295                continue;
296            };
297            let (Some(first), Some(second)) =
298                (lookup(&order, &owned, left), lookup(&order, &owned, right))
299            else {
300                // A symbol the vocabulary does not define can never be produced.
301                continue;
302            };
303            let rank = u32::try_from(rank).unwrap_or(u32::MAX);
304            if table.contains_key(&(first, second)) {
305                return Err(TokenizerError::DuplicateMerge);
306            }
307            let mut merged = String::with_capacity(left.len() + right.len());
308            merged.push_str(left);
309            merged.push_str(right);
310            // A merge whose result is not in the vocabulary can never be emitted.
311            let result = lookup(&order, &owned, merged.as_str());
312            table.insert((first, second), (rank, result));
313        }
314
315        let bos = match file.metadata_u32(KEY_BOS) {
316            Some(id) if (id as usize) < vocab_len => Some(id),
317            Some(_) => return Err(TokenizerError::BadSpecialToken),
318            None => None,
319        };
320        let eos = match file.metadata_u32(KEY_EOS) {
321            Some(id) if (id as usize) < vocab_len => Some(id),
322            Some(_) => return Err(TokenizerError::BadSpecialToken),
323            None => None,
324        };
325
326        let spm = if model == MODEL_SPM {
327            Some(build_spm_tables(&file, &owned, &order, scores)?)
328        } else {
329            None
330        };
331
332        // Control and user-defined tokens, longest first so a `find` loop can take the longest
333        // match at the earliest position.
334        let mut specials: Vec<(String, u32)> = Vec::new();
335        if let Some(types) = file.metadata_i32_array(KEY_TOKEN_TYPE) {
336            for (id, token) in owned.iter().enumerate() {
337                let kind = types.get(id).copied().unwrap_or(0);
338                if kind == token_type::CONTROL as i32 || kind == token_type::USER_DEFINED as i32 {
339                    specials.push((token.clone(), id as u32));
340                }
341            }
342            specials.sort_unstable_by(|left, right| {
343                right
344                    .0
345                    .len()
346                    .cmp(&left.0.len())
347                    .then(left.1.cmp(&right.1))
348            });
349        }
350
351        // llama.cpp inserts BOS for SentencePiece vocabularies unless the file says otherwise, and
352        // never for byte-level BPE; an explicit metadata flag wins in both cases.
353        let add_bos_default = matches!(spm, Some(_));
354
355        Ok(Tokenizer {
356            tokens: owned,
357            order,
358            merges: table,
359            byte_to_char: canonical_byte_to_unicode(),
360            bos,
361            eos,
362            add_bos: file.metadata_bool(KEY_ADD_BOS).unwrap_or(add_bos_default),
363            add_eos: file.metadata_bool(KEY_ADD_EOS).unwrap_or(false),
364            spm,
365            specials,
366        })
367    }

369    /// Number of tokens in the vocabulary.
370    pub fn vocab_size(&self) -> usize {
371        self.tokens.len()
372    }

374    /// Number of merges recorded in the merge table, which is what the engine accounts for.
375    ///
376    /// Entries the merge list cannot use are not recorded: a malformed entry without a separating
377    /// space, and a merge naming a symbol or producing a result the vocabulary does not define.
378    /// A merge whose result is missing is recorded (so a duplicate pair is still detected) and
379    /// therefore counted. A SentencePiece vocabulary has no merge list — its merges are chosen by
380    /// token score — so this is `0` for one.
381    pub fn merge_count(&self) -> usize {
382        self.merges.len()
383    }

385    /// Estimated heap memory held by the owned tables, in bytes.
386    ///
387    /// The engine adds this to its `resident_bytes()`. It is an estimate: it counts the vocabulary
388    /// storage (string headers and string bytes), the reverse index and the merge table plus a
389    /// fixed slack per merge for the map's node overhead, and deliberately excludes allocator
390    /// bookkeeping and the `Tokenizer` struct itself.
391    pub fn bytes(&self) -> usize {
392        let strings = self.tokens.capacity() * size_of::<String>()
393            + self.tokens.iter().map(String::capacity).sum::<usize>();
394        let index = self.order.capacity() * size_of::<u32>();
395        let merges =
396            self.merges.len() * (size_of::<((u32, u32), (u32, Option<u32>))>() + MAP_ENTRY_SLACK);
397        let specials = self.specials.capacity() * size_of::<(String, u32)>()
398            + self
399                .specials
400                .iter()
401                .map(|(token, _)| token.capacity())
402                .sum::<usize>();
403        let spm = match &self.spm {
404            Some(tables) => {
405                tables.scores.capacity() * size_of::<f32>()
406                    + tables.token_type.capacity()
407                    + size_of::<[Option<u32>; BYTE_ALPHABET]>()
408            }
409            None => 0,
410        };
411        strings + index + merges + spm + specials
412    }

446    pub fn token_bytes(&self, id: u32) -> Option<Vec<u8>> {
447        let text = self.token_str(id)?;
448        if let Some(spm) = &self.spm {
449            return Some(spm_token_bytes(text, spm, id as usize));
450        }
451        let mut out = Vec::with_capacity(text.len());
452        for ch in text.chars() {
453            if let Some(byte) = unicode_to_byte(ch) {
454                out.push(byte);
455            }
456        }
457        Some(out)

460    /// Encode text into token ids (no BOS/EOS inserted).
461    ///
462    /// Dispatches on the vocabulary family: byte-level BPE introduces tokens with
463    /// [GPT-2 pre-tokenization], SentencePiece treats whitespace as U+2581 and merges by score.
464    ///
465    /// [GPT-2 pre-tokenization]: https://github.com/openai/gpt-2/blob/master/src/encoder.py
466    pub fn encode(&self, text: &str) -> Vec<u32> {
467        if self.specials.is_empty() {
468            return self.encode_plain(text);
469        }
470
471        let mut out = Vec::new();
472        let mut rest = text;
473        while !rest.is_empty() {
474            // Earliest match wins; at the same position the longest token wins (the table is
475            // length-sorted, and `>` keeps the first of equal lengths).
476            let mut best: Option<(usize, usize, u32)> = None;
477            for (token, id) in &self.specials {
478                let Some(start) = rest.find(token.as_str()) else {
479                    continue;
480                };
481                let better = match best {
482                    None => true,
483                    Some((best_start, best_len, _)) => {
484                        start < best_start || (start == best_start && token.len() > best_len)
485                    }
486                };
487                if better {
488                    best = Some((start, token.len(), *id));
489                }
490            }
491            match best {
492                Some((start, len, id)) => {
493                    out.extend(self.encode_plain(&rest[..start]));
494                    out.push(id);
495                    rest = &rest[start + len..];
496                }
497                None => {
498                    out.extend(self.encode_plain(rest));
499                    break;
500                }
501            }
502        }
503        out
504    }

506    /// Encode one run of text that contains no special token, using the vocabulary's family.
507    fn encode_plain(&self, text: &str) -> Vec<u32> {
508        if let Some(spm) = &self.spm {
509            return self.encode_spm(text, spm);
510        }
511        let chars: Vec<char> = text.chars().collect();
512        let mut out = Vec::new();
513        let mut symbols = Vec::new();
514        let mut start = 0;
515        while start < chars.len() {
516            let end = next_pre_token(&chars, start);
517            // `next_pre_token` never returns a non-advancing end; guard anyway so that no input
518            // can turn into an infinite loop.
519            let end = if end > start { end } else { start + 1 };
520            if let Some(chunk) = chars.get(start..end) {
521                symbols.clear();
522                for &ch in chunk {
523                    self.push_symbols(&mut symbols, ch);
524                }
525                self.merge_symbols(&mut symbols);
526                out.append(&mut symbols);
527            }
528            start = end;
529        }
530        out
531    }

533    /// SentencePiece encoding: escape whitespace, split into characters with byte fallback, then
534    /// merge adjacent symbols in decreasing score order while the merged string is a token.
535    ///
536    /// This mirrors llama.cpp's `llm_tokenizer_spm`, which is the reference every GGUF consumer
537    /// shares; the crate's tests pin the observable consequences (round-trips, known merges, byte
538    /// fallback, whitespace handling) rather than the loop shape.
539    fn encode_spm(&self, text: &str, spm: &SpmTables) -> Vec<u32> {
540        let mut symbols: Vec<(String, Option<u32>)> = Vec::new();
541
542        // A leading space becomes the U+2581 marker, so `"the"` and `" the"` differ — that is the
543        // SentencePiece contract, not an artifact. Text that already starts with a space must not
544        // gain a second marker: `" the"` is one `▁the`, not `▁▁the`.
545        if spm.add_space_prefix && !text.is_empty() && !text.starts_with(' ') {
546            symbols.push((String::from(SPACE_MARKER), None));
547        }
548        for ch in text.chars() {
549            if ch == ' ' {
550                symbols.push((String::from(SPACE_MARKER), None));
551            } else {
552                symbols.push((String::from(ch), None));
553            }
554        }
555
556        // Resolve each symbol: exact vocabulary match, else byte fallback, else unknown.
557        let mut resolved: Vec<(String, Option<u32>)> = Vec::with_capacity(symbols.len());
558        for (text, _) in symbols {
559            if let Some(id) = lookup(&self.order, &self.tokens, text.as_str()) {
560                resolved.push((text, Some(id)));
561                continue;
562            }
563            let mut fallback = Vec::with_capacity(text.len());
564            let mut complete = true;
565            for byte in text.bytes() {
566                match spm.byte_ids[byte as usize] {
567                    Some(id) => fallback.push((
568                        String::from(self.tokens.get(id as usize).map(String::as_str).unwrap_or("")),
569                        Some(id),
570                    )),
571                    None => {
572                        complete = false;
573                        break;
574                    }
575                }
576            }
577            if complete && !fallback.is_empty() {
578                resolved.append(&mut fallback);
579            } else {
580                resolved.push((text, spm.unknown));
581            }
582        }
583
584        // Merge in decreasing score order; ties keep the leftmost pair, matching llama.cpp.
585        loop {
586            let mut best: Option<(usize, f32, u32)> = None;
587            for index in 0..resolved.len().saturating_sub(1) {
588                let mut candidate =
589                    String::with_capacity(resolved[index].0.len() + resolved[index + 1].0.len());
590                candidate.push_str(&resolved[index].0);
591                candidate.push_str(&resolved[index + 1].0);
592                let Some(id) = lookup(&self.order, &self.tokens, candidate.as_str()) else {
593                    continue;
594                };
595                let score = spm.scores.get(id as usize).copied().unwrap_or(f32::MIN);
596                if best.is_none_or(|(_, best_score, _)| score > best_score) {
597                    best = Some((index, score, id));
598                }
599            }
600            let Some((index, _, id)) = best else { break };
601            let right = resolved.remove(index + 1);
602            resolved[index].0.push_str(&right.0);
603            resolved[index].1 = Some(id);
604        }
605
606        resolved
607            .into_iter()
608            .filter_map(|(_, id)| id.or(spm.unknown))
609            .collect()
610    }

645    /// Append the symbol ids for one input character.
646    ///
647    /// The symbol for a byte is the byte-level token for that byte; a byte whose token string is
648    /// absent from the vocabulary is skipped (its constituent byte token is the symbol itself,
649    /// which is precisely what is missing).
650    fn push_symbols(&self, out: &mut Vec<u32>, ch: char) {
651        let mut utf8 = [0u8; 4];
652        for &byte in ch.encode_utf8(&mut utf8).as_bytes() {
653            let symbol = self.byte_to_char[byte as usize];
654            let mut buf = [0u8; 4];
655            let text: &str = symbol.encode_utf8(&mut buf);
656            if let Some(id) = lookup(&self.order, &self.tokens, text) {
657                out.push(id);
658            }
659        }
660    }

662    /// Merge adjacent symbols by rank until no recorded merge applies.
663    fn merge_symbols(&self, symbols: &mut Vec<u32>) {
664        loop {
665            let mut best: Option<((u32, u32), u32, u32)> = None;
666            for pair in symbols.windows(2) {
667                if let Some(&(rank, Some(merged))) = self.merges.get(&(pair[0], pair[1])) {
668                    if best.is_none_or(|(_, best_rank, _)| rank < best_rank) {
669                        best = Some(((pair[0], pair[1]), rank, merged));
670                    }
671                }
672            }
673            let Some(((first, second), _, merged)) = best else {
674                return;
675            };
676            let len = symbols.len();
677            let mut read = 0;
678            let mut write = 0;
679            while read < len {
680                // `write <= read` throughout, so compaction never loses an unread symbol.
681                if read + 1 < len && symbols[read] == first && symbols[read + 1] == second {
682                    symbols[write] = merged;
683                    read += 2;
684                } else {
685                    symbols[write] = symbols[read];
686                    read += 1;
687                }
688                write += 1;
689            }
690            symbols.truncate(write);
691        }
692    }

695/// Build the SentencePiece side tables from GGUF metadata.
696///
697/// `scores` is `tokenizer.ggml.scores`; `tokenizer.ggml.token_type` is optional because several
698/// converters omit it — without it every token is treated as normal text, except the `<0xXX>` byte
699/// tokens this function recognises by their text (llama.cpp builds its byte table the same way).
700fn build_spm_tables(
701    file: &GgufFile<'_>,
702    tokens: &[String],
703    order: &[u32],
704    scores: Vec<f32>,
705) -> Result<SpmTables, TokenizerError> {
706    let token_type = match file.metadata_i32_array(KEY_TOKEN_TYPE) {
707        Some(types) => {
708            let mut owned = Vec::with_capacity(tokens.len());
709            for index in 0..tokens.len() {
710                owned.push(types.get(index).copied().unwrap_or(0).clamp(0, 255) as u8);
711            }
712            owned
713        }
714        None => Vec::new(),
715    };
716
717    let mut byte_ids = [None; BYTE_ALPHABET];
718    for index in 0..tokens.len() {
719        let is_byte = token_type
720            .get(index)
721            .is_some_and(|kind| *kind == token_type::BYTE);
722        if !is_byte && !token_type.is_empty() {
723            continue;
724        }
725        if let Some(byte) = parse_byte_token(tokens[index].as_str()) {
726            byte_ids[byte as usize].get_or_insert(index as u32);
727        }
728    }
729
730    let unknown = match file.metadata_u32(KEY_UNKNOWN) {
731        Some(id) if (id as usize) < tokens.len() => Some(id),
732        // A vocabulary that declares an unknown token id pointing outside itself is malformed the
733        // same way a bad BOS id is.
734        Some(_) => return Err(TokenizerError::BadSpecialToken),
735        None => lookup(order, tokens, "<unk>"),
736    };
737
738    Ok(SpmTables {
739        scores,
740        token_type,
741        byte_ids,
742        unknown,
743        add_space_prefix: file.metadata_bool(KEY_ADD_SPACE_PREFIX).unwrap_or(true),
744    })
745}

747/// Parse a SentencePiece byte token (`<0xXX>`) into its byte value.
748fn parse_byte_token(text: &str) -> Option<u8> {
749    let hex = text.strip_prefix(BYTE_TOKEN_PREFIX)?.strip_suffix('>')?;
750    if hex.len() != 2 {
751        return None;
752    }
753    u8::from_str_radix(hex, 16).ok()
754}

756/// Decoded bytes of one SentencePiece token.
757///
758/// Control, unknown, and unused tokens decode to nothing (they carry structure, not text); byte
759/// tokens decode to their byte; every other token has its U+2581 markers turned back into spaces.
760fn spm_token_bytes(text: &str, spm: &SpmTables, id: usize) -> Vec<u8> {
761    match spm.token_type.get(id).copied() {
762        Some(token_type::CONTROL | token_type::UNKNOWN | token_type::UNUSED) => Vec::new(),
763        _ => {
764            if let Some(byte) = parse_byte_token(text) {
765                return alloc::vec![byte];
766            }
767            text.chars()
768                .map(|ch| if ch == SPACE_MARKER { ' ' } else { ch })
769                .collect::<String>()
770                .into_bytes()
771        }
772    }
773}

775/// Lowest id of `token` in `tokens`, using the `(token, id)`-sorted `order` index.
776///
777/// `order` must be sorted by `(tokens[index], index)`; a token string that appears more than once
778/// in the vocabulary therefore resolves to its lowest id.
779fn lookup(order: &[u32], tokens: &[String], token: &str) -> Option<u32> {
780    let position = order.partition_point(|&index| {
781        tokens.get(index as usize).map(String::as_str).unwrap_or("") < token
782    });
783    let index = *order.get(position)?;
784    if tokens.get(index as usize).map(String::as_str)? == token {
785        Some(index)
786    } else {
787        None
788    }
789}

791/// Character class of the pre-tokenizer's three run alternatives.
792#[derive(Clone, Copy, PartialEq, Eq)]
793enum Class {
794    /// `\p{L}` (approximated by `char::is_alphabetic`).
795    Letter,
796    /// `\p{N}`.
797    Numeric,
798    /// `[^\s\p{L}\p{N}]`.
799    Other,
800    /// `\s`.
801    Whitespace,
802}
803
804/// Classify one character for the pre-tokenizer.
805fn classify(ch: char) -> Class {
806    if ch.is_whitespace() {
807        Class::Whitespace
808    } else if ch.is_alphabetic() {
809        Class::Letter
810    } else if ch.is_numeric() {
811        Class::Numeric
812    } else {
813        Class::Other
814    }
815}

817/// Length in characters of the GPT-2 contraction starting at `start`, or `None` when there is no
818/// `'s`, `'t`, `'re`, `'ve`, `'m`, `'ll` or `'d` there.
819fn contraction_len(chars: &[char], start: usize) -> Option<usize> {
820    if chars.get(start) != Some(&'\'') {
821        return None;
822    }
823    match *chars.get(start + 1)? {
824        's' | 't' | 'm' | 'd' => Some(2),
825        'l' => (chars.get(start + 2) == Some(&'l')).then_some(3),
826        'r' | 'v' => (chars.get(start + 2) == Some(&'e')).then_some(3),
827        _ => None,
828    }
829}
830
831/// End (exclusive) of the pre-token starting at `start`.
832///
833/// `start` must be a valid character index. The alternatives are tried in the reference order, and
834/// the returned end is always greater than `start` when `start < chars.len()`.
835fn next_pre_token(chars: &[char], start: usize) -> usize {
836    let len = chars.len();
837    let Some(&first) = chars.get(start) else {
838        return len;
839    };
840    if first.is_whitespace() {
841        let mut run_end = start;
842        while let Some(&ch) = chars.get(run_end) {
843            if !ch.is_whitespace() {
844                break;
845            }
846            run_end += 1;
847        }
848        if run_end == len {
849            // `\s+(?!\S)` at the end of the text consumes the whole run.
850            return run_end;
851        }
852        if run_end > start + 1 {
853            // `\s+(?!\S)`: everything but the final whitespace character.
854            return run_end - 1;
855        }
856        if first != ' ' {
857            // `\s+`: whitespace that cannot be the optional leading space of a group.
858            return start + 1;
859        }
860        // A single literal space followed by a non-whitespace character is absorbed below.
861    } else if first == '\'' {
862        if let Some(length) = contraction_len(chars, start) {
863            return start + length;
864        }
865    }
866    // ` ?\p{L}+` / ` ?\p{N}+` / ` ?[^\s\p{L}\p{N}]+`; a space is only absorbed when a
867    // non-whitespace character follows it, so `group_start` is a valid index.
868    let group_start = if first == ' ' { start + 1 } else { start };
869    let Some(&head) = chars.get(group_start) else {
870        return start + 1;
871    };
872    let class = classify(head);
873    let mut end = group_start + 1;
874    while let Some(&ch) = chars.get(end) {
875        if classify(ch) != class {
876            break;
877        }
878        end += 1;
879    }
880    end
881}

897/// The canonical GPT-2 `bytes_to_unicode` table: byte to code point.
898fn canonical_byte_to_unicode() -> [char; BYTE_ALPHABET] {
899    let mut table = [REPLACEMENT; BYTE_ALPHABET];
900    let mut extra = 0u32;
901    for (byte, slot) in table.iter_mut().enumerate() {
902        let raw = byte as u32;
903        let printable = (0x21..=0x7E).contains(&raw)
904            || (0xA1..=0xAC).contains(&raw)
905            || (0xAE..=0xFF).contains(&raw);
906        if printable {
907            *slot = char::from_u32(raw).unwrap_or(REPLACEMENT);
908        } else {
909            *slot = char::from_u32(FIRST_EXTRA_CODE_POINT + extra).unwrap_or(REPLACEMENT);
910            extra += 1;
911        }
912    }
913    table
914}

916/// Inverse of [`canonical_byte_to_unicode`]: code point to byte, `None` when the code point is not
917/// part of the byte-level alphabet.
918fn unicode_to_byte(ch: char) -> Option<u8> {
919    let code_point = ch as u32;
920    match code_point {
921        // Printable ASCII and Latin-1 map to themselves.
922        0x21..=0x7E | 0xA1..=0xAC | 0xAE..=0xFF => u8::try_from(code_point).ok(),
923        // The bytes without a printable representative, in byte order:
924        // 0x00..=0x20, then 0x7F..=0xA0, then 0xAD.
925        FIRST_EXTRA_CODE_POINT..=LAST_EXTRA_CODE_POINT => {
926            let index = code_point - FIRST_EXTRA_CODE_POINT;
927            let byte = if index < 0x21 {
928                index
929            } else if index < 0x21 + 0x22 {
930                index - 0x21 + 0x7F
931            } else {
932                0xAD
933            };
934            u8::try_from(byte).ok()
935        }
936        _ => None,
937    }
938}

1554                tokens: vec![
1555                    String::from("<unk>"),
1556                    String::from("<s>"),

1567                vocab.push(format!("<0x{byte:02X}>"), 0.0, token_type::BYTE as i32);
1568            }

1570            // how a real SentencePiece vocabulary ranks its merges.

1573            vocab.push("h".to_string(), 0.4, 1);
1574            vocab.push("e".to_string(), 0.4, 1);

1576            vocab.push("\u{2581}th".to_string(), 2.0, 1);
1577            vocab.push("\u{2581}the".to_string(), 3.0, 1);

1750    #[test]
1751    fn control_tokens_are_matched_before_pre_tokenization() {
1752        // A byte-level vocabulary with one control token: without special-token matching the
1753        // template marker would tokenize as `<`, `|`, `i`, … and the model would see nonsense.
1754        let vocab = vocabulary();
1755        let token_refs_before = vocab.tokens.len();
1756        let mut tokens = vocab.tokens.clone();
1757        let special = String::from("<|im_start|>");
1758        tokens.push(special.clone());
1759        let refs: Vec<&str> = tokens.iter().map(String::as_str).collect();
1760        let merges: Vec<&str> = vocab.merges.iter().map(String::as_str).collect();
1761        let mut types = vec![1i32; token_refs_before];
1762        types.push(token_type::CONTROL as i32);
1763
1764        let mut image = GgufImage::new();
1765        image.str(KEY_MODEL, MODEL_GPT2);
1766        image.str_array(KEY_TOKENS, &refs);
1767        image.str_array(KEY_MERGES, &merges);
1768        image.i32_array(KEY_TOKEN_TYPE, &types);
1769        let image = image.finish();
1770
1771        with_tokenizer(&image, |tokenizer| {
1772            let special_id = token_refs_before as u32;
1773            let plain = tokenizer.encode("hi");
1774            assert_eq!(plain.len(), 2, "plain text uses one token per byte here");
1775            assert_eq!(
1776                tokenizer.encode("<|im_start|>hi"),
1777                vec![special_id, plain[0], plain[1]],
1778                "the control token must be one id, not characters"
1779            );
1780            // Text without specials is unaffected.
1781            assert_eq!(tokenizer.encode("hi"), plain);
1782            // Specials are only matched where they actually appear: one token each side.
1783            assert_eq!(
1784                tokenizer.encode("h<|im_start|>i"),
1785                vec![plain[0], special_id, plain[1]]
1786            );
1787        });
