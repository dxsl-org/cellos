3//! Hardware-independent logic for the Intel integrated-GPU driver Cell
4//! (ADR-0033, plan `.agents/261104-0801-x86-igpu-compute/`).
5//!
6//! Everything here is pure computation over byte/word buffers, so it is
7//! host-tested before any machine exists. MMIO, DMA and syscalls live in the
8//! driver Cell, not here; the `XE_GPU` IPC frames ([`wire`]) and their per-client
9//! server ([`server`]) are byte codecs shared by the driver and the Mesa shim, and
10//! every device effect of a request goes through the driver's [`hw::GpuHw`].
11//!
12//! Behaviour follows the MIT-licensed Linux `xe` driver; each module names the
13//! upstream file it mirrors. No firmware is parsed beyond its public CSS header.
