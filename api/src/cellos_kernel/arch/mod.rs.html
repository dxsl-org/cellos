2//! Architecture seam (Phase 14).
3//!
4//! Every architecture difference in the kernel lives under this directory. Each
5//! `<arch>/` module exports the same function sets (`irq`, `clock`, `power`,
6//! `smp`, `tlb`, `user_access`, `page_probe`, ...) with the same signatures,
7//! and exactly one of them is selected here. Shared code calls
8//! `crate::arch::<set>::<fn>()` and names no architecture.
9//!
10//! `crate::hal::arch` is the HAL's own per-architecture facade (`Context`,
11//! `ViTrapFrame`, ...); it is spelled in full so the two never collide.
12//!
13//! Each arch module is glob re-exported (`pub use <arch>::*`) once it has
14//! content.
15//!
16//! `legacy` holds the 32-bit code (riscv32, arm, x86). It is selected by
17//! `not(cellos_wide)` and, like before the move, does not build today.
18
