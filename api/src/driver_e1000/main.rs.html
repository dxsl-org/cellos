1//! Intel e1000 (8254x) NIC Driver Cell — Tier-1 Privileged Driver Cell.
2//!
3//! This cell owns one 82540EM or 82545EM PCIe endpoint exclusively. Through the
4//! shared `nic_driver` skeleton it:
5//!   1. Calls `sys_find_pcie_device_by_vendor(8086, id)` (opcode 424) for each ID
6//!      in `identity::QUERY_DEVICE_IDS`. The class triple `02:00:00` is shared
7//!      with `/bin/igb`, `/bin/e1000e` and `/bin/virtio-net`, so the cell names
8//!      its controllers exactly instead of using the class query (H-S3-6).
9//!      Absent, it exits silently.
10//!   2. Confirms the identity (`identity::classify`) before it touches MMIO.
11//!   3. Claims exclusive MMIO via `sys_request_mmio`.
12//!   4. Initialises the controller (TX/RX ring setup, EEPROM MAC read).
13//!   5. Calls `sys_register_nic_driver()` to announce itself to the kernel.
14//!   6. Serves Tx/Rx/GetMac IPC from the net cell. RX is request-driven (the net
15//!      service asks for frames), so the cell stays polled.
16//!
17//! This cell is granted `PcieDriverCap` by `init` via direct TCB write at spawn
18//! time — NOT via a manifest flag (all 8 flag bits in v1 are occupied).
19

30// ── Capability manifest ───────────────────────────────────────────────────────
31// PcieDriverCap is granted by init via direct TCB write (not a manifest flag).
32abi::declare_manifest!(
33    block_io = false,
34    network = false,
35    spawn = false,
36    gpio = false,
37    uart = false,
38    hypervisor = false
39);
40
41// ── Syscall allowlist ─────────────────────────────────────────────────────────
42// `run_app!` emits a manifest but NOT a `VICELL_SYSCALLS` section, so without
43// this the kernel leaves the cell at its TCB's `u64::MAX` allowlist. The list is
44// exactly `/bin/igb`'s: the AppContext base set, the exact-identity PCIe query,
45// NIC registration, the try_send reply path, the exit path, and the DMA calls
46// behind `DmaBuf::alloc`/`authorize`. `Exit`/`Yield` carry no allowlist bit and
47// are always permitted; naming them documents the intent.
48abi::declare_syscalls![
49    // AppContext event-loop base set.
50    Send,
51    TrySend,
52    Recv,
53    TryRecv,
54    Log,
55    Heartbeat,
56    LookupServiceBound,
57    GetTime,
58    RecvTimeout,
59    // PCIe device path: the exact-identity query (424, shares allowlist bit 50
60    // with the legacy class query) and the BAR0 claim.
61    FindPcieDeviceByVendor,
62    RequestMmio,
63    // System NIC-driver role.
64    RegisterNicDriver,
65    // Clean shutdown returns through the exit path.
66    Exit,
67    // DMA: `DmaBuf::alloc` -> GrantAlloc, `DmaBuf::authorize` -> GrantDma.
68    GrantAlloc,
69    GrantDma
70];
