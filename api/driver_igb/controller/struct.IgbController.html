fn program_rings(&mut self)

Initial DMA-address programming and TX/RX enablement, in order: TX ring base, every RX descriptor, RX ring base, enable. Every address is an authorized IOVA.

Source

fn wait_link_up(&self) -> ViResult<bool>

Poll STATUS.LU for a bounded window. Returns whether link is up; a timeout is not fatal (the model brings link up on its own schedule) but the caller reports it.

Source

fn recv_frame(&mut self, out_buf: &mut [u8]) -> usize

Poll for a received frame; copies into out_buf. Returns the number of bytes written, or 0 when nothing is ready.
