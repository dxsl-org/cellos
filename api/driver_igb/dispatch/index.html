driver_igb

Module dispatch 

Source
Expand description

IPC request dispatcher for the igb NIC Driver Cell.

The wire format is byte-for-byte the e1000/virtio-net NIC protocol, so the net service consumes this cell exactly as it consumes /bin/e1000 — one network surface, no device-specific path:

byte 0: op (0 = Tx, 1 = Rx, 2 = GetMac) Tx request: [0x00, len_lo, len_hi] ++ frame_bytes (Ethernet frame, no FCS) Rx request: [0x01] GetMac: [0x02]

Replies: Tx → [0x00] OK / [0x01] error; Rx → [len_lo, len_hi] ++ frame; GetMac → the 6 MAC bytes.
