Module endpoint 

Source
Expand description

Which transport the network backend uses for an endpoint.

WHY: the network backend’s reply is parsed for TOOL_CALL: lines, so whoever controls the bytes on the wire proposes the agent’s next action. Plaintext HTTP hands that to anyone on path. TLS (through service-net, which verifies the server chain and SNI) is therefore the default for every endpoint.

The single exception is opt-in and lab-only: with the qemu-plaintext-llm feature, the QEMU user-network host alias QEMU_SLIRP_HOST may be reached in plaintext, because there the “network” is QEMU’s in-process NAT to the developer’s own machine (tools/hypha-mock-llm). A cell cannot tell QEMU from a real LAN where 10.0.2.2 is an arbitrary host, which is why this is a build choice rather than a runtime guess. Tool calls stay operator-confirmed either way (core’s tool_gate).
