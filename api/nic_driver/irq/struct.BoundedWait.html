pub fn setup(tag: &'static str, bdf: u32, want: usize) -> Self

Ask 435 for want MSI-X entries of the owned function bdf. MSI is not accepted: per-queue causes need MSI-X. A refusal leaves the cell polled (reason=alloc-refused).

Source

pub fn wait_for( &mut self, parks: u32, polls: u32, ready: impl FnMut() -> ViResult<bool>, ) -> ViResult<bool>

Wait (bounded) until ready holds: a short spin, then up to parks interrupt parks with MSI-X, or polls spins when polled. The device is re-read after every return. Ok(false) means the budget ran out. For devices that keep a vector armed on their own.

Source

pub fn wait_for_rearmed( &mut self, parks: u32, polls: u32, rearm: impl FnMut() -> ViResult<()>, ready: impl FnMut() -> ViResult<bool>, ) -> ViResult<bool>

As wait_for, for devices whose causes must be re-armed: before every park rearm runs and the condition is re-checked, so a cause that lands afterwards raises a fresh message.
