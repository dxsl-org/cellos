Module ring 

Source
Expand description

Descriptor rings and frame buffers in device-visible DMA pages.

Law 4 exception: the volatile accesses and copies below touch memory the controller reads and writes. Every ring and buffer is a whole DmaBuf the cell owns for its lifetime (mapped read-write at virt() for size() bytes, page-aligned), and every access is checked against that size before it is made. Nothing here programs a device address: that stays behind crate::dma::DmaSet::alloc_authorized.
