Expand description

Authorize-before-program DMA layout.

Every NIC cell allocates its rings and frame buffers, authorizes each one for its BDF (DmaBuf::authorize → GrantDma) in one deterministic order, and only then programs any device-visible address. The first refusal stops the walk before a later slot is exposed, and the returned IOVAs are kept verbatim: a chip must never substitute a CPU physical address for them.

The order is: extra slots placed Position::Before (i40e’s admin queues), TX ring, TX buffers, RX ring, RX buffers, extra slots placed Position::After (bcm57xx’s status block). The chip programs its own registers from the returned Iovas.
