Expand description

One Ethernet controller family, as the shared cell skeleton drives it.

Required Associated Constants§

Source

const TAG: &'static str

Log tag, brackets included ("[igc]"). Every line the skeleton prints starts with it.

Source

const VENDOR: u16

PCI vendor ID passed to FindPcieDeviceByVendor.

Source

const QUERY_IDS: &'static [u16]

Device IDs queried, in order. Empty means no part is admitted yet: the probe finds nothing and the cell reports itself absent.

Source

const ABSENT_LINE: Option<&'static str>

Text printed after the tag when no controller is found, or None to exit silently (/bin/e1000, whose tag sibling lanes assert absent).

const MAX_TX: usize = FRAME_MAX

Largest frame accepted by OP_TX and returned by OP_RX (at most FRAME_MAX).
