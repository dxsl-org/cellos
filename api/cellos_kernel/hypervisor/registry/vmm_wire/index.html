Module vmm_wire 

Source
Expand description

Byte images of the records the hypervisor syscalls copy to the cell. Byte images of the hypervisor-syscall records the kernel copies to a cell.

The hypervisor syscalls move these records through the caller’s copy view, which takes bytes. A typed ViVmExit cannot be viewed as bytes soundly — its padding is uninitialised and would leak kernel stack — so the exit is serialised field by field into a zeroed image of its #[repr(C, u8)] layout: the u8 tag at 0, the payload (a repr(C) struct per variant) at 8, the union’s alignment.
