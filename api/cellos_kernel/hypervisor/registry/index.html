cellos_kernel::hypervisor

Module registry 

Source
Expand description

VM registry — per-owner RAII store for Stage-2 tables, guest RAM, and vCPUs.

A VM belongs to the Cell incarnation that created it (VmKey), never to a tid: every operation names that incarnation, and the incarnation’s VMs are reaped together when its root retires (reap_vms_for).

§Lock order

VM_REGISTRY → FRAME_ALLOCATOR (same order as grant reaper; never reverse).

§Non-aarch64

All public functions return Err(ViError::NotSupported) so the compiler produces a complete match for the hypervisor Syscall arms on every target.
