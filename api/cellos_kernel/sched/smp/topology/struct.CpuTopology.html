Expand description

A write-once bijection between N logical harts and physical ids below P.

Fields§

§physical: [AtomicUsize; N]

Logical hart → physical id, or UNMAPPED.

§logical: [AtomicUsize; P]

Physical id → logical hart, or UNMAPPED. Kept so the reverse lookup (AArch64 resolves the calling hart through it on every current_hart_id) stays O(1).

§count: AtomicUsize

Logical slots published so far.

pub fn publish(&self, logical: usize, physical: usize) -> bool

Publish logical ↔ physical.

Returns true when the pair is now mapped (also when it already was). Returns false, leaving the map unchanged, when either id is out of range, logical already names another physical id, or physical is already claimed by another logical hart.

Source

pub fn physical(&self, logical: usize) -> Option<usize>

The physical id of logical, if published.

Source

pub fn logical(&self, physical: usize) -> Option<usize>

The logical hart that owns physical, if published.

Only the forward slot completes a mapping, so a claim whose publisher has not finished (or is about to give it back) is not reported.
