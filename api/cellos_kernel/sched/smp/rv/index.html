Constants§

SECONDARY_BOOT_TIMEOUT_TICKS 🔒
How many 10 ms ticks hart 0 waits for each secondary to come online before logging a warning and continuing single-hart. 500 ms is generous for QEMU and for an SBI hart_start that has to power a core up. (AArch64 waits on the architected counter instead, which runs with IRQs masked.)

secondary_start 🔒
smp_hart_entry’s riscv64 bring-up, up to interrupts enabled: map the physical hart to its logical id, enter the shared kernel root, install the hart-local state and trap vector, arm the tick, enable interrupts. Returns the logical hart.
set_boot_physical_hart
Publish the RV64 boot hart’s numbering into CPU_TOPOLOGY: the boot hart is logical 0 and the hart it displaced takes its number (topology::boot_swapped_physical). Called once by kmain on the boot hart, before any secondary is started.
start_secondaries
