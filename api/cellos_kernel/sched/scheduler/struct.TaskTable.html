Expand description

Indirect sorted task storage. Reserved publications hold capacity rather than inserting a hidden task into the live scheduler namespace.

Fields§

§rows: Vec<(usize, Box<Task>)>§reservations: usize§deadlines: Vec<(u64, usize)>

(deadline, tid) of parked tasks, sorted; at most one row per task. Rows go stale when the task wakes early and are checked before use.

§event_waiters: Vec<usize>

Parked tasks the sweep polls for events on every pass.

§sweep_scratch: Vec<usize>

Reused candidate list for the sweep, so the timer path never allocates.

pub(crate) fn note_parked(&mut self, id: usize, state: &TaskState)

Record what the sweep must watch for id, which just switched out in state: its deadline, if any, and whether it waits for events. Called on every switch-out, so it also forgets a task that left a parked state.

Source

fn sweep_candidates(&mut self, now: u64) -> Vec<usize>

Tasks the sweep must examine at now, ascending by tid: every deadline that has passed (removed from the queue) and every event waiter. The list is the reserved scratch buffer; hand it back with return_sweep_scratch.
