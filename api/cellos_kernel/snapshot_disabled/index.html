Module snapshot_disabled 

Source
Expand description

The snapshot API on kernels built without snapshot-qualified (architecture remediation Phase 09): the 5.7k-line engine in snapshot_engine.rs is not compiled at all, and this module is the only closed-gate behaviour.

  • no scratch region is reserved at boot;
  • a capture is refused with SnapshotError::GateClosed;
  • a boot never restores, and clears a header an older image may have left behind, so that image cannot replay it after a downgrade.

clear_stale_header 🔒
Reads the header sector and zeroes it (then flushes) only when it carries the snapshot magic, so a board without a snapshot region sees no stray write. Returns whether a header was found and cleared; write and flush failures are non-fatal because nothing on this kernel reads the region.
