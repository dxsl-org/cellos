Function repoint

pub(crate) fn repoint(
    service_id: u16,
    from_tid: usize,
    to: (usize, u64, u64),
) -> bool
Expand description

Re-point service_id from provider from_tid to to = (tid, cell_id, generation) in place: only an active row that still names from_tid changes, so a racing re-registration is never overwritten. The row keeps its map slot, so nothing is allocated (exit teardown, which may run in an ISR, calls it); it takes to’s identity with no flags and no pause, as register would write it. false, with nothing changed, when no row of service_id names from_tid, the row is paused, or to names tid 0.

A paused row belongs to a hot swap in flight: only commit_paused moves it, and clear_tid removes it when its provider dies, so the swap’s commit then fails instead of publishing over a re-pointed row.
