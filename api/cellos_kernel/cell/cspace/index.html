Module cspace 

Source
Expand description

Shared Cell CSpace, Principal Discrimination, and Local Generational Handles.

Implements candidate specifications D01 r2, D02 r1, and D03 r2 under Phase 02.

  • D01: Opaque 64-bit tickets indexing preallocated slot arenas; 48-byte handle requests; 32-byte status headers; 48-byte BootFS file requests.
  • D02: Strict Principal discrimination (Kernel singleton vs Cell { id, generation }); 40-byte principal record.
  • D03: Single shared CellAuthority per (CellId, generation); 64-byte CSpace request; single-parent revocation hierarchy with AdmissionCut and quiescence tracking.
