Enum Principal 

Source 
pub enum Principal {
    Kernel,
    Cell {
        id: CellId,
        generation: u64,
    },
}
Expand description

Principal discrimination per D02 r1.

An exceptional Kernel singleton is minted exclusively by kernel bootstrap context. Ordinary cells are identified by their CellId and unique monotonic generation.
