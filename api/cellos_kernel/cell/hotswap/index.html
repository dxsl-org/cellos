Hot-swap support primitives shared by the supervisor-owned replacement path.

The legacy syscall-400 whole-sequence orchestrator is retired. This module now keeps only the still-live freeze state, replacement binding, mailbox cutover, and HotSwapReady bookkeeping used by opcodes 401 and 413-422.
