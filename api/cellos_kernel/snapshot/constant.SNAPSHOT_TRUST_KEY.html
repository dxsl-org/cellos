The keyed-MAC key that authenticates the header (and therefore the epoch).

The kernel has one hash primitive, crate::sha256::sha256, and the workspace’s HMAC-SHA256 construction over it lives in libs/attestation/src/hkdf.rs:14 — written there precisely because the kernel and its neighbours must not take a crypto dependency. This mirrors that RFC 2104 construction over the kernel’s own SHA-256: a standard construction, no new algorithm, no new crate.

Trust material is provisioned, not invented: with the dev posture (dev-signing-key, the same switch crate::signing uses for the cell trust anchor) a reproducible dev key is compiled in; without it there is no key at all and every authenticated-freshness check refuses, so a production build cannot silently fall back to an unauthenticated epoch.
