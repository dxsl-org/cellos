Struct ScratchRegion 

Source 
pub struct ScratchRegion {
    pub base: u64,
    pub bytes: usize,
}
Expand description

A bounded physical workspace the capture owns, reserved at boot.

It is the capture’s workspace, not machine state: every frame in it is excluded from the inventory (take_allocated_frame), so a restored image can never replay the capture’s own stack or buffers over live scratch, and the region is what assert_scratch_outside_runs proves the planned runs do not touch. The frozen window’s stack and every buffer it fills live inside it, which is what makes that proof honest rather than a claim about a span the capture is not actually using.
