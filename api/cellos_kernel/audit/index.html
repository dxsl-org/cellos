Kernel audit ring buffer — 256 KB in-memory event log.

Records key kernel events (IPC, file, net, spawn, fault, exit) with a monotonic timestamp for post-mortem analysis. A background Cell (or shell builtin) drains the ring and appends to /data/kernel.log.

§Concurrency

Two things can make a write concurrent with another producer: the timer ISR preempting a syscall-context log_event() call on the same hart, and a second hart logging at the same time. S-mode interrupts are disabled for the duration (which also makes the lock below unreachable from an ISR, so it cannot self-deadlock), and WRITE serialises the hart-to-hart case: without it two harts read the same head, write into the same byte range, and store the same advanced head, so one record is silently overwritten.

§Overflow

When the ring is full the oldest whole records are evicted, counted in dropped_count, and reported in-band by a RecordsDropped record written just ahead of the record that forced the eviction. No blocking, no corruption.

§Record format

[u64 mtime_ticks LE][u8 event_type][u8 payload_len][payload…]

Total minimum: 10 bytes per event.

peek
Copy whole records, up to out.len() bytes, from the oldest one without removing them. Returns the ring position the copy started at and the bytes copied; hand both to consume once the copy has reached its reader, so a failed delivery loses no audit record.
push_record 🔒
Evict for, then write, one record at head; returns the new head, the new tail and how many records were evicted. dropped is the cumulative eviction count before this call. An eviction is reported by a RecordsDropped record (evicted, cumulative) ahead of the event, so a consumer sees the gap where it happened; room for it is reserved up front so it never evicts on its own.
