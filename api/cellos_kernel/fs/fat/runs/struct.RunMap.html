Expand description

A file’s data as volume byte ranges, in file order, covering file offsets 0..mapped_len() without gaps.

The map is a snapshot: it stays correct only while neither the file’s cluster chain nor its directory-entry size changes.

pub(super) fn build<IO: ReadWriteSeek, TP, OCC>( file: &mut File<'_, IO, TP, OCC>, ) -> ViResult<Self>

Walk file’s cluster chain once, from its first cluster, and record its data as merged contiguous runs.

Mapping stops at the size the directory entry declares, so a chain longer than the file (or a cyclic one) is not followed past the file’s data. A chain that ends early yields a map shorter than the declared size.

§Errors

ViError::IO when the FAT cannot be read; ViError::OutOfMemory when the run list cannot grow.
