Module smbios 

Source
Expand description

Bounded SMBIOS reader for the system identity (structure type 1).

Reads one entry point (64-bit _SM3_ preferred, then 32-bit _SM_), maps the structure table it names, and returns the first type 1 structure’s manufacturer, product name and UUID.

Contract:

  • Never panics. Every malformed, truncated, oversized or unmappable input yields None; a caller treats None exactly like firmware without SMBIOS.
  • Every firmware range is mapped through the caller’s mapper before it is read, so SMBIOS memory gets the same admission as ACPI tables.
  • Strings are firmware-controlled. They are truncated to SMBIOS_STRING_MAX bytes, kept as raw bytes, and grant no authority.
