Module fsapi 

Source
Expand description

The kernel’s file-descriptor and working-directory layer over the embedded BootFS (VIFS1): path resolution against a task’s cwd, the per-task open-file table and the stdio descriptors. A Spec 15 exception: its target is the VFS Cell, which already owns every mounted filesystem except BootFS.
