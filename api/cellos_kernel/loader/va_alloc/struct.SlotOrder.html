Expand description

Where SlotAllocator::alloc starts probing.

Randomised iff seed found its source able to fill one 64-bit word; it is then read again for every allocation. Otherwise every start is 0 (lowest free slot first) and the source is never called again.

Source

fn random_start(&self, span: usize) -> Option<usize>

The random start offset for one allocation over a span of span slots, below span; None in deterministic order. In randomised order a source that fails this once (RDSEED and RDRAND both exhausted after their bounded retries) starts that one allocation at offset 0; which slot it gets never affects ownership.
