BLOCK_IO_REGISTERED 🔒
Tracks whether a block-I/O cell has registered the VFS fast-IPC handler pointer. Set to true on first registration; subsequent registrations (hot-swap path) log a warning and re-point the handler. Never reset — warm boot / snapshot restore skips spawn_from_path, so re-registration never fires spuriously.
