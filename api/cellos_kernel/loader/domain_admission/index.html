Module domain_admission 

Source
Expand description

Internal, default-off RV64 domain-admission policy. It has no loader route. Default-off, internal-only gate for future native-domain admission.

A successful result is an immutable policy-generation lease, not permission to expose a Tier-2 route. No public loader or manifest path constructs a request; test hooks use this module solely to prove denial and drain rules.
