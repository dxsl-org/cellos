Struct ElfSnapshot

pub(crate) struct ElfSnapshot {

Expand description

An owned copy of an ELF image. The u64 backing keeps it 8-aligned so bytes borrows it instead of copying a second time.

pub(crate) fn zeroed(len: usize) -> ViResult<Self>

A zero-filled snapshot of len bytes for the caller to fill once.

len is the image’s own (caller-chosen) size, so the reservation is fallible: vec![0u64; ..] would reach the infallible alloc error handler and halt the kernel instead of refusing the spawn.
