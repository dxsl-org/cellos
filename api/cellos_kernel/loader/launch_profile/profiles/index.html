KMS_SSH_ADMIN_EDGE 🔒
The child ceiling of the one reviewed edge that starts /bin/kms-ssh-admin (shell, kernel-resolved path route only; KSSH K7): the pre-annex X/M/W rights plus kms_ssh_admin. No network, no sign right: the admin and sign rights are never held by one Cell, so request(/bin/kms-ssh-admin) ∩ ceiling is the sole way a Cell obtains CALLER_FLAG_KMS_SSH_ADMIN. The constant lives here, not in targets.rs, for the same reason as SSH_CLIENT_EDGE.
LEGACY 🔒
The pre-annex X/M/W rights every reviewed non-sandbox edge keeps (annex S2-T/S2-W §3, D-TW1); “capability-free” below means nothing beyond them.

SHELL_EDGE 🔒
The child ceiling of every reviewed edge that hosts the interactive shell /bin/cellbox: LEGACY plus config_write, which service-config bounds to the shell key namespace (Phase 01 CP1, D-Q5). Must equal the init boot row boot_ceiling("/bin/cellbox").

SSH_CLIENT_EDGE 🔒
The child ceiling of the one reviewed edge that starts /bin/cellbox-ssh (shell, kernel-resolved path route only): the outbound client rights of NET_CLIENT plus kms_ssh_sign (KSSH K3). A separate constant on purpose: NET_CLIENT is the ceiling of every other network client (curl, wget, mqtt, ocel, llm-gateway, https-demo, robot-demo) and must not carry the right. Only this edge carries it, so request(/bin/cellbox-ssh) ∩ ceiling is the sole way a Cell obtains CALLER_FLAG_KMS_SSH_SIGN.

c_spawn_profile 🔒
The C spawn adapter needs one exact, capability-free child edge. Both routes are allowed because they resolve the same reviewed row: the kernel-resolved path form is the one a board with a kernel block device can use, and the caller-supplied-ELF form is the only one that reaches the VFS-served cell store post-boot, where the kernel deliberately drives no block hardware. The child holds no authority of its own, so a compromised child cannot escalate through the edge it was started with.
