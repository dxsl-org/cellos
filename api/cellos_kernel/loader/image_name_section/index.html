Module image_name_section

Bounded read of the __ViCell_image program-name section, and the measured identity an admitted image is published with.

The signing tool emits the section into the bytes it signs. The name feeds ImageIdentity, which VFS matches path rules against, so it is read with the duplicate-refusing ElfSections parser rather than ElfLoader::get_section (first match wins, no duplicate check).

Functions§

declared_name 🔒
The declared program name, or None when the image declares none or the declaration is unusable (duplicated, NOBITS, out of bounds, or not a valid name). Unusable is treated as absent: the image still spawns, it just carries no name, so no name-bound rule can ever match it.
measured_identity 🔒
The identity recorded for an admitted image. verified is true only when its signature verified under this kernel’s anchor: the name is believed only then, because only then are the section bytes covered by a signature the kernel checked. An unsigned image states its digest and nothing else, whatever name its section claims.
