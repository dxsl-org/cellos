Module rank

Expand description

Static lock ranks (architecture remediation Phase 10).

Every static Spinlock is built with Spinlock::ranked and a rank from the table below. A hart may only acquire a ranked lock whose rank is strictly greater than every ranked lock it already holds; the order of the table is the lock order. Instance locks (fields of per-object structs) stay unranked.

The check runs only in the test posture (test-hooks) and in host tests: there, acquiring out of order panics with both lock names before spinning, so an inversion is reported instead of deadlocking. Dev and release kernels store no rank and do no work (docs/generated/lock-ranks.md is generated from this table).
