pub fn flush_ranges(
    cap: &mut FlushCap,
    ranges: &[(VAddr, usize)],
    all: bool,
) -> FlushOutcome
Expand description

Invalidate page-aligned ranges of the shared (kernel) root on every online hart, or every translation when all, as one operation: one remote request per hart, one bounded probe.

Never panics and never waits past the probe bound. Unconfirmed carries the epochs each remote hart was asked for: the caller keeps every frame the changed translations named (frame_run::Batch quarantines them) and must not report a permission lowering as done. Callers hold no FRAME_ALLOCATOR (the cap proves it) and log the outcome themselves, because this may run under KERNEL_ROOT, which ranks above the console.

  • x86_64: every PCID and global entry locally, then every online CPU’s acknowledged full flush.
  • riscv64: sfence.vma per page (or all), then SBI RFENCE per range. An RFENCE error, or all, takes the IPI epoch path instead: every remote hart serves the request with a full local flush.
  • aarch64: broadcast tlbi per page (or vmalle1is); no acknowledgement exists to wait for.
