Module deferred_release 

Source
Expand description

Bounded deferred release of page-table frames whose tag invalidation was not confirmed synchronously, plus the reaper that completes them. The private-root half of the release contract: frames a private root no longer maps, retained until that root’s tag invalidation is confirmed.

A release path must never wait synchronously for a remote acknowledgement: a peer hart can be held non-preemptible for seconds. A path whose bounded probe did not confirm its tag hands the frames (and, for a root teardown, the tag’s lease) to [defer_frames] / [defer_frames_and_tag]. They become Quarantined(TagUnconfirmed) runs in the one frame-run quarantine (memory::frame_run::PENDING), whose hart-0 reaper frees them once every remote hart has published an epoch asked for after the unmap.

Fail-closed, in this order:

  1. a frame is released only after the invalidation that covers it is acknowledged — never on a timeout, never silently;
  2. nothing is abandoned: a hart that never answers keeps the frames quarantined (counted, and logged once on escalation) and the tag reads unconfirmed for as long as it does (census §7.5);
  3. a wait that cannot be recorded (no heap) leaks its frames, counted, and makes every tag read unconfirmed for the rest of the boot.

[tag_invalidation_unconfirmed] is the one answer every dependent path asks (a grant drain, a re-publish over a retired VA): false is the only proof that no hart can still resolve a stale translation under the tag.
