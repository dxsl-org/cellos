Expand description

Lock [base, base + len) of task owner for DMA export export_id, held by the Cell holder_cell (ADR-0033 CP1 §5.1).

The caller proves ownership of the range while holding the grant-table lock that resolved it (order grant table → this leaf), so the owner cannot free the range between the check and the lock. Export ids are unique for the boot; the lease table in task::dma_export bounds how many locks exist.

§Errors

PinError::InvalidRange for an empty or overflowing range; PinError::TableFull if export_id is already locked (never issued twice).
