Paging management for ViCell kernel.

Architecture dispatch: riscv64, aarch64 — SV39 / AArch64 page tables via HAL PageTable x86_64 — 4-level PML4 via HAL PageTable, read through the HHDM riscv32, x86, arm — bare physical (no page tables); stubs return NotSupported

Constants§

FREE_FRAME_ALIAS 🔒
The kernel alias of every free RAM frame where RAM is identity-mapped (RV64, AArch64): supervisor read/write, never executable. The boot map gives it to every Usable frame, and a run whose alias was taken over restores it before free (frame_run::KernelBackend::normalise). Nothing executes from a free frame or its identity alias: the kernel fetches only its own image (MemoryType::Kernel), cells fetch through their USER mappings, and guests through Stage-2. x86_64 reaches RAM through the HHDM and never uses it.
MMIO_LOWER_CHUNK_PAGES 🔒
Pages one MMIO lowering step rewrites under one KERNEL_ROOT hold and invalidates with one shared flush (2 MiB): it bounds how long the lock is held with interrupts masked, at 128 flushes for a 256 MiB ECAM claim.

identity_map_refused 🔒
Refuse an identity (VA == PA) map of physical [start, start + len) when it reaches the VA the kernel allocates (va_alloc::overlaps_allocated_va: the cell slots and the stack arena), whose leaves it would overwrite or alias. Logs the refusal, naming what, rate-limited (refusal_to_log); true means refused, and the caller maps nothing and fails with its own error (or, for a boot window, treats the device as absent). RAM never reaches the slots: the frame allocator manages none there (va_alloc::IDENTITY_RAM_END).

restore_mmio_run
Clear USER on the pages pages from page-aligned start, in steps of MMIO_LOWER_CHUNK_PAGES: each step’s mapped leaves are rewritten and the whole step, absent leaves included, is invalidated with one shared flush (protect_mapped_range). Every page is attempted, even after one failed. Once a step’s flush is unconfirmed the lowering has failed (its window is quarantined), so the remaining steps still rewrite their leaves but only request their flushes, without waiting a probe bound each. Returns the pages cleared, or the first failure.
