pub fn restore_mmio_run(
    start: usize,
    pages: usize,
    await_flush: &mut bool,
) -> Result<usize, (usize, PageTableError)>
Expand description

Clear USER on the pages pages from page-aligned start, in steps of MMIO_LOWER_CHUNK_PAGES: each step’s mapped leaves are rewritten and the whole step, absent leaves included, is invalidated with one shared flush (protect_mapped_range). Every page is attempted, even after one failed. await_flush is the caller’s one flag for its whole lowering: once a flush is unconfirmed the lowering has failed (its window is quarantined) and the flag is cleared, so every later step and run of that lowering still rewrites its leaves but only requests its flush, without waiting a probe bound each. Returns the pages cleared, or the first failure.
