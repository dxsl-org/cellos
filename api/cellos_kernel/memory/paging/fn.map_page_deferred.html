map_page for one page of a batch whose invalidation the caller issues once, with flush_deferred_maps over the batch (Cell ELF segments, phase 07b R1, owner grant s2-phase07b-flush-batching-grant.md). Now that map_page records into a batch on every arch, the two are one function; the name keeps the loader’s contract visible.

Precondition: the leaf is new (absent before this call) or only gains rights over what it already maps. Never use this to re-point a present leaf to another frame or to remove a right, and never free a frame a leaf mapped this way referred to before the batch has been finished — until then another CPU may still hold the old translation.
