Expand description

The allocation charge open on this hart, restored on drop.

Only three kinds of code open one: syscall entry (Charge::dispatched()), an owner-directed allocation (the incarnation that owns the object), and a kernel scope (Charge::KERNEL) for kernel bookkeeping. Every interrupt entry opens ChargeScope::interrupt first, and yield_cpu holds a kernel scope across each switch, so no scope crosses a switch or reaches an interrupt handler. A scope dropped on another hart than it was opened on restores that hart: the activation, not the hart, owns it.
