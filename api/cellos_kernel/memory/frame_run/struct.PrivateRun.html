Struct PrivateRun 

Source 
pub struct PrivateRun(Option<FrameRun>);
Expand description

A run no shared root maps: the kernel reaches it only through its own alias of RAM (Intact), and hardware reaches it only through structures its owner tears down itself. Hypervisor control structures (VMCB, VMCS, MSR/IO bitmaps, the xAPIC page), nested and Stage-2 tables, and a VM’s guest RAM are such runs (RunKind::VmStructure, PageTable, Leaf).

Its release has nothing to unpublish and nothing to flush in the shared root, so dropping it frees the frames (through a Batch, which quarantines them for the reaper on a hart that may not take the allocator). The owner drops it only once nothing else can reach the frames: the VM left its registry, so no vCPU can enter it; its VMCS was cleared; its nested or Stage-2 translations were invalidated. An error path that drops a structure no VM ever used frees it the same way, so a partial construction never leaks (census §5).
