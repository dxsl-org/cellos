Expand description

The machinery a release needs, separated so host tests drive the same state machine with a fake acknowledgement source and allocator.

Required Methods§

Source

fn completed(&self, hart: usize, epoch: usize) -> bool

Has hart published epoch (0 = never asked)?

Source

fn reissue(&mut self, asid: Option<usize>) -> Epochs

Ask every online remote hart again (flushing asid locally first, if any) and return the epochs requested.

Source

fn normalise(&mut self, run: &FrameRun) -> bool

Restore the frames’ kernel alias before free (KernelAlias ≠ Intact). false: not restored (no page-table frame); the run must not be freed.

Source

fn free(&mut self, base: PhysAddr, pages: usize, hold: Option<VaHold>)

Return pages frames at base to the allocator, then release hold in the same allocator hold: no allocation can take the frames back between the two, so a new owner’s reservation of the same range is never the one released.

fn tag_ack_withheld(&self) -> bool

Test-hooks seam: is every private tag’s acknowledgement withheld? A tag entry then stays unconfirmed whatever its epochs say.

Source

fn tag_wait_ended(&mut self, _asid: usize)

Private tag asid’s wait has ended (its slot, if the entry held one, is already back in its pool): work that skipped the tag while it was unconfirmed may run again.
