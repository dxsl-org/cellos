Expand description

A run of physical frames with one charge and one release protocol.

Dropping a run that is not RunState::Free never frees it: the frames are leaked (counted in Counters::leaked) because nothing proves them safe.

Mapped → Quarantined(reason) for a long holder (pin, lease, DMA export, revoking domain record, live VM): its PTEs stay, because the holder still dereferences them. Invalidation reasons are refused: they arise only from an unconfirmed flush of an unpublished run.

fn free(&mut self, backend: &mut impl Backend) -> Result<(), StateError>

Unpublished | Quarantined(epochs) → Free: normalise, free, release the VA hold, refund the charge. Only callers that proved the invalidation reach this, whichever context they run in (the owner’s syscall, retirement, the hart-0 reaper in the timer interrupt). A run whose alias cannot be restored is not freed: it keeps its state (still freeable) and the Err carries it, for the caller to quarantine as Reason::AliasUnrestored.
