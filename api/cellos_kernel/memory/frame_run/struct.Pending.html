Quarantined runs, one entry per wait (one per private tag, one for shared invalidations, one for RFENCE fallbacks, one per event key).

pub(crate) fn push(&self, run: FrameRun, epochs: &Epochs)

Record a quarantined run; epochs are the requests an invalidation reason waits for (ignored for an event key).

Runs that wait on the same thing share an entry (same tag, any shared flush, any RFENCE fallback, the same event key); merged epochs take the per-hart maximum, which only ever waits longer. Built with try_reserve: teardown must not panic on heap, so a run that cannot be recorded is leaked (counted), never freed.

pub(crate) fn try_push( &self, run: FrameRun, epochs: &Epochs, ) -> Result<(), (FrameRun, &'static str)>

Self::push for a caller that holds a lock the console ranks below (the pin registry): a run that cannot be recorded is handed back, for the caller to Self::forget_unlogged and log once its locks are released. Never frees it.

pub(crate) fn defer_tag( &self, asid: usize, runs: Vec<FrameRun>, tag_slot: Option<TagLease>, epochs: &Epochs, ) -> TagWait

Wait for private tag asid until epochs are published: quarantine runs (unpublished: the private root no longer maps them) behind it and, with tag_slot (the lease of tag asid), keep that root’s tag reserved until the same entry completes. An entry is recorded even with no run: it is what makes the tag read unconfirmed (Self::tag_unconfirmed).

Nothing waits here and nothing is freed. A wait that cannot be recorded (no heap) leaks its runs (counted), drops the lease (so its tag stays reserved for the boot), and makes every tag read unconfirmed from then on: fail closed.

pub(crate) fn reap(&self, backend: &mut impl Backend) -> usize

One reaper pass: step every entry once. An entry whose epochs are all published is removed and its runs normalised and freed outside the lock; the others count an attempt and are reissued every REISSUE_EVERY. A run whose alias cannot be restored stays quarantined and is retried on the next pass (never within this one). Event-keyed entries are left to Self::release_event. Never waits on a hart. Returns the pages freed.
