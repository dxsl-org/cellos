Expand description

One operation’s shared-root invalidation and the runs it frees.

Owners record every changed translation (Self::invalidate) and hand over every unpublished run (Self::retire); Self::finish then flushes once and frees or quarantines the runs. A cell teardown is O(operations) broadcasts, not O(pages). Dropping an unfinished batch finishes it (without waiting when the cap is unavailable), so a forgotten finish can never free a frame under a live translation.

pub fn await_tag(&mut self, asid: usize)

Every run retired into this batch also waits for private tag asid, whose bounded probe did not confirm after the caller unmapped the frames from that domain root. The runs are then quarantined as Reason::TagUnconfirmed whatever the shared flush says, and the reaper frees them once every remote hart has published an epoch asked for after this flush.

pub fn invalidate_range(&mut self, start: VAddr, size: usize)

The translations of [start, start + size) changed in the shared root. Adjacent ranges merge; with no heap for a new range, or a range that wraps the address space, the batch widens to a full invalidation rather than drop one.

pub fn invalidate_all(&mut self)

Source

pub fn drain_user_copies(&mut self)

Wait out open SAS user-copy windows after the flush and before any free (census §7.2 step 5): a copy that probed a page earlier must not land in its frame once it is reused.

Source

pub fn retire(&mut self, run: FrameRun)

Free run after the flush confirms; quarantine it otherwise. The run must be Unpublished. With no heap to hold it the run is leaked (counted), never freed.

Source

pub fn hold_va(&mut self, hold: VaHold) -> bool

Keep hold reserved until the last run retired so far is freed (an owner whose VA must outlive its frames’ invalidation, census risk 2). false when there is no such run, or it already holds a range: the caller keeps the VA and releases it itself.

Source

pub fn finish(self, cap: &mut FlushCap) -> FlushOutcome

Flush once, wait for the copy windows, then free every run or quarantine it. Returns the flush outcome; an unconfirmed one is logged.

Source

pub fn complete(self) -> FlushOutcome

Self::finish with this hart’s cap, or — when it holds the frame allocator and so may not wait — Self::complete_without_wait.

Source

pub(crate) fn complete_without_wait(self) -> FlushOutcome

The local flush plus the remote requests, without waiting for any answer, for a hart that may not wait (it holds the frame allocator, or runs the timer reaper). Nothing is freed here — a free takes the frame allocator — so every run is quarantined behind the epochs asked for (none on a single hart: the next reap frees it) and the reaper frees it.
