Expand description

A published private root. The root field is declared last so table/page frames drop first.

pub fn begin_execution(&self, hart: usize) -> Result<(), AddressSpaceError>

Pins this hart as an executor of this root, failing closed against the selection-time TOCTOU where retirement lands between the Live check and the pin. Mirrors acquire_copy_reader’s double-check: a retirement that races the pin makes it unavailable, while retirement AFTER a successful pin is legal — the set bit pins the space against teardown drain until the owning hart clears it on its next transition away from this root.
