A bounded set of tags with a per-owner limit. See the module docs.

Fields§

§first: u32§span: Span§reuse: Reuse§per_owner: u32§used: [AtomicU64; 4]

Reuse::AfterInvalidation: bit i set while first + i is held.

§issued: AtomicU32

Reuse::Never: how many values were issued.

§held: [AtomicU64; 64]

Per CellId: the holding incarnation’s generation (low 32 bits) in bits 32..64, its lease count in bits 0..32. A row naming another generation counts 0 for this one, and a release by a retired incarnation leaves the next one’s count alone.

pub(crate) fn acquire( &'static self, owner: Charge, ) -> Result<TagLease, TagRefusal>

Lease the lowest free value (the next unissued one for Reuse::Never) to owner.

The owner limit is checked first, so an owner at its limit is refused with TagRefusal::OwnerLimit even when the pool is also exhausted. A refusal takes nothing. While an acquire of the same owner is in flight and about to fail on exhaustion, another may transiently read that owner one lease higher.
