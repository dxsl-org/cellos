Module tag_pool 

Source
Expand description

One allocator for architectural tags (private-root ASIDs, VMIDs, SVM ASIDs) with a per-owner limit. One allocator for the architectural tags that name a translation context: private-root ASIDs/PCIDs, AArch64 Stage-2 VMIDs and x86 SVM ASIDs (census §8.5).

A [TagPool] hands out each value in first..first + count to at most one [TagLease] at a time, and at most per_owner leases to one incarnation ([Charge]). [Charge::KERNEL] is exempt from the owner limit: kernel fixtures and kernel-owned roots are bounded by the pool alone.

Reuse is the pool’s contract, not the caller’s:

  • [Reuse::AfterInvalidation]: a value goes back only through [TagLease::release], which takes an [Invalidated] proof for exactly that value. The proof exists only once the invalidation that drops every TLB entry tagged with it, on every hart, has completed.
  • [Reuse::Never]: a value is issued once per boot.

A lease dropped without release or cancel keeps its value reserved and its owner counted for the rest of the boot. That is the fail-closed answer for a tag whose invalidation was never confirmed: it is never silently reissued.

Lock-free: every operation is a CAS or a fetch on one word, so a release from the hart-0 timer reaper or under any spinlock takes no lock rank.
