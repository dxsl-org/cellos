pub fn protect_mapped_range(
    start: VAddr,
    pages: usize,
    new_flags: Flags,
    await_flush: &mut bool,
) -> Result<usize, (VAddr, PageTableError)>
Expand description

Rewrite the permission bits of every mapped page of the pages pages from page-aligned start, then invalidate the whole range on every hart with ONE shared flush, before returning either way (one step of the MMIO lowering, paging::restore_mmio_run).

  • An absent leaf is skipped, not an error, but the flush still covers it: a translation removed without one may still be cached.
  • A leaf that cannot be rewritten does not stop the pass: every other page is still lowered and flushed, so a failure never leaves more pages reachable than it must.
  • KERNEL_ROOT is held from the first leaf write through the flush, as protect_pages holds it.
  • await_flush: wait for every hart to confirm the flush. An unconfirmed flush clears it (and is logged), so the later steps of the same lowering only send their requests: the lowering has already failed, and a silent hart would otherwise cost each step a full probe bound.

Returns the pages rewritten.

§Errors

The first page that could not be rewritten, else (start, InvalidationUnconfirmed) when the flush is not confirmed on every hart (without await_flush, whenever a remote hart was asked).
