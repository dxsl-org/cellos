Struct Reservation 

Source 
pub(crate) struct Reservation {
    charge: Charge,
    account: Account,
    bytes: usize,
}
Expand description

Bytes taken from one account of one incarnation, refunded once on drop, to that incarnation only (a no-op once the slot was re-registered).

Source

pub(crate) const fn kernel(account: Account) -> Self

The kernel’s budget for an object that draws frames over its life (a kernel-owned VM’s tables): every split succeeds and nothing is counted.

Source

pub(crate) fn split(&mut self, bytes: usize) -> Option<Self>

Draw bytes down into a reservation of their own, same owner and account; None, changing nothing, when fewer remain.

Source

pub(crate) fn keep(self)

Leave the bytes charged with no owning object. They return only through refund with the same charge and account, or at deregister.

Source

pub(crate) fn into_parts(self) -> (Charge, Account, usize)

Hand the bytes to an object that refunds them itself (a FrameRun when its frames are freed): they stay charged, and the parts name the refund.
