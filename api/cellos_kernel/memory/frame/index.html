Physical frame allocator for ViCell kernel.

Manages physical memory frames (4KB pages) using a Bitmap Allocator. This allows for O(1) allocation and deallocation (amortized) and frame reuse.

plan_managed_ranges
Normalize a memory map into the set of usable ranges the allocator manages: every usable frame below IDENTITY_RAM_END, the first cell VA slot. Grants and SHM pages keep their physical address as VA, and RV64/AArch64 map all RAM there, so RAM at or above it would alias the cell slots or the stack arena; it is left unused and counted in ManagedPlan::unmanaged_above, and the machine boots with the rest.
