pub fn retry_quarantined_windows() -> usize
Expand description

Lower every quarantined window again and release those whose lowering is now in force on every hart. The housekeeping pass calls it; it acts only when the timer poll armed it (RETRY_ARMED) and no remote hart owes an invalidation, and it lowers without REGISTRY, as release_mmio_for does. Returns the windows still quarantined.
