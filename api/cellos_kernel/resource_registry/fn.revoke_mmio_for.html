pub fn revoke_mmio_for(
    cell_id: CellId,
    device_mask: MmioClass,
) -> Vec<(usize, usize)>
Expand description

Release the regions owned by cell_id whose class is in device_mask, and return their (base, len) so the caller can remove user accessibility.

Selective by construction: a class the caller did not name stays owned and mapped, so revoking one device class never disarms another. Used by runtime revocation (sys_cap_revoke); Cell death uses release_for, which drops every region regardless of class.
