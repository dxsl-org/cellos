pub fn release_mmio_for(tid: usize)
Expand description

Release all MMIO regions owned by task tid.

Retirement calls this for every member task of the retiring incarnation. The windows’ USER pages first go back to the boot posture (kernel-only) on every architecture: RequestMmio installed them, so without this a dead Cell’s window would stay U-mode/EL0/ring-3-reachable for every other Cell. The windows pass to RELEASING_OWNER first, under REGISTRY, so every claim on them is refused; the lowering then runs without REGISTRY, which ranks after KERNEL_ROOT and the console that the lowering takes. A window is released only once its lowering is in force on every hart. A window whose lowering is not (a remote hart did not confirm the invalidation, or the leaf could not be rewritten) stays registered to QUARANTINED_OWNER — counted, logged, and handed to no Cell — because a stale USER translation may survive on that hart, until retry_quarantined_windows lowers it again and that lowering is confirmed.
