pub(crate) fn release_unowned_routes(tid: usize)
Expand description

Unbind the NIC and block routes of tid whose device it no longer owns: a runtime capability revoke freed those devices (ownership::release_for, ownership::release_mmio_devices_in) while the task lives on, so a replacement’s 416/417 must find the route vacant. A route on a device it still owns (the DWC2 aperture, held by UsbDriverCap) stays. A lost NIC primary passes to the next live route as at exit; with none, the active service::NIC_DRIVER row naming tid is removed, so the net service does not keep resolving to a driver without a device, and the next registration takes the primary.

Syscall context, without SCHEDULER held; same ROLE_PUBLICATION transaction as registration and exit teardown.
