pub(crate) fn publish_block_route(
    key: DeviceKey,
    provider: (usize, u64, u64),
) -> Option<usize>
Expand description

Bind key’s route to provider and return its slot index.

The caller holds SCHEDULER and has proven that provider owns key, so publication shares the role transaction with exit teardown. A key already in the table keeps its slot: an empty provider or the same tid is (re)bound, a different live provider is refused. A new key takes the next free slot. None means refused (live foreign provider or full table) and leaves the table unchanged.

Logged at warn! for the same reason as set_input_cell: Driver Cells are spawned by init AFTER the kernel drops its log level to Warn, and the registration line is the marker the block-driver integration tests assert.
