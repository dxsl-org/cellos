Expand description

Bind the NIC route of key to provider.

The caller holds SCHEDULER and has proven that provider owns key (owned_network_device). The slot rules are those of publish_block_route: a known key keeps its slot and rebinds an empty provider, the same tid or a holder that no longer owns key; a holder that still owns it is refused; a new key takes the next free slot. The bound route becomes the primary when no other route is (NIC_ROUTES.primary) or when it already was (a rebound stale primary), and only then is publish_primary — the service::NIC_DRIVER publication — called; if it fails, the bind is rolled back. A secondary route is bound without touching the service. None means refused, with the table unchanged.

warn! — see publish_block_route. The line keeps the prefix the NIC lanes match and gains the device and route.
