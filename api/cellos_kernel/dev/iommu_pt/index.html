Module iommu_pt 

Source
Expand description

Helpers shared by the DMA remappers’ page tables.

The tables themselves live with their backend (VT-d iommu_x86::slpt::VtdSlpt, RISC-V iommu_riscv::sv39::Sv39IommuPt). Both map IOVA == PA for explicitly registered DMA ranges, so any other IOVA faults at the unit. This module holds what they share: the table page allocator, kernel-heap address translation, and the boot-time teardown probe.
