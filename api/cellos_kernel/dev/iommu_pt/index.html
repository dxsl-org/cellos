Module iommu_pt 

Source
Expand description

Identity-mapping IOMMU page tables for DMA isolation.

Both table types map IOVA == PA for explicitly registered DMA ranges. Any other IOVA causes an IOMMU fault — preventing arbitrary RAM access via DMA.

Sv39IommuPt — RISC-V IOMMU second-stage (Sv39, 3 levels) VtdSlpt — Intel VT-d second-level page table (3 levels, AW=39-bit)
