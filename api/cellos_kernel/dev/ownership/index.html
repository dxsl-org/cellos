Module ownership 

Source
Expand description

Per-device ownership records (architecture remediation Phase 18).

One DeviceRecord per device a Driver Cell can own: a PCI function, a VirtIO MMIO slot, or the DWC2 USB aperture. Each names the device’s owner, its claimable windows, its interrupts and its DMA domain, so MMIO (RequestMmio), IRQ (435, WaitIrq, the MSI and VirtIO ISRs), DMA (GrantDma, DMA export) and route (416/417) checks answer from one record, and one release (release_for) frees it.

The owner is the claiming task id, the key every check used before. A dead owner’s records stay owned (quarantined) until its DMA teardown is acknowledged and its windows are released, so no replacement can claim the device, its windows or its vectors while hardware may still reach the old domain.

The table holds a record for every device the boot scan, the Platform Cell or a claim names, however many there are: records are appended only at registration and claim (boot and syscall context, charged to the kernel) and never removed, so release, teardown (which may run in the timer/IPI ISR) and every check only touch records in place and never allocate.
