pub fn quiesce_function(bdf: u32) -> Result<Quiesced, QuiesceError>
Expand description

Stop a function a dead driver owned from starting DMA or raising interrupts: clear Bus Master, set INTx Disable, and turn off MSI and MSI-X (masking MSI-X), each confirmed by readback.

The capability list is walked here, bounded by the same 64-entry budget as the scan, through range-checked config addresses; no cached or driver-supplied offset is used.

Clearing Bus Master stops new requests but does not prove that writes the device already posted have drained. The caller still needs the IOMMU fence before it releases any frame.
