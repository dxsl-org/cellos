Module pcie_ecam 

Source
Expand description

PCIe ECAM (Enhanced Configuration Access Mechanism) walker.

The kernel fallback scans one admitted bus, probing functions per the header-type multi-function bit. Exposes a kernel-internal device snapshot.

ECAM bases per machine: x86_64 : runtime ACPI MCFG (no q35 fallback) RISC-V virt : 0x3000_0000 AArch64 : none. The kernel discovers no config-space window there (devices are VirtIO MMIO), so it never touches PCI config space.

The Platform Cell may map and enumerate the complete firmware-admitted bus range. Kernel fallback enumeration remains bus-0-only on non-x86 targets.

Call ordering: platform::init() → init_kernel_paging*() → pcie_ecam::init().
