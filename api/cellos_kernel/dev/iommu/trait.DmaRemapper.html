Expand description

One family of DMA remapping hardware.

A domain holds the translations granted to one owner; a device joins its owner’s domain on the first mapping and leaves it when the owner’s domain is revoked. Firmware tables, page-table formats, cache write-back and interrupt remapping stay inside the implementation.

Source

Publish [phys, phys + len) at the export window [iova, iova + len) of owner’s domain for dev, read-only unless writable.

Source

fn unmap_window(&self, owner: DomainKey, iova: u64, len: usize) -> bool

Clear export window [iova, iova + len) from owner’s domain and flush its cached translations. true only when the flush was acknowledged.

Source

fn revoke(&self, owner: DomainKey) -> bool

Detach every device from owner’s domain, flush it and drop it. true only when hardware acknowledged the teardown.

Source

fn translating(&self, dev: DeviceKey) -> bool

Whether DMA from dev is translated.
