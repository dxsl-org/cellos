Shared VirtIO MMIO slot enumeration.

virtio_blk, input_irq_ack, and Driver Cells use virtio_slots() to iterate all VirtIO MMIO slots for the current platform.

AArch64: the board backend’s VirtIO MMIO window, if any. QEMU virt scans all 32 slots at 0x0a000000, stride 0x200; the Raspberry Pi boards expose no VirtIO MMIO window and yield no slots. QEMU assigns devices to slots in an implementation-defined order so we must probe all 32 there. The identity map in paging.rs covers the window wherever the backend declares one.

RISC-V: reads DTB-confirmed slots from platform::PLATFORM. PCIe-only arches expose no VirtIO-MMIO slots.
