Struct RiscvIommu 

Source 
pub struct RiscvIommu;
Expand description

The RISC-V IOMMU behind DmaRemapper: a domain per owner (one PSCID and one Sv39IommuPt), device contexts per requester. It has no export windows, and with no IOMMU found every DMA request is refused.
