pub unsafe fn switch(plan: SwitchPlan) -> IrqSaved
Expand description

Run plan through __switch.

Returns this activation’s interrupt token when it is resumed. On RV64 it is already spent: the resuming __switch restored this context’s sstatus.

§Safety

Both pointers must be valid context slots, plan.irq must have been saved on this hart, and plan.root must name a completed root this hart may run.
