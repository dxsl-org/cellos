icache: publishing loaded code to instruction fetch on every online hart.

RV64 instruction fetch is not coherent with stores, and the hart that dequeues a freshly loaded task may not be the one that wrote its code: the loader fences locally, asks every other online hart through SBI RFENCE remote_fence_i, and falls back to an IPI epoch served with fence.i.

ICACHE_SYNC_PROBE_TICKS 🔒
How long the IPI fallback waits for every asked hart’s fence.i before refusing the spawn: the same 200 ms budget a TLB probe gets.

Statics§

ICACHE_SYNC_COMPLETE 🔒
ICACHE_SYNC_REQUEST 🔒
Instruction-cache sync epochs: the IPI fallback a code publisher takes when SBI RFENCE remote_fence_i fails. Kept apart from the TLB epochs so a routine invalidation never pays for an instruction-cache flush. Served on the same trap path and in the same spin answers as the TLB request.
