Log RFENCE failures since the last report. The flush itself cannot log: it may run under KERNEL_ROOT, which ranks above the console. Called from the hart-0 reaper, which holds no lock.
shared_flush_local 🔒
The local half of a shared-root flush (tlb_shootdown::flush_ranges): sfence.vma per page (or all), then SBI RFENCE per range (or one over the whole address space). Only an RFENCE error leaves the remote harts to the IPI epoch path, which each serves with a full local flush.
