Expand description

The sstatus of the activation that called IrqSaved::save, with SIE masked until the token is dropped or handed to switch.

Dropping a live token restores the captured sstatus. switch consumes the token: __switch stores the value in the outgoing Context and the hart that resumes it restores it, so the token it returns is spent.
