sched: the scheduler’s context-switch seam.

The switch itself is the HAL’s: switch(SwitchPlan { out, inc, root, irq }). root: None writes no satp (see hal::arch::SwitchPlan).

Structs§

IrqSaved
The sstatus of the activation that called IrqSaved::save, with SIE masked until the token is dropped or handed to switch.
Root
A private root the switch programs between the outgoing save and the incoming load: the root table’s page number and its ASID.
SwitchPlan
One context switch: the outgoing and incoming contexts, the root to program between them, and the interrupt state captured before selection.

Constants§

MASK_AT_ENTRY
yield_cpu masks SIE on entry, before any scheduler lock or publication: cooperative yields can enter with SIE set, and masking only at __switch would leave the current/selected scheduler state interruptible.
REPORTS_DISPATCH
RV64 reports its harts through the SMP and self-test lines instead.
