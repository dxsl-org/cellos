Module cell_session 

Source
Expand description

CellSessionV1: scheduler-serialized operation, holder and launch authority. Rings belong to pipe.rs; Cell identity belongs exclusively to Scheduler.

Every transition below runs under the one SCHEDULER lock, so death, expiry, abort, cancel and commit race through a single canonical owner funnel. The only bookkeeping that is not allocation-free is reservation: the final commit_child consumes capacity promised during PrepareChild.
