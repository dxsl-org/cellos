pub(crate) fn while_live<T, E>( &self, not_live: E, publish: impl FnOnce() -> Result<T, E>, ) -> Result<T, E>

Run publish (check-dependent mapping and its recording) only while the grant is Live, holding the gate so revocation cannot begin in between.

Source

pub(crate) fn serialized<T>(&self, f: impl FnOnce() -> T) -> T

Run f serialized with publication without consulting the state (a receiver drain must never interleave with a half-published receiver).
