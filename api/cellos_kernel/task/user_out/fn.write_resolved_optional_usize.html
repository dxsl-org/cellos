Write a slot resolved by resolve_optional_usize_slot.

The slot is user memory, so the write goes through the caller’s copy view (the user-copy window: STAC/CLAC under x86 SMAP), never a raw store. It runs after the caller’s result is committed (lease and publish) and can still fail: when the caller’s stack or address space is no longer live by then, e.g. a sibling thread killed a private-root domain between publish and this write (its is_live() turns false). The result then stands, the slot keeps its old value, and the failure is counted and logged. Callers must not hold a grant-table lock here.
