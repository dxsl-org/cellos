Module guard 

Source
Expand description

Per-hart recoverable-fault guard: window arming, the guarded byte-copy core, and the trap-facing glue contract. The RV64 trap handler routes guard-owned page faults here by rewinding sepc to the landing pad published in user_copy_guard_resume_pc.

Structs§

GuardWindow 🔒
Arm the per-hart recoverable-fault window. Interrupts are masked FIRST so a timer preempting mid-window can never switch tasks with the guard set; the active flag publishes last (Release) so the trap hook never sees an armed guard with an unpublished range.

Functions§

clear_guard_for_context_switch 🔒
Defense-in-depth: a hart switching tasks must never carry an armed guard into the next task. The guarded window masks interrupts, so in the current design this can only fire if a future change reintroduces preemption mid-window; clearing costs one store either way.
commit_guarded 🔒
Run one byte-copy chunk inside the per-hart recoverable fault window.
guarded_byte_copy 🔒 ⚠
Byte-copy loop with a trap-recoverable error landing pad (local label 3). Direction-neutral: reading src and writing dst byte-by-byte covers both copy directions through the boundary; the caller picks which side points at user memory and publishes the matching guard range.
