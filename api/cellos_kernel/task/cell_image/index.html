Kernel side of ResolveCellImage (syscall 441, api::cell_image).

The identity lives on the Cell’s root task (Task::bind_image), bound from the admission measurement before the task is published and never rewritten. It is reached only through the live owner slot, so the answer is always for the exact (cell_id, generation) asked about: a respawn under the same CellId is a different generation with its own root and its own image, and a dead or stale generation has no answer at all.
