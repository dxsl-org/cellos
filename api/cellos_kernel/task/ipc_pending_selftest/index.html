Boot self-test for receiver-owned IPC delivery.

Runs after scheduler initialization and before secondary harts start. Each producer receives a synthetic Recv task whose buffer pointer is deliberately invalid: success proves the producer queued owned bytes without touching the foreign buffer. Teardown removes every synthetic task and ready-queue entry.
