pub struct Stack {
    pub base: VAddr,
    pub pages: usize,
    pub guard_pages: usize,
    pub top: VAddr,
    run: Option<FrameRun>,
    in_arena: bool,
}
Expand description

Represents an allocated Stack. Implements Drop to automatically free pages.

Placement: a kernel stack is one contiguous run identity-mapped at its physical address (VA == PA), guard frames included and unmapped. A user stack is a contiguous run of only its usable frames, mapped USER RW at base + guard_pages * PAGE_SIZE inside a stack-arena slot (loader::va_alloc::alloc_stack_va); its guards are VA with neither a leaf nor a frame behind them, and its frames keep their kernel alias. Either way the run backs the top run.pages() pages of [base, top).

Base address (lowest address) of the allocated range. This includes the guard pages at the bottom.

Number of usable pages (excluding guard pages).

Number of verified-unmapped pages below the usable range.

§top: VAddr

Top of the stack (initial SP).

§run: Option<FrameRun>

The frames (a kernel stack’s guards included); None only once retired (or for a host test’s stack, which owns no frames).

§in_arena: bool

base is a stack-arena slot (a user stack), returned with the frames.

pub fn new_kernel(pages: usize) -> Result<Self, ViError>

Allocate a new Kernel Stack of pages usable pages plus the configured bottom guard reservation, owned by the kernel and billed to nobody.

§Errors
  • OutOfMemory — no contiguous run of usable plus guard frames exists, or a page-table mapping could not be installed.
  • NotSupported — every guard page could not be established. No stack is returned in that case; see Self::allocate.

pub fn new_user(pages: usize) -> Result<Self, ViError>

Allocate a new User Stack of pages usable pages below STACK_GUARD_PAGES unmapped guard pages, in a stack-arena slot (see Stack), owned by the kernel and billed to nobody. Usable pages are mapped USER RW.

§Errors

Same as Self::new_kernel, plus OutOfMemory when every arena slot is held or the stack does not fit one.

fn allocate( pages: usize, guard_pages: usize, user_mode: bool, bill: RunBill, ) -> Result<Self, ViError>

Internal allocation logic.

Contract: this either returns a stack whose guard page is verified absent from the page tables, or it returns an error having released every frame it took. There is deliberately no third outcome. An unguarded stack is not a degraded stack — in a single address space the frame below it belongs to another cell, so an overflow that should have trapped instead corrupts a neighbour with no fault and no log, and the victim dies later somewhere unrelated. A log line at allocation time is not a mitigation: nothing reads it in the microseconds before the overflow.

fn allocate_kernel_in( allocator: &mut FrameAllocator, batch: &mut Batch, pages: usize, guard_pages: usize, total_pages: usize, bill: RunBill, ) -> Result<Self, ViError>

A kernel stack, with the frame allocator held: one contiguous run of total_pages frames identity-mapped kernel RW at its physical address, its bottom guard_pages frames unmapped. Every changed translation, and on failure the whole run, goes to batch.

fn allocate_user_in( allocator: &mut FrameAllocator, batch: &mut Batch, pages: usize, guard_pages: usize, total_pages: usize, bill: RunBill, ) -> Result<Self, ViError>

A user stack, with the frame allocator held: a stack-arena slot, and one contiguous run of pages frames mapped USER RW right above the slot’s guard_pages guard pages. The guards are never mapped and have no frame; the frames’ kernel alias is never touched (KernelAlias::Intact). Every new translation, and on failure the run and the slot, goes to batch; the slot returns only after the batch’s flush (VaHold).

pub fn zero_usable(&self)

Zero the usable pages through the frames’ kernel alias (frame::phys_to_virt), never through the stack’s own VA: a user stack’s VA is a USER mapping, which the kernel writes only inside a user-access window. Frames come back from the allocator holding their last owner’s bytes, so every spawn path zeroes a stack before it runs.

fn retire_without_drop(self, batch: &mut Batch)

Tear this stack down as part of a larger operation: its run joins batch, whose one shared flush covers every owner retired into it, and is freed — or quarantined, reservation included — when the batch finishes. A p01 obligation the stack still holds is dropped unfinished.

Source

pub(crate) fn retire_behind_tag(asid: usize, stacks: [Stack; 2])

Tear a thread’s stacks down after their unmap from a domain root could not confirm private tag asid: a remote hart may still resolve the stale private entry, so the runs are quarantined behind that tag (and a fresh epoch from every remote) whatever the shared flush says, and the reaper frees them — reservations with them — once it is confirmed. Before this phase they were forgotten and never reused (census F5).

The caller settles any p01 obligation first; one still held is dropped unfinished, as the old mem::forget did.
