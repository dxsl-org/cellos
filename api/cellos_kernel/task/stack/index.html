Stack Management for Tasks.

Handles allocation, deallocation, and guard pages for Kernel and User stacks. Complies with Rule 2 (Owned Buffers / Memory Safety) and Rule 8 (Resource Management).

Functions§

overlaps_stack_reservation 🔒
Does [start, end) overlap a live stack run, guard pages included? The ELF loader refuses such pages: an unmapped guard is not a free VA.
release_stack_reservation 🔒
VaHold release for a kernel stack’s run: only now are its guard VAs identity-mapped again, so the loader’s collision check takes over.
release_stack_slot 🔒
VaHold release for a user stack: nothing translates any page of its arena slot on any hart, so the slot may be handed out again.
retire_run 🔒
Hand a stack run mapped at va to batch: unmap each of its pages (recording the shared-root invalidation), detach the tables only the run needed where no alias is restored (x86_64, and every user stack, whose frames keep their kernel alias), and retire the run, which the batch frees only once that invalidation is confirmed — restoring its kernel alias first where the run says so.
unpublish_user_frames 🔒
Retire pages user-published pages at VA base (a stack, or a grant at its physical address) from the shared root before their frames return to the allocator.
