Static PARK_RELEASE

static PARK_RELEASE: [AtomicUsize; 8]
Expand description

The latest epoch released by a requester. A target parks for request E only while PARK_RELEASE < E, so this single store is both “resume” and “cancel a request that was never satisfied”. It is monotone (fetch_max), which is what makes release_park idempotent and safe for a hart that never acknowledged.
