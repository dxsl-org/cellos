Expand description

Proof that the harts were parked, releasing them when dropped.

Fields§

§state: &'a QuiesceState§harts: &'a dyn QuiesceHarts§requested: HartSet

The harts that were actually asked to park (empty on the no-op and the refusing paths, so release never touches a hart this protocol did not park).

§epochs: [usize; 8]

The epoch each requested hart must acknowledge, indexed by hart id.

§released: bool
