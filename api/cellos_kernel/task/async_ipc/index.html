Module async_ipc

Kernel-owned, bounded request/reply operations. All transitions are serialized by SCHEDULER; neither a reply nor a wake depends on caller-owned memory.

Operations
Task-local, kernel-charged storage. Tokens are global monotonic identifiers, never slot indexes; reuse after take cannot alias a late service reply.
