The multi-source wait: any mask other than a lone NET_RX or TIMER.

One reservation (slot) serves every source. Each round resolves NET_RX readiness outside SCHEDULER (its leaf lock is never taken under it), then selects under SCHEDULER with select_locked, where every IPC terminal transition is serialized too. A chosen IRQ line is taken outside SCHEDULER under the allocation lock, which re-checks ownership. Nothing ready parks through publish_wait_state_locked, which re-checks the mailbox, pending IPC notifications and the IRQ snapshot in the same hold that publishes the state. Exactly one source is reported; a NET_RX observation that is not reported goes back to the level flag, an IPC notification that is not reported stays latched, and so does an IRQ line.
