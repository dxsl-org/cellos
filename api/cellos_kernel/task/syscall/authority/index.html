commit_cap_revoke 🔒
Withdraw cap_mask from the target’s Cell incarnation after its Class-2 teardown has finished: re-run the gate, then narrow the incarnation record (root_tid’s Task::rights, captured before the teardown) that every thread of the Cell is gated on. The record is narrowed even if the target thread exited meanwhile; only a retired incarnation (root gone) has nothing left to narrow. Returns whether the target itself is still present. Takes SCHEDULER only.
