Expand description

Resolve one grant row for a capable domain receiver.

Returns the resolved base on success and the established usize::MAX “not authorized” sentinel for every refusal: an unresolvable or non-domain receiver, a SAS-owned record, an unresolvable or dying owner, a record that is not Live, missing or unsupported rights, a partial receiver mapping, or an unacknowledged rollback invalidation.
