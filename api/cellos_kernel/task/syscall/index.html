DENIED_RIGHT 🔒
Audit detail of an admission refusal: the allowlist bit that was missing, or DENIED_RIGHT | the opcode’s bit when the bit was present but the edge withholds its observation right, or u32::MAX for an unknown opcode or a caller that is not live.

Raw opcodes outside ViSyscall that the trap decodes, with the allowlist bit that gates each (None = always permitted). Feature-gated raw opcodes are handled where their feature is.

TRUSTED_INIT_TID 🔒
Tid of trusted init, published once by loader::governed_spawn::spawn_init right after init’s task is committed; zero before. It keys the MACHINE_PIN registration restriction, so that restriction never trusts a spawner-chosen task name. Tids are never reused, so a dead init’s tid cannot be taken over.
