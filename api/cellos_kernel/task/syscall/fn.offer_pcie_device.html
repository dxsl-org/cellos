Expand description

Serialize a matched PCIe device into the 48-byte PcieDeviceInfo wire record (padded from the 44 meaningful bytes by vendor_id/device_id alignment) and write it to the caller’s out_ptr.

Shared by the class-triple (FindPcieDevice) and exact-identity (FindPcieDeviceByVendor) queries so the two hand-out paths cannot drift. Claims BDF ownership first and returns 0 without writing when a live Driver Cell already owns the device.
