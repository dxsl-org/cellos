Constants§

MAX_USER_BUF 🔒
Maximum bytes a single syscall may read/write through a user buffer. Bounds kernel work per syscall and acts as a coarse sanity check against len = usize::MAX style attacks. 64 MiB is well above any legitimate caller need today; tighten further for specific syscalls (see MAX_LOG_MSG).
