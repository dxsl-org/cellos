pub(crate) fn release_acked_frames(tid: usize)
Expand description

Return quarantined frames owned by tid to the allocator once the driver has acknowledged that nothing can still reach them.

The acknowledgement point is iommu::cleanup_cell(tid): with the cell’s IOTLB entries flushed and its DDT/context entries zeroed, no device it authorised can address the frames. Call this immediately after that teardown, and only with a task id — the pin registry is keyed by task, not by cell.

Order-insensitive with respect to reap_grants_for_task: an acknowledgement that arrives first drops the pins, so the reaper then frees the frames itself.

Must run with neither FRAME_ALLOCATOR nor SCHEDULER held.
