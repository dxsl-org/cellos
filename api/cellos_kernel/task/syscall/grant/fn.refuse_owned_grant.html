Refuse a GrantAlloc/GrantRegister row after alloc_owned_grant already published its frames. Those frames are a live row’s (refuse_duplicate_row), so the caller must keep no translation of them once that row frees them: every translation this allocation published is removed first, then the run is leaked (counted), never freed. Called with no table lock held.
