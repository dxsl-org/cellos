Expand description

Run publish for SHM handle handle while its row is held, if incarnation (cell, generation) owns it or the cell is its receiver; None otherwise. A caller in the owner’s cell first records receiver (a live target cell) as the receiver.

The publication runs under PAGE_GRANT_TABLE, the lock the owner’s retirement takes the row under (release_shm_for): a take that wins leaves no row, so nothing is published; a take that comes after sees the publication (the identity VA maps the frame) and unpublishes it before the frame is freed. Checked and published under separate holds, a receiver could map a frame USER RW after the retirement took its row, and keep it after the free. The caller completes the publication’s flush batch after this returns, with the lock released. Lock order: PAGE_GRANT_TABLE → whatever publish takes (FRAME_ALLOCATOR → KERNEL_ROOT for ShmMap).
