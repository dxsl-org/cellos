fn take_owned_row(

Expand description

Take id from table for its owner caller_id’s free, unless an in-flight operation still holds the region (refuse_if_pinned); None when the caller owns no such row.

The pin check runs inside the table lock (order: grant table → pin REGISTRY, a leaf), so a concurrent VFS GrantSlice or GrantDma cannot publish a pin between the check and the removal.
