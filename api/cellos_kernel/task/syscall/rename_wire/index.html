Module rename_wire 

Source
Expand description

The one VFS request the kernel sends itself: Syscall::Rename.

The kernel links neither wire nor postcard (Phase 13 A3), so it writes the postcard bytes of wire::ipc::VfsRequest::Rename { old, new } and reads wire::ipc::VfsResponse::{Ok, Err(u8)} by hand. The host test below pins both to postcard’s own encoding of the wire types (wire::ipc::encode).

Postcard layout: an enum is its variant index as a varint u32, then the fields in order; a &str is its byte length as a varint usize, then the UTF-8 bytes; a u8 is one raw byte. A varint is LEB128: seven bits per byte, least significant first, high bit set on every byte but the last.
