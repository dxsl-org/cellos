Struct TaskCopyView 

Source 
pub(crate) struct TaskCopyView(TaskCopyRepr);
Expand description

Execution view for byte movement performed on behalf of one task.

Derive it while holding whatever lock produced the &Task; the view owns its state afterwards, so guarded copies can run with that lock dropped.

pub(crate) fn write_scatter( &self, ranges: &[(usize, usize)], payload: &[u8], ) -> Result<(), ()>

Write contiguous payload bytes scattered across multiple destination user ranges (ptr, len).

Multi-destination write transaction: every destination is validated and staged (with reader pins retained for Domain views) BEFORE any byte is committed to user memory. If any destination fails, no destination is modified.
