Struct BucketClaims 

Source 
struct BucketClaims {
    publication: AtomicU32,
    rollback: AtomicU32,
    created: AtomicBool,
    rollback_ahead: AtomicUsize,
}
Expand description

Capacity claims against one (hart, priority) bucket.

Every field is read and written only while that hart’s ready leaf lock is held, so Relaxed atomics merely provide static storage. Invariant per non-empty claim set: queue.capacity() >= queue.len() + publication + rollback. Ordinary enqueue, steal destination and selection rollback all honor it; none can consume a claim or move it to another hart.

Fields§

§publication: AtomicU32

Slots promised to prepared, unpublished children.

§rollback: AtomicU32

Slots vacated by a selection that may still roll back.

§created: AtomicBool

The bucket key exists only because a publication claim created it.

§rollback_ahead: AtomicUsize

While rollback != 0: how many queued entries still precede the slot the pending selection vacated. Every removal from the bucket that takes an entry ahead of that slot (steal, remove_from_all) lowers it, so the rollback reinserts at the exact FIFO position, not a stale index.
