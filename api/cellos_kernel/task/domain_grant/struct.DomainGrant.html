pub(crate) fn publish( &self, root: &Arc<AddressSpace>, cell: CellId, generation: u64, rights: Flags, ) -> Result<(), DomainGrantError>

Publish rights for root at the grant’s physical base, replacing any previous receiver mapping.

The tuple (cell, generation, root, rights) is compared first: only a change revokes the old PTE. Every page is mapped transactionally; on any failure the pages already mapped are unmapped (with acknowledgement) and nothing is published.
