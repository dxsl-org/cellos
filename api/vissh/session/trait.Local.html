Expand description

The local side of the session.

Required Methods§

Source

fn trust(&mut self, key: &HostKey) -> Trust

Decide on the server’s host key. Only KnownExact lets the session continue.

Source

fn confirm_unknown(&mut self, key: &HostKey) -> Trust

Called only when trust answered Unknown, before anything else is sent: run the first-trust confirmation. KnownExact (the key is now stored) lets the session continue; any other answer ends it with that answer.

Source

fn password(&mut self, secret: &mut String) -> bool

Ask once for the password, after the host key was trusted. Write it into secret and return true, or return false to cancel. secret is wiped after use.

Source

fn identity(&mut self) -> Result<[u8; 32], Credential>

Publickey only, called once after the host key was trusted and the server listed publickey: the 32-byte ed25519 public key to offer. A refusal ends the login with that Credential. Never called in password mode.

Source

fn sign(&mut self, r: &SignRequest<'_>) -> Result<Signed, Credential>

Publickey only, called once after the server accepted the key (so an identity the server does not know never costs a passphrase): produce the signature for r. Never called in password mode.

Source

fn input(&mut self, buf: &mut [u8]) -> Input

Fill buf with local input.

Source

fn stdout(&mut self, data: &[u8])

Remote standard output (or, in PTY mode, the whole terminal output).

Source

fn stderr(&mut self, data: &[u8])

Remote extended data type 1 (exec mode only).

Source

fn resized(&mut self) -> Option<(u16, u16)>

A new terminal size since the last call, if any (PTY mode).

Source

fn progress(&mut self, phase: Phase, dispatch: Dispatch)

The session entered phase with dispatch (write-ahead: MayHaveRun is reported before the request frame exists).

fn checkpoint(&mut self, _point: Point) -> u64

The session reached point. The answer is how long to hold there, in ms, while only the transport is serviced (no packet is processed; at Point::RequestSent not even the request is written). Production answers 0.
