Module phy 

Source
Expand description

82574 PHY access through MDIC and copper autonegotiation.

MDIC layout (82574 datasheet §10.2.2.9): data 15:0, PHY register 20:16, PHY address 25:21, opcode 27:26 (01 write, 10 read), ready 28, interrupt-enable 29, error 30. The integrated PHY answers at address 1. MII register numbers and bits are IEEE 802.3 clause 22.

After a global reset the PHY restarts from its power-on defaults and STATUS.LU follows the PHY’s autonegotiation, so the cell restarts autoneg explicitly and then waits for link (bounded, see controller.rs).
