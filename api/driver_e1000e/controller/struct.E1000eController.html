fn new(mmio: MmioRegion, bdf: u32, kind: MacKind) -> ViResult<Self>

Bring the controller up on mmio (BAR0) for the function at bdf.

Source

fn program_rings(&mut self) -> ViResult<()>

Initial DMA-address programming and TX/RX enablement, in order: TX ring base, every RX descriptor, RX ring base, enable. Every address is an authorized IOVA.

Source

fn send_frame(&mut self, frame: &[u8]) -> ViResult<()>

Transmit frame (no FCS) and wait, bounded, for its write-back. IO when the slot to fill or the one after it was posted and never written back: the controller may still read the first, and posting would move the tail onto the second (one slot always stays empty).

Source

fn recv_frame(&mut self, out: &mut [u8]) -> usize

Take the next received frame into out; 0 when none is ready. Errored and multi-descriptor frames are dropped.
