Module rings 

Source
Expand description

Legacy TX/RX descriptor rings in GrantDma-authorized memory.

The 82574 keeps the 8254x legacy descriptor formats (datasheet §7.1.4 receive, §7.2.10 transmit), selected by RFCTL.EXSTEN = 0 and RCTL.DTYP = 00 (both reset defaults). Each descriptor is 16 bytes; one 4 KiB ring page holds every slot this cell uses. Volatile access to the rings goes through nic_driver::ring::DescRing, which bounds every slot.
