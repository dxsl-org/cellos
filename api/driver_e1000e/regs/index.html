Module regs 

Source
Expand description

82574 register map and the register-file seam.

Offsets and bits are from the Intel 82574 GbE Controller Family Datasheet, chapter 10 (register descriptions). Only the registers this cell touches are named. Where the 82574 differs from the 82540EM that /bin/e1000 drives:

  • EERD carries the word address at bits 15:2 and signals done at bit 1 (8254x: address at 15:8, done at bit 4);
  • MSI-X causes are routed per queue through IVAR and only reach a vector with CTRL_EXT.PBA_SUPPORT set;
  • ICR reports the per-queue MSI-X causes RXQ0/TXQ0 and the summary OTHER cause (bits 20, 22, 24).

RegisterFile is the only path to the device: MmioRegion implements it for the cell, and the host tests implement it with a fake register file.
