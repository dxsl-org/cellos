fp_context_test

Module regs 

Source
Expand description

The only unsafe in this crate: loading a known pattern into the whole floating-point register file, yielding, and reading the file back in one asm! block.

One block is the point: between the load and the read-back the only code that runs is the Yield trap and whatever the kernel schedules in the meantime, so a mismatch can only come from the kernel handing this task another task’s FP registers. Confined to this file, which is named in scripts/unsafe-allowlist.toml (class test-harness).
