pub(crate) fn pattern(thread: usize, round: u64) -> [u64; 33]
Expand description

A pattern no other (thread, round) produces: the thread id and round sit in the high bits, the register index in the low byte. fcsr uses only its architected bits (frm 5-7, fflags 0-4); frm stays a valid mode (0-4).
