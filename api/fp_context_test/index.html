Per-task floating-point register file regression test.

Two threads of one Cell alternate on the same hart. Each round a thread loads its own bit pattern into f0-f31 and fcsr, yields (so the other thread runs and loads its pattern), and reads the registers back. Every word must come back unchanged: the kernel owes each task its own FP state across a context switch. Before __switch saved FP state on RV64, the first round already read the peer’s pattern.

Markers (integration-test contract): [fp-context-test] thread 0 ok rounds=… [fp-context-test] FAIL thread=… round=… reg=… expected=0x… observed=0x… FP-CONTEXT-TEST: PASS
