Module input_producer 

Source
Expand description

Input producer frames into the input service, which the kernel emits itself (sender 0). wire::proto::input re-exports these at their service-contract path.

Producer frame: [kind][code u32 LE][value i32 LE], 9 B, from the kernel (sender 0), the UART relay or a registered producer. EV_DEVICE frames carry a device id first: [EV_DEVICE][device u32][kind][code u32][value i32]. These EV_* kinds are not the Linux evdev types of wire::vmm_session (there EV_KEY is 1).
