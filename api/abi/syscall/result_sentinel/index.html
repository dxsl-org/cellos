Module result_sentinel

Error sentinels of the generic syscall return encoding, as offsets below the all-ones “error” register value (usize::MAX on 64-bit, u32::MAX on RV32). One definition for the kernel encoder and the ostd decoders (architecture remediation Phase 08, Law-1 CP1); the values are frozen.
