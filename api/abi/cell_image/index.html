Module cell_image 

Source
Expand description

Kernel-measured image identity of one live Cell incarnation (syscall 441 ResolveCellImage).

The caller-identity trailer says which Cell generation sent a message, not what program it runs: a Cell’s only other name is the path its spawner chose. This record carries what the kernel measured at admission: the SHA-256 of the exact bytes, the anchor that verified the signature (if any), and the program name declared in IMAGE_NAME_SECTION.

The signature covers every ELF byte except its own 64 (kernel/src/signing.rs), so a signed image cannot change its name bytes without failing verification. The kernel reports a name only for a verified image, and a name is as trustworthy as its anchor: the dev seed is public, so under ANCHOR_DEV anyone can sign any name.

Invariants: recorded once at publication and immutable for the incarnation; resolved only for the exact live (cell_id, generation).
