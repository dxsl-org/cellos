cpp-freestanding runtime profile smoke cell.

Proves the profile end to end in a Tier 2 paged domain:

  1. the cell is admitted as an FFI-class Tier 2 cell (kernel marker),
  2. C++ static constructors ran (crt0 walks __init_array),
  3. virtual dispatch, templates, and new/delete work,
  4. file I/O works both ways: the VFS service over typed IPC and the shim’s C open/read/close ABI through the kernel file table.

Markers (integration-test contract): [cpp-smoke] static-ctor marker=0xC0FFEE11 [cpp-smoke] virtual-dispatch area=37 [cpp-smoke] templates total=64 [cpp-smoke] heap churn checksum=… [cpp-smoke] vfs client roundtrip bytes=… [cpp-smoke] c-abi read magic=ELF CPP-SMOKE: PASS
