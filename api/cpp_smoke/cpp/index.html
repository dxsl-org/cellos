C++ FFI boundary for the cpp-freestanding profile smoke cell.

Every unsafe in this crate lives here, behind safe wrappers that take and return plain values, so the host logic in main.rs reads as ordinary Rust. This file and the crate are both named in scripts/unsafe-allowlist.toml (class c-ffi): a C++ translation unit is outside the Rust type system by construction, exactly like the C FFI cells that came before it.
