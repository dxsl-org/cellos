/srv/sshd/authorized_keys: the only source of login authority.

Format, one key per line: ssh-ed25519 <base64 blob> [comment]. Blank lines and lines starting with # are skipped; a trailing \r is tolerated. Any other key type, option prefix (from=…, command=…) or malformed blob makes that line authorize nothing — sshd does not implement OpenSSH key options, so honouring the key while dropping its restriction would widen what the administrator wrote.
