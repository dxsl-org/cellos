SSH-2.0 server daemon for Cellos.

Listens on TCP port 22 and serves one connection at a time: curve25519-sha256 key exchange with a fresh per-connection scalar, the persisted Ed25519 host key (host_key), chacha20-poly1305, and publickey (ssh-ed25519) login against /srv/sshd/authorized_keys (auth). A connection that has not logged in within LOGIN_GRACE_MS is dropped so one idle peer cannot hold the single slot.
