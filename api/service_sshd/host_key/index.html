The persisted Ed25519 host key.

The 32-byte seed lives at /srv/sshd/host_ed25519.seed on the CellosFS /srv volume. It is loaded when present and exactly 32 bytes; when absent (or the wrong size) a fresh seed is drawn from kernel entropy, written, and read back before use. Every failure — no entropy, no /srv, a write that does not persist, a VFS error that cannot be told apart from “absent” — stops sshd: serving a key that is constant, guessable, or gone after the next boot would teach clients to accept host key changes.
