Expand description

The submatches of a single-line match as (start, end) offsets into SinkMatch::bytes, following rg’s printer (record_matches / find_iter_at_in_context): the matcher runs over the input up to the end of the line (its terminator removed), starting at the line, so look-behind sees the preceding bytes; a match starting at or after the line end ends the iteration; and a final empty match at the end of the searched bytes is dropped. More than max submatches is SubmatchError::Limit.

Cellos adaptation: “the input” is taken from the start of the input, not from the start of the searcher’s buffer, so the result does not depend on where a buffer (or a resumed ResumableSearch segment) begins. A line at the start of a buffer that does not begin the input is searched behind its preceding line terminator (one line copy), so \A matches only at the start of the input; and the final empty match is dropped only when it lies at the end of the input searched so far measured from offset 0. Both equal upstream whenever the buffer starts at the start of the input (inputs within one buffer).
