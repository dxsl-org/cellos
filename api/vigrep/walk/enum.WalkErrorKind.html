§

Io(Error)

The tree reported an error.

§

Ignore(Error)

An ignore file could not be fully applied (malformed rule or non-UTF-8 line); its valid rules are in effect.

§

OtherKind

An entry of kind EntryKind::Other (DV7-5).

§

InvalidName

A listing returned a name that is not a single path component.

§

ListingChanged

The directory changed while it was listed.

§

FileModified

The file was modified while it was read (DV7-4).

§

DepthLimit

WalkLimits::max_depth exceeded; the directory was not entered.

§

EntryLimit

WalkLimits::max_entries exceeded; the walk ended.

§

DirEntryLimit

WalkLimits::max_dir_entries exceeded; the directory was skipped.

§

PendingNamesLimit

WalkLimits::max_pending_bytes or WalkLimits::max_pending_entries exceeded; the directory was skipped.

§

PathTooLong

WalkLimits::max_path_len exceeded.

§

IgnoreFileTooLarge

WalkLimits::max_ignore_file_bytes exceeded; the directory was skipped.

§

IgnoreRulesLimit

WalkLimits::max_ignore_rules_per_file exceeded; the directory was skipped.

§

IgnoreBytesLimit

WalkLimits::max_ignore_bytes_total or WalkLimits::max_ignore_rules_total exceeded; the directory was skipped.
