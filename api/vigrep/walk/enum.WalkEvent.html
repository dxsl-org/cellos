    File {

    },
    MountSkipped {

    },
    Error(WalkError),
    Cancelled,
}
Expand description

One step of a walk.

Variants§

§

File

A file admitted for search; pass path to Walker::search_file or Walker::begin_file.

Fields

§path: Vec<u8>

The canonical path of the file.

§explicit: bool

The file was a root operand (filters were not applied).

§

MountSkipped

A child of kind EntryKind::Mount was skipped (DV7-7).

Fields

§path: Vec<u8>

The path of the mount root.

§

Error(WalkError)

An entry failed; the walk continues unless it ended.

§

Cancelled

The cancel callback returned true. Every handle was released and the walk ended.
