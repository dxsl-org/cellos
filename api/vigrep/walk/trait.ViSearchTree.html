Expand description

A tree of directories and files the walker can search.

Paths are canonical byte paths: /-separated, no empty, . or .. components and no trailing / except for the root /. Every method enforces the implementation’s own authority checks; the walker never assumes access. Errors use io::ErrorKind; ViSearchTree::open_dir must return io::ErrorKind::NotADirectory when path names a file.
