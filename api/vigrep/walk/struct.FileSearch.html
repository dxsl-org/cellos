Struct FileSearch

pub struct FileSearch<F> { /* private fields */ }
Expand description

One file opened by Walker::begin_file, searched in segments by FileSearch::step.

The file handle is held from begin_file until step returns anything but Step::Paused, or until FileSearch::abandon. Closing needs the tree, so dropping a paused FileSearch without abandon leaks its handle. Every step must use the same walker, tree, searcher configuration and matcher; the resume rule is that of ResumableSearch over the tree file (rewindable, with a window of WalkLimits::resume_window_bytes).

pub fn step<T, M, S>( &mut self, walker: &mut Walker, tree: &mut T, searcher: &mut Searcher, matcher: M, sink: &mut S, cancel: &mut dyn FnMut() -> bool, ) -> Result<Step, SearchFileError<S::Error>>
where T: ViSearchTree<File = F>, M: Matcher, S: Sink,

Run one searcher segment, reporting rows to sink.

A sink returning Ok(false) from matched or context means “row accepted, pause now”: the step returns Step::Paused and keeps the handle; the next step resumes exactly after that row. The searcher’s binary detection is set from the walker’s BinaryMode on every step. On Step::Finished the file’s state is checked (a modification, or a NUL the preflight did not see, is WalkErrorKind::FileModified), the handle is released and WalkStats::files_scanned counts the file. On error the handle is released and WalkStats::errors counts it, except SearchFileError::Cancelled, which ends the walk. A step after the handle was released does nothing and returns Step::Finished.
