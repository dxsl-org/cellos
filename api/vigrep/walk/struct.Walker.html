pub fn search_file<T, M, S>( &mut self, tree: &mut T, path: &[u8], searcher: &mut Searcher, matcher: M, sink: S, cancel: &mut dyn FnMut() -> bool, ) -> Result<FileOutcome, SearchFileError<S::Error>>
where T: ViSearchTree, M: Matcher, S: Sink,

Search the file at path with searcher/matcher, reporting to sink.

This is Walker::begin_file followed by FileSearch::step until Step::Finished. A sink returning Ok(false) from matched or context pauses (it never stops), so the file is still searched to its end. In BinaryMode::Skip the file is first read completely; if it contains a NUL byte, Ok(FileOutcome::Binary) is returned and sink sees nothing. The searcher’s binary detection is set by this call. The file’s state is checked after the preflight and after the search; a modification is WalkErrorKind::FileModified (rows already given to sink by the search pass then belong to a failed file). The file handle is always released before returning.

pub fn begin_file<T: ViSearchTree>( &mut self, tree: &mut T, path: &[u8], cancel: &mut dyn FnMut() -> bool, ) -> Result<Begun<T::File>, SearchFileError<Infallible>>

Open the file at path for a segmented search.

In BinaryMode::Skip the file is first read completely; if it contains a NUL byte the handle is released and Begun::Binary is returned. The file’s state is then checked; a modification is WalkErrorKind::FileModified. On success the returned FileSearch holds the file handle until FileSearch::step returns anything but Step::Paused, or FileSearch::abandon is called. On error the handle is released.
