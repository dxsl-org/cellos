vigrep: ripgrep’s search components for Cellos, as no_std + alloc.

This crate is an adaptation of five crates from ripgrep 15.2.0 (commit e89fff89ac9af12e8d4ce9d5fd07beb408ca730f, MIT chosen from Unlicense OR MIT, copyright (c) 2015 Andrew Gallant) plus a serial walker written for Cellos. The std boundary of the upstream crates is replaced by io (a core-only reader) and by byte paths; nothing here touches a filesystem, the environment, threads or memory maps.

Dropped upstream code: searcher/src/searcher/mmap.rs, encoding/BOM transcoding and the path/file entry points of the searcher; globset’s serde support; ignore’s walk.rs, types.rs, default_types.rs, global and git-exclude discovery, repository detection and environment lookups. The per-file upstream SHA-256 values are listed in PROVENANCE.

§Host tests

The workspace pins a bare-metal default target, so run cargo test -p vigrep --target x86_64-unknown-linux-gnu.

Modules§

glob
The globset crate provides cross platform single glob and glob set matching.
ignore
The ignore crate provides a fast recursive directory iterator that respects various filters such as globs, file types and .gitignore files. The precise matching rules and precedence is explained in the documentation for WalkBuilder.
io
Core-only byte reader and error, used by the adapted searcher in place of std::io::Read and std::io::Error.
matcher
This crate provides an interface for regular expressions, with a focus on line oriented search. The purpose of this crate is to provide a low level matching interface that permits any kind of substring or regex implementation to power the search routines provided by the grep-searcher crate.
regex
An implementation of grep-matcher’s Matcher trait for Rust’s regex engine.
searcher
This crate provides an implementation of line oriented search, with optional support for multi-line search.
walk
A serial, depth-first walker over a ViSearchTree.
