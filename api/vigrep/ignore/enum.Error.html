Expand description

Represents an error that can occur when parsing a gitignore file.

vigrep: upstream’s walk-only WithDepth and Loop variants (and Error::depth) and the file-type UnrecognizedFileType and InvalidDefinition variants are not ported; walk errors are crate::walk::WalkError. Paths are bytes and I/O errors are crate::io::Error.

An error that occurs when trying to parse a glob.

Fields

§glob: Option<String>

The original glob that caused this error. This glob, when available, always corresponds to the glob provided by an end user. e.g., It is the glob as written in a .gitignore file.

(This glob may be distinct from the glob that is actually compiled, after accounting for gitignore semantics.)

§err: String

The underlying glob error as a string.

pub fn is_partial(&self) -> bool

Returns true if this is a partial error.

A partial error occurs when only some operations failed while others may have succeeded. For example, an ignore file may contain an invalid glob among otherwise valid globs.

Source

pub fn is_io(&self) -> bool

Returns true if this error is exclusively an I/O error.

Source

pub fn io_error(&self) -> Option<&Error>

Inspect the original crate::io::Error if there is one.

[None] is returned if the Error doesn’t correspond to an I/O error.

This method returns a borrowed value that is bound to the lifetime of the Error. To obtain an owned value, Error::into_io_error can be used instead.

Source

pub fn into_io_error(self) -> Option<Error>

Similar to Error::io_error except consumes self to convert to the original crate::io::Error if one exists.
