vigrep::ignore

Module gitignore 

Source
Expand description

The gitignore module provides a way to match globs from a gitignore file against file paths.

Note that this module implements the specification as described in the gitignore man page from scratch. That is, this module does not shell out to the git command line tool.

vigrep: paths are bytes and rules come from bytes supplied by the caller (GitignoreBuilder::add_bytes, GitignoreBuilder::add_line); nothing here opens a file, reads git configuration or consults the environment, so upstream’s Gitignore::new, Gitignore::global, build_global and gitconfig_excludes_path are not ported.
