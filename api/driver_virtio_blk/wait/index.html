Module wait 

Source
Expand description

Time budget for one polled request completion (every transport).

The budget is milliseconds on the kernel’s monotonic clock (GetTime), read only at the yield cadence; without a clock a poll count bounds the wait instead. Same scheme as the virtio-scsi and NVMe cells.
