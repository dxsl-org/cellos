Module io 

Source
Expand description

Polled, deadline-bounded request issue for every transport.

Interrupts are not routed to this cell, and the blocking virtio-drivers requests spin on the used ring without bound: a stalled device, a DMA fault or a device that raises DEVICE_NEEDS_RESET would hang the cell while it holds the state lock, and with it every VFS block request. Reads, writes and flushes are therefore submitted through the non-blocking API and awaited here under IO_BUDGET_MS, checking the device status before submission and at every yield point.

§Poisoning

A request that misses its deadline or meets DEVICE_NEEDS_RESET stays published: the device may still complete it later. The device is then poisoned — logged once, never touched again — and every later request is refused as NotIssued. The device only ever addresses bounce memory (hal_x86 slots, mmio grant pages), and a stalled request never reaches unshare, so that memory stays claimed and a late completion cannot write cell memory. No reset or recovery is attempted: a reset would race the abandoned request.

§Unsafe island

The non-blocking virtio-drivers calls are unsafe fns.
