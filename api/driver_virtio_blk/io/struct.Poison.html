Struct Poison 

Source 
pub(crate) struct Poison(bool);
Expand description

Poison latch: set by the first stall and never cleared. While set, every request is refused before it reaches the queue, so it claims no bounce memory (the stalled request keeps its own, and repeated stalls would otherwise exhaust it).
