Phase 09B software provider crash/restore witness (CP1 option B, .agents/261030-1945-ginux-lessons-hardening/phase-09b-cp1.md).

Three Cells: recovery-authority owns the committed state, the writer epoch and the request-binding ledger and is the lifecycle parent of recovery-worker, which serves clients and commits every mutation at the authority before replying; recovery-client drives the evidence scenarios. All state is RAM-only and survives a worker crash only.

Modules§

corrupt
Corrupt.kind injected at the authority (fault-inject builds only).
crash
Crash.mode scenarios executed by a fault-inject worker.
ledger
The demo provider’s state authority (CP1 option B): the committed counter, its revision, the writer epoch and the request-binding ledger, all in the authority Cell’s RAM. It survives a worker crash and nothing else: losing the authority loses the state, which is RecoveryFailed, never a cold start.
state
Status.state values reported by the authority.
wire
Fixed 64-byte frames exchanged by the recovery-demo client, worker and authority. Same-build, provider-private records (not kernel ABI): byte 0 is the tag, byte 1 the version (exactly 1), byte 2 a per-tag code, byte 3 is reserved zero, bytes 4..8 a little-endian u32, then seven u64 words. Decoding refuses a short buffer, another version, a non-zero reserved byte and an unknown tag before anything acts on the frame.
