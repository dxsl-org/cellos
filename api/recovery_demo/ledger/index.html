Module ledger 

Source
Expand description

The demo provider’s state authority (CP1 option B): the committed counter, its revision, the writer epoch and the request-binding ledger, all in the authority Cell’s RAM. It survives a worker crash and nothing else: losing the authority loses the state, which is RecoveryFailed, never a cold start.

Contract:

  • Only the bound writer (epoch, tid, cell, generation) may look up or commit.
  • A commit is atomic with its binding: state, revision and ledger entry change together or not at all, and only for the expected revision.
  • The ledger key is (caller cell, caller generation, request id). The same key with a different method, rights or payload is Conflict, never a replay.
  • fence ends the current writer and captures the final committed revision; a replacement attaches only if the stored state is intact and still at that watermark.
