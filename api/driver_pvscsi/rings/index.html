driver_pvscsi

Module rings 

Source
Expand description

Ring state, request and completion descriptor layouts and the DMA area map (pure; host-tested). The encoders and decoders are in proto.rs.

The #[repr(C)] mirrors follow FreeBSD’s pvscsi.h (pvscsi_rings_state, pvscsi_ring_req_desc, pvscsi_ring_cmp_desc, pvscsi_cmd_desc_setup_rings; BSD-2-Clause, see NOTICE). They only derive field offsets: every field is naturally aligned in the device layout, so repr(C) reproduces it, and the tests pin offsets and sizes.
