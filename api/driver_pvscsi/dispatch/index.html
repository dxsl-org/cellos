Source
Expand description

IPC request dispatcher — translates DrvRequest messages into SCSI I/O on the selected disk.

Wire format: types::block_wire, shared with the virtio-blk/NVMe/AHCI cells so VFS speaks one block protocol. The disk’s logical block is 512 bytes (checked at bring-up), so one wire sector is one LBA.
