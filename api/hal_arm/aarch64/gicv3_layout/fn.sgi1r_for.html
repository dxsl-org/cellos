Expand description

The ICC_SGI1R_EL1 value that raises SGI sgi on exactly the core with mpidr (GICv3 §12.2.13): Aff3/Aff2/Aff1 name its cluster and the target list holds one bit for its Aff0.

The target list covers 16 Aff0 values; Aff0 ≥ 16 is reached through the range selector, which exists only when ICC_CTLR_EL1.RSS says the CPU interface implements it (range_selector). Without it such a core cannot be addressed and the answer is None — never a bit for a different core.
