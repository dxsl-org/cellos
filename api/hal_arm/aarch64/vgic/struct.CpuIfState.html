Struct CpuIfState

pub struct CpuIfState { /* private fields */ }
Expand description

One vCPU’s virtual CPU interface state. It lives in GICH only while that vCPU runs: CpuIfState::load installs it before entry and CpuIfState::save takes it back after exit.

Source

pub unsafe fn load( &mut self, gich: usize, next_pending: impl FnMut() -> Option<u32>, ) -> usize

Install this vCPU’s interface state in the GICH window at gich, with LRs planned by plan_entry_lrs; every other implemented LR is cleared. Returns the number of LRs in use, which the matching CpuIfState::save needs.

Precondition: INTIDs from next_pending are ≤ 1019 (validated by the syscall layer, m3).

§Safety

Caller must be at EL2 with the GICH window at gich mapped and no vCPU running.

Source

pub unsafe fn save( &mut self, gich: usize, used: usize, is_level: impl Fn(u32) -> bool, repend: impl FnMut(u32), )

Take this vCPU’s interface state back from the GICH window at gich after exit and clear the used LRs; the LRs are sorted by sort_exit_lrs with is_level and repend.

§Safety

Caller must be at EL2 with the GICH window at gich mapped and no vCPU running; used is the value the matching load returned.
