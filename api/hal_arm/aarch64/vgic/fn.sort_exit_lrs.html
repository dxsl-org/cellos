Expand description

Sort the LRs read back after an exit.

Empty LRs (elrsr bit set) are skipped. Active and Pending+Active LRs are kept verbatim for the next entry, because the guest is still handling them. Pending-only LRs go back through repend, except for level-sensitive INTIDs (is_level): the caller re-samples those lines at entry, so a line the guest has since deasserted is not delivered again. For the same reason a kept Active level LR loses its Pending bit. Returns the kept Active LRs and their count.
