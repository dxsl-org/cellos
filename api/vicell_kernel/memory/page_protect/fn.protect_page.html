pub fn protect_page(vaddr: VAddr, new_flags: Flags) -> PagingResult<()>
Expand description

Rewrite the permission bits of one mapped 4 KiB page and invalidate its TLB entry.

new_flags REPLACES the old flags wholesale — it is not OR-ed in. Pass the complete desired set (including VALID / USER / ACCESSED / DIRTY), because a missing VALID bit unmaps the page rather than restricting it.

§Errors

  • PageTableError::InvalidAddress — vaddr is not currently mapped.
  • PageTableError::NotSupported — paging is inactive, or the target is a bare-physical arch (riscv32 / x86_32 / arm32) with no page tables.
