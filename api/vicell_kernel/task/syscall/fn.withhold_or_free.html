fn withhold_or_free(base: usize, pages: usize) -> bool
Expand description

Whether the reaper must withhold pages frames at base instead of freeing them, because an in-flight operation still holds part of the region.

A pin held by a task OTHER than the one dying counts: a driver cell may have authorised DMA against a buffer belonging to the cell now being reaped, and that driver — not the corpse — is the one whose acknowledgement must arrive. The frames are charged to the holder so its acknowledgement releases them.

Returns true when the frames must not be freed. A full quarantine also returns true: leaking the frames is the only safe answer left.
