Module local_service_lifecycle 

Source
Expand description

Local service-call lifecycle witness.

Both synchronous SDK calls and asynchronous calls use kernel-owned bounded operations. A provider that consumes a request and exits without replying must terminate either caller with PeerGone, not leave a masked Recv stranded. The same lane witnesses quota retention, real expiry and queued caller death.
