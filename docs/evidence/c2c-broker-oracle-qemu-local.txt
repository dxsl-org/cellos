Notes
-----
  * The bounded-queue refusal is the legacy oracle's own `busy_frame=0x7f01` on
    18 attempts with `queue_peak=16`, i.e. congestion is a refusal, not a drop
    (`indeterminate=0`, `stale=0`, `correlation=0`, `silent_drop=0`).
  * `restart status=PASS ... stale_send=INDETERMINATE` is the local half of the
    stale-binding contract: after the broker respawns with a new tid, a send to the
    old one is reported indeterminate, not silently retried.
  * `idle_ipc_wake` is honest about its own ceiling: one recordless return landed
    under `proof_ceiling_ticks`, one did not, so the verdict is
    `sub-ceiling-wake` on this host. A previous run of the same lane reported
    `quantum-spanning-idle-out` for the same sub-metric, which is why the lane
    asserts the drain/return bounds rather than a fixed verdict.
  * No remote route is involved: this is the local broker oracle only.
