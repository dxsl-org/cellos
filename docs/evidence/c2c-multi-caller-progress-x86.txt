Scope: new fixture-only witness, no production kernel/SDK/ABI changes. This proves owner quota isolation and exact completion correlation in one controlled two-caller window. It is NOT a general queue/scheduler fairness proof, sustained competing-producer benchmark, hostile monopolization test or SMP result.

Scenario:
- Coordinator B starts provider and child caller A using bounded raw control handshakes.
- A submits64 operations. Provider receives each and captures its explicit token before acknowledging. A reaches owner quota, overflow submit returns Busy, and all64 exact call handles still report Pending.

- A's second overflow is Busy even with64 terminal replies untaken. A takes each exact two-byte Reply sequence0..63 once; second take rejected for every retired token.
- B gets another fresh exact Reply sequence65 after A drain. Provider checks distinct B tokens and sender identity, and checks mailbox exclusion for both refused A requests. All raw control gates have500-tick watchdogs; reply waits use existing bounded helper.
