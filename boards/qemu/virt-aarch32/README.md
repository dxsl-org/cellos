# QEMU virt aarch32

This directory is a planning placeholder for future QEMU Arm 32-bit `-machine virt`
work only.

Current status:

- not implemented
- no `board.rs`
- no `BoardDescriptor`
- no `Architecture` or `SocId` variant
- no Cargo feature or build contract
- no CI lane
- no boot or runtime evidence
- not a supported Cellos board

Until 32-bit Arm bring-up exists, only `boards/qemu/virt-aarch64` is active.
