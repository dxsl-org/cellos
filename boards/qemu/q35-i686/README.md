# QEMU q35 i686

This directory is a planning placeholder for future `qemu-system-i386 -machine q35`
work only.

Current status:

- not implemented
- no `board.rs`
- no `BoardDescriptor`
- no Cargo feature or build contract
- no CI lane
- no BIOS or UEFI boot evidence
- not a supported Cellos board

Until 32-bit x86 bring-up exists, only `boards/qemu/q35-x86_64` is active.
