## Assumptions requiring runtime proof
- Multi-architecture QEMU runs prove CPU-facing semantics only; remote TLB and physical-board timing require exact hardware witness. A snapshot with live tasks cannot be deemed safe until capture, integrity, restore stack and device reinitialization are proved; otherwise return unavailable and make state explicit in docs. Multi-region allocator would impact snapshot format and framebuffer MMIO boundary, so reserve for a separately measured implementation step, not a silent side effect.
