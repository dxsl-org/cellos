## Blockers And Failures

### Fresh RV64 artifact build

`timeout 900 pwsh -NoProfile -File ./gen_disk.ps1` built and signed the updated `app-bench`, but
stopped when rebuilding the kernel. A direct rerun exposed the decisive error:

```text
error[E0308]: mismatched types
kernel/src/cell/hotswap.rs:471: expected &mut Vec<PendingMsg>, found &mut PendingMailbox
```

The disk script correctly refused to ship a stale kernel. This blocks the requested bounded
benchmark and OOM runtime probes. A clean A2/A3 runtime artifact cannot be built from the current
shared tree without reconciling this concurrent IPC mismatch; this test pass did not edit IPC
files.

### RV32 compile

`cargo check -p vicell-kernel --target riscv32imac-unknown-none-elf -Z build-std=core,alloc`
failed on existing target-portability defects:

- `kernel/src/task/tcb.rs:396`: uses `core::sync::atomic::AtomicU64`, unavailable on RV32 despite
  the crate's `portable-atomic` dependency.
- `kernel/src/task/syscall.rs:4045`: returns `u32` where `usize` is required.
- `kernel/src/task.rs:533`: passes a `u32` stack pointer where `usize` is required.

These failures are not introduced by A2/A3, but the four-target gate is not green.

### Host-only ostd and kernel cfg(test)

`cargo test -p ostd --lib` cannot run under the host harness because its no_std panic and
allocation handlers conflict with `std`. The focused decoder test exists at
`libs/ostd/src/syscall.rs:405`, but was not executed by a valid in-tree runner.

The allocator and syscall cfg(test) cases exist at `kernel/src/memory/frame.rs:375` and
`kernel/src/task/syscall.rs:4980`, but the bare-metal kernel has no host unit-test target. Their
production code compiled on RV64, AArch64, and x86_64; this is compile evidence, not executed
unit-test evidence.
