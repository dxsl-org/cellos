# New command contracts — Phase 01 candidate v1

**State:** proposed behavioral freeze for review, not CP1/CP2 approval, source implementation or executed acceptance. This is the normative new-command annex to [command-catalog.md](command-catalog.md). It refines the accepted [design](../../docs/cellbox-cli.md) and Phase [07](phase-07-ripgrep-search.md), [08](phase-08-compact-editor.md), [09](phase-09-ssh-client.md) without expanding their scope. [spec.md](spec.md) owns engine/serialization/session rules; [abi-vfs-telemetry.md](abi-vfs-telemetry.md) owns D03 save/trust semantics. [dependency-review.md](dependency-review.md) owns exact upstream pins, source/license boundaries and unqualified runtime dependencies. All behavior below is selected candidate behavior, not a claim about current code or upstream defaults.

## 1. Shared command admission

- Invocation is `/bin/cellbox COMMAND ...`; short names use the same registry. Options precede operands except SSH's explicit `--command` form described below. `--` ends option parsing; an operand starting `-` requires it. No argv reconstruction, shell evaluation or response files. Empty operands and NUL reject unless explicitly permitted below. The shared encoded argv limit remains 512 bytes, including command/option/operand terminators; smaller per-field limits also apply.
- Each command accepts sole `-h` or `--help`, returns 0 and performs no backend/session effect. No other undocumented option, abbreviation, combined short option, `--name=value`, implicit environment configuration, user config file or trailing operand is supported. Options taking values consume exactly the next argument. Repeating scalar options rejects; explicitly repeatable options are identified below. Validation/type/admission errors occur before file open, screen acquisition, network connection or credential release.
- `rg` is a finite Rows producer (or a Bytes-to-Rows transform for explicit stdin). `edit` and PTY SSH are Session commands, sole foreground stage with no data redirect/background. Non-PTY SSH is Bytes-to-Bytes with independent stderr. Session commands do not accept native records. No automatic JSON detection or byte-to-text coercion.
- Native schemas below use the types and typed JSON(L) encoding of spec.md, not a new transport codec. `schema` is the literal name below and `schema_version` is UInt(1). UInts retain exact width at machine boundaries. Path/Bytes never undergo replacement decoding. Diagnostics and completion are control/stderr, never successful rows. Terminal rendering may escape untrusted text; it never executes it as a local command or emits embedded data as trusted terminal control.
- All numeric limits are candidate safety/admission ceilings, not measured production capacity. Limit failures are explicit, never successful truncation. Base operation/session/entropy admission is not an additional grant of file, network, credential or trust authority. Numeric protected selectors, persistent codecs, storage placement, real providers and accountable owner approval remain their existing CP1 gates.

## 2. `rg`: bounded upstream-derived search

### 2.1 Exact argv and options

```text
cellbox rg [OPTIONS] PATTERN [PATH ...]
cellbox rg [OPTIONS] -e PATTERN [-e PATTERN ...] [PATH ...]
```

Without `-e`, exactly the first operand is the pattern. With `-e`, all operands are paths; positional pattern plus `-e` is not a second pattern grammar. No path means the explicitly granted cwd directory, never implicit stdin. Exactly one path `-` means stdin bytes and must be the only path; there is no stdin/path mixing. There are at most 16 path operands and 32 patterns, at most 4,096 aggregate UTF-8 pattern bytes. An empty pattern is valid and selects every eligible line, including an empty line. Empty input has no lines. File reads/traversal require R; explicit stdin requires none. Paths are resolved from explicit directory grants, never ambient cwd authority.

| Supported spelling | Exact effect |
|---|---|
| `-e PATTERN`, `--regexp PATTERN` | Repeatable, OR the patterns in argument order; report nonoverlapping leftmost-first matches using the pinned regex engine's alternative priority (not longest-match or earliest-end POSIX selection). At an equal start, pattern argument order breaks inter-pattern ties; within a pattern the engine's alternative priority applies. Duplicate ranges are emitted once. |
| `-F`, `--fixed-strings` | Treat every pattern literally; no regex metacharacters. |
| `-i`, `--ignore-case` | Unicode simple case folding in Unicode regex mode; fixed strings use the same selected matcher semantics. No smart-case inference. |
| `-w`, `--word-regexp` | Wrap each pattern in the pinned grep-regex word-boundary selection; incompatible with `-x`. |
| `-x`, `--line-regexp` | Select whole lines only; incompatible with `-w`. Line terminator is excluded. |
| `-n`, `--line-number` | Text rendering includes 1-based line numbers; this is already the default and never changes records. |
| `-q`, `--quiet` | Suppress all rows/text; still traverse/read all admitted input so later access/limit errors cannot be hidden by an early match. Incompatible with context options. |
| `-A N`, `--after-context N`; `-B N`, `--before-context N`; `-C N`, `--context N` | N is decimal 0..20. `-C` sets both sides and cannot coexist with `-A/-B`; otherwise each side occurs once. Overlapping windows emit each line once; a matching line is always Match, not Context. |
| `-g GLOB`, `--glob GLOB` | Repeatable at most 32, aggregate 4,096 bytes. Pinned ignore/globset syntax, leading `!` excludes; later matching command glob wins. Positive globs restrict eligible files and may override ignore/hidden filtering for matching entries, but cannot resurrect descendants of a pruned directory without an admitted ancestor traversal. No authority override. |
| `--hidden` | Include dot-prefixed entries except `.`/`..`; does not disable ignore rules. |
| `--no-ignore` | Disable all ignore-file rules; does not include hidden entries unless `--hidden` or explicit operand/positive glob admits them. |
| `-a` | Search NUL-containing files as bytes instead of binary exclusion; no decoding/transcoding. |
| `--encoding none` | Only accepted encoding value; explicit statement of the default: no BOM stripping, transcoding, encoding detection or invalid-byte replacement. |
| `--text` | Select deterministic human/plain-text final rendering instead of typed JSONL at nonterminal sinks; distinct from `-a`. Not an implicit byte decoding mode. |

`--text` above is the Cellbox renderer selector from spec.md, **not** upstream rg's alias for `-a`; `-a` alone controls binary eligibility. Help must call out this intentional spelling difference. All other upstream flags are unsupported, including `-u/-uu/-uuu`, `-L/--follow`, `-P/--pcre2`, `-U/--multiline`, `-z`, `--pre`, `--search-zip`, `--mmap`, `-j/--threads`, `--engine`, `--encoding` values other than `none`, `-f`, `--ignore-file`, `--type*`, `--json`, `-o`, replacement, count/list-only and sort flags. No decompressor, executable preprocessor, mmap, PCRE2, parallel walker or upstream printer is imported. Supported regex syntax/Unicode classes come from the pinned grep-regex/regex-automata adaptation; backreferences and look-around reject with status 2, never fall back to legacy grep. Default Unicode regex matching does not select invalid UTF-8 bytes; supported inline byte-mode groups `(?-u:...)` can match them, as can fixed byte sequences representable by UTF-8 argv. Anchors are per line; patterns matching LF reject as unsupported multiline search.

### 2.2 Traversal, ignore and bytes

The five matched ripgrep-15.1.0 component pins in dependency-review.md are the reference for regex, line searching, ignore and glob semantics. Only their pure admitted portions plus serial scoped VFS traversal are selected; no host filesystem/environment discovery is implied.

1. Process explicit roots in argv order; traverse directories depth-first with children sorted by exact component bytes. Deduplicate overlapping roots by VFS file object identity+generation within the operation; first admitted occurrence wins. No global filesystem snapshot is claimed. Explicit regular-file operands bypass hidden/ignore/glob exclusion, but never R checks or binary policy. Explicit directory roots are entered even when hidden/ignored; their descendants use normal filtering.
2. Discover only `.gitignore`, `.ignore`, `.rgignore` in each entered directory, from the explicit root downward (cwd is the implicit root). No ancestor-above-root, home/global git excludes, `.git/info/exclude`, repository detection or Git subprocess. Within one directory precedence is `.rgignore` over `.ignore` over `.gitignore`; deeper directory rules override ancestor rules; within a file last match wins. Command globs have highest precedence. Negation cannot revive descendants of a directory already pruned. Ignore files themselves are hidden entries unless explicitly admitted. Rule loading is UTF-8, pinned gitignore escaping/anchoring/directory semantics; malformed rule or denied rule-file read reports an error, not a silently ignored policy.
3. Hidden entries are excluded by default. Symlinks are **never followed**, including explicit operands: a discovered link is skipped with `links_skipped` accounting; explicit link operand returns UnsupportedSymlink/error2. No `--follow` exists. A backend unable to distinguish links or enforce same-mount traversal returns Unsupported rather than dereference. Mount transitions and directories outside the delegated scope are not followed; an encountered required inaccessible boundary is a partial traversal error, not a successful empty tree.
4. Binary means at least one NUL byte anywhere in a regular file. Default excludes the whole file from match/context output. To prevent late NUL from invalidating previously emitted rows, first scan the file with bounded scratch, then search the same version: provider must supply a stable version/read view or revalidate identity+content revision before emitting; changed versions fail that file. There is no unbounded deferred result collection or silent late-binary partial output. `-a` streams one pass, treats NUL as content and still detects version changes at final validation; already emitted rows then remain explicitly partial on error. Stdin has no rewind: require `-a` for `-` before consuming input.
5. Line separator is LF; bytes before it are the content (including any CR). Final unterminated bytes form a line; terminal LF does not invent an additional empty line. Absolute byte offsets count original bytes, including line terminators/BOM; no UTF-16/locale conversion. UTF-8 decode is optional metadata, never a condition for preserving bytes. Directory names unsupported by the admitted VFS path codec error; native Path ability is not permission to invent raw-byte VFS support.

### 2.3 Schema, bounds and completion

Each row is `schema="cellbox.search.line"`, with fields `schema_version:UInt`, `kind:String("match"|"context")`, `path:Path|Null` (Null for stdin), `line_number:UInt(u64,1-based)`, `absolute_offset:UInt(u64, first content byte)`, `line_bytes:Bytes` (no LF), `text:String|Null` (exact valid UTF-8 content or Null), `terminator:Bytes` (LF or empty), `submatches:List<Record{start:UInt,end:UInt}>`. Ranges are half-open byte offsets relative to `line_bytes`, ordered, nonoverlapping; Context has no submatches. Zero-width matches are allowed; after one at a position, advance by one UTF-8 scalar in Unicode mode or one byte in byte mode, and emit at most one at the terminal boundary. No display-column or character offsets masquerade as bytes. A matching line emits once, even if several patterns match. Completion summary is separate control: `files_scanned`, `files_binary_skipped`, `links_skipped`, `lines_scanned`, `matching_lines`, `matches`, `bytes_read` (includes preflight scans), `complete:Bool`, `reason:String|Null`; no summary row pollutes a Match pipeline.

Text renderer uses `ESCAPED_PATH:LINE:ESCAPED_LINE` for Match and `ESCAPED_PATH-LINE-ESCAPED_LINE` for Context, one LF per row, path `<stdin>` for stdin. Escape backslash as `\\`, LF/CR/tab/NUL as `\n/\r/\t/\0`; other controls, invalid UTF-8 bytes and literal `:`/`-` in path use `\xHH` per byte (uppercase hex). Printable valid UTF-8 is retained; no ANSI in nonterminal text. This is display text, not a machine-record parse contract. Native output/typed JSONL is authoritative for bytes/ranges.

Limits: read scratch 16 KiB; line content at most 65,536 bytes; at most 4,096 submatches per line; compiled regex storage at most 2 MiB; directory depth at most 64 below each root, 65,536 visited entries total and 65,536 bytes/1,024 rules per ignore file, 256 KiB retained ignore-rule bytes total. At most 64 KiB context-line bytes retained across before/after windows, checked before retention; requesting 20 lines does not authorize 20 oversized buffers. D02/native-edge budgets still apply; backpressure stops reads. File size and aggregate searched bytes have no 64 KiB cap; counters use checked u64 and quota/counter overflow errors. Exceeding any limit produces error2 and `complete=false`, never truncation-as-success.

Status: 0 at least one selected matching line and complete; 1 complete with none (including all-binary/empty); 2 any parse/regex/access/I/O/version/limit/partial traversal error even if matches were emitted; cancellation130, timeout124, session loss125. On operational per-file/entry errors continue other admitted roots/entries and retain error2; an unrecoverable operation/lease failure stops immediately. Expected downstream `take` close stops traversal/read and releases every handle without an error; completion is short-circuit, not a claim the tree was completely searched.

### 2.4 Required acceptance (not executed)

- Compare the selected flag/regex/glob/ignore behavior against pinned upstream fixtures with explicit equivalent settings; separately assert intentional Cellbox differences (`--text`, quiet error scanning, subtree-only ignore discovery, no-follow, stable binary preflight).
- Cover all supported spellings/invalid combinations, empty/Unicode/byte regex, literal argv, zero-width/multiple/overlap matches, byte ranges, CRLF/BOM/final LF, malformed UTF-8 and JSONL round trips. Unsupported flags reject before reads.
- Cover nested competing/negated rules, hidden explicit files, pruned parents, ignore-read denial, inaccessible mount, symlink cycle/explicit symlink, late NUL, changed-between-pass file and stable-version provider absence. No denied path leaks or fallback.
- Search a multi-chunk file larger than 64 KiB and an aggregate larger than 64 KiB without whole-file buffering; hit every resource limit and cancellation/consumer close while observing stopped producer work and released handles. Match plus later error must finish2, including `-q`.

## 3. `edit`: compact foreground text editor

### 3.1 Argv, bytes and session

```text
cellbox edit [PATH]
```

No options other than sole help. Zero operands opens an unnamed empty buffer; one operand opens an existing regular file or creates an unsaved candidate for an observed absent destination. No stdin, object/byte pipeline, alternate file list, read-only flag, plugins, subprocess, shell escape, IDE/LSP/build command or system clipboard bridge. Requires R+W+T, even before user elects to save; unavailable D03/session support fails truthfully, not a fake editor. Open/create/save-as paths are resolved solely under delegated directory grants; user-entered prompt paths at most 4,096 UTF-8 bytes with no NUL, subject to backend component limits.

One buffer, at most 4 MiB stored UTF-8 bytes, at most 262,144 logical lines, no NUL. Invalid UTF-8, binary NUL, nonregular/link/unsupported backend or oversized file refuses without editing/mutation. Preserve all existing LF versus CRLF terminators individually and the presence/absence of final newline. Lone CR is ordinary content rendered escaped, not silently normalized. Newline inserted by Enter is the nearest preceding line terminator, otherwise first existing terminator, otherwise LF; splitting/joining changes only the selected break. Empty new buffers have no final newline until entered. Tabs are literal tab bytes, displayed at SDK 8-column stops; no auto-indent, tab conversion, automatic trailing newline or whitespace trimming.

Cursor/selection boundaries are UTF-8 scalar boundaries, never inside a multibyte encoding. Left/Right move one scalar (including combining scalars), Up/Down preserve desired display column and choose the closest scalar boundary; combining zero-width and wide-cell continuation are rendered using the SDK width rules, never a cursor in a continuation cell. Home/End are logical line start/end excluding terminator; display wraps do not insert bytes. Page motion is one viewport height minus one line, minimum one. Resize only changes viewport/wrap/layout and retains buffer/cursor/selection/history. Unsupported control characters are escaped in the display, not sent as terminal escape data.

### 3.2 Complete key/action map

Printable text inserts at cursor, replacing selection; Enter inserts newline; Tab inserts tab. Backspace deletes previous scalar or selected range; Delete deletes next scalar or selected range; a line terminator is one deletion unit (CRLF stays paired). Arrow/Home/End/PageUp/PageDown navigate as above. No mouse requirement, modal editing or undocumented shortcut is implied.

| Key | Behavior |
|---|---|
| `Ctrl-S` | Save to current observed destination; unnamed buffer opens Save As prompt. |
| `Ctrl-O` | Save As path prompt; never open a second buffer or discard this one. |
| `Ctrl-Q` | Exit clean buffer immediately; dirty buffer opens Save / Discard / Cancel prompt. |
| `Ctrl-Z`, `Ctrl-Y` | Undo / redo one complete edit group. |
| `Ctrl-Space` | Toggle selection anchor at cursor; while active navigation extends the half-open range. Toggle off clears selection. |
| `Ctrl-C`, `Ctrl-X`, `Ctrl-V` | Copy selection / copy then delete selection / paste private session clipboard replacing selection. Empty selection is no-op; copy preserves selection; cut/paste clear it. Clipboard is local to editor operation, no OSC52/global clipboard. |
| `Ctrl-F` | Literal case-sensitive UTF-8 search prompt; Enter finds next from cursor, wraps once with explicit wrap indication; `Ctrl-N` repeats last nonempty query. No regex/replace-all. |
| `Ctrl-G` | Prompt for decimal 1-based logical line; 1..line_count only, invalid/out-of-range retains state and displays error. |
| `Ctrl-H` | Toggle visible shortcut help; Backspace is the distinct SDK Backspace event (serial DEL), not this control key. |
| `Escape` | Cancel prompt or clear selection; otherwise no-op, never discard dirty text. |

Prompt editing accepts printable UTF-8, Backspace, Enter, Escape; no command interpolation. Search query at most 1,024 bytes, save path at most 4,096 bytes. Save/Discard/Cancel confirmation accepts only `s/d/c` (case-insensitive) or Escape=Cancel, no default Enter acceptance. Existing Save As overwrite confirmation accepts only `y/n` (case-insensitive), Escape/Enter=no. Dirty-exit Save exits only after committed save; any failed/unknown save leaves editor foreground and dirty. SDK cancellation/session loss is not the dirty-exit UI: stop, retain no claim of saving, release guards and return130/125. Ctrl-C inside the editor means Copy, not the shell's cancellation shortcut; explicit SDK cancel remains available.

Bracketed paste is one edit group with literal text; reject entire event on invalid UTF-8/NUL, more than 256 KiB, buffer/line limit or clipboard cap breach. Clipboard at most 256 KiB. Each ordinary insert/delete key event, cut, paste and newline is one undo group; navigation/copy/search/resize are not. No timing-based grouping. Undo stores bounded inverse edit ranges, not a whole-document copy per key. At most 1,024 groups AND 1 MiB retained old/new UTF-8 payload across undo+redo; evict oldest complete groups until both fit. A new edit after undo drops redo. All accepted groups must fit individually (paste cap already below budget); otherwise refuse before mutation. Undo restores bytes/cursor/selection; it never rolls back an already committed file. Dirty means current bytes differ from last successfully committed bytes, or an unsaved named/unnamed candidate has nonempty content; an absent named empty file remains unsaved/dirty until creation or explicit discard. Comparison must be exact (digest alone cannot establish equality). Undo to saved bytes becomes clean even after history eviction; redo away becomes dirty. Empty unnamed initial buffer is clean.

### 3.3 Highlighting and save

Highlight only filename suffixes `.toml`, `.sh`, `.rs`, case-sensitive; every other path/unnamed buffer is plain text. This is lexical highlighting, not parse validation or file execution. TOML: `#` comments, single/double quoted strings and decimal numbers; shell: unquoted `#` comments and single/double quoted strings, no expansion evaluation; Rust: `//` and nonnested `/*...*/` comments, quoted string/character tokens, decimal numbers and the fixed keywords `fn let mut pub use mod struct enum impl trait if else match for while loop return const static`. Escapes only affect double-quoted/Rust string termination; line-state carries only Rust block comments and TOML triple-quoted strings. Unsupported grammar remains plain/default style; an incomplete token never prevents save. Highlighting performs no VFS include, shell sourcing or language-server call, changes no bytes/undo/dirty state and falls back to uncolored display on its own resource limit with a visible notice, never aborts editing. Scan at most 64 KiB/refresh and retain at most 256 KiB token/style cache; invalidate affected lexical state on edit and progressively recompute under that cap.

Open binds D03 present observation; absent target binds absent observation. Save uses exact UTF-8 buffer bytes and original observation, no stale mtime/exists check. Save As resolves/observes its destination, asks overwrite only for a present regular file and binds that answer to the exact observed binding+content revision. D03 stages, seals exact length/digest and conditionally publishes: create-if-still-absent or replace-if-exact-version. Even byte-identical concurrent writes/ABA invalidate observation. No silent retry with a fresh version after confirmation.

Conflict/denial/short write/interruption/proven precommit failure leaves committed original/destination bytes intact, buffer/cursor/selection/history retained and dirty. An indeterminate commit retains dirty state and uncertainty; query the same transaction only, never replay commit or mark clean from a lost reply. CommittedVisible may mark clean for the live namespace but visibly says durability unproven; CommittedDurable marks clean with provider's bounded guarantee, not an invented physical power-loss promise. Successful Save As switches current destination/observation only after acknowledged commit; failure retains old association. Dirty-exit after indeterminate outcome cannot claim successful save. No raw truncate/write fallback, backup overwrite trick or generic shell redirect stands in for D03.

Status 0 clean exit or deliberate discard; 2 invalid argv/type; 1 open/provider/storage/unsupported failure preventing entry; 130 explicit cancellation; 125 session loss; 124 operation timeout. Recoverable editing/save errors stay in editor and do not produce a successful save status. Save staging remains D03's 4 MiB/512-byte chunks and save-object/receipt quotas; session grids/queues remain D02 limits.

### 3.4 Required acceptance (not executed)

- Exercise every key/action through real serial and GUI SDK sessions, including selection over CRLF/multibyte/combining/wide/tab content, paste cancellation, search wrap, help, resize and raw/echo/alternate-screen restoration on normal exit, cancellation and reader death.
- Save/reopen UTF-8 mixed line endings, tabs, empty file and no-final-newline bytes exactly. Cover filename highlight selection and incomplete tokens without text changes or command execution. Unsupported files/flags/pipelines fail without mutation.
- Cover undo/redo grouping, branch discard, eviction at both limits, exact saved-byte dirty comparison and save/undo/redo interactions. At every rejected edit the entire buffer/history/selection remains unchanged.
- Inject original change, rename/ABA, denied save, short stage, failed seal/replacement, present Save As refusal, absent destination created after prompt and present destination mutated after confirmation. Observe old committed bytes and retained dirty candidate; test all D03 visible/durable/unknown outcomes and no automatic retry.

## 4. `ssh`: one outbound connection, one session channel

### 4.1 Exact argv, auth and boundary

```text
cellbox ssh --user USER --auth password [OPTIONS] HOST
cellbox ssh --user USER --auth publickey --identity KEY_ID [OPTIONS] HOST
cellbox ssh --user USER --auth publickey --identity KEY_ID [OPTIONS] HOST --command COMMAND
```

Password form also admits the same `HOST --command COMMAND` suffix. `--user` and `--auth` are mandatory, once each. Options before HOST only: `-p PORT` or `--port PORT` (decimal 1..65535, default22), `--connect-timeout SECONDS` (decimal1..300, default30), `--timeout SECONDS` (decimal1..86400, absent=no overall deadline), plus `--identity KEY_ID` only for publickey. `--command` is the single exceptional post-HOST marker: exactly one following nonempty UTF-8 argument, at most 4,096 bytes and subject to shared argv512; extra arguments reject. `--` before HOST permits a dash-leading operand syntactically, but host validation still applies. USER is 1..31 ASCII bytes `[A-Za-z0-9._-]`; no default local username. HOST is D03's exact ASCII DNS/IP identifier (IPv6 unbracketed, port separate), no `user@host`, URI, host aliases or IDNA inference. KEY_ID is 1..64 ASCII `[A-Za-z0-9_-]`, resolved only by an independently issued KMS credential ref, never a file path, private key bytes or authority token parsed from argv.

No `--command` means PTY shell Session; with `--command` means non-PTY byte execution. No `-t/-T` option or PTY exec mode, no implicit remote command built from remaining argv. COMMAND after local shell quoting is submitted **byte-for-byte as one SSH exec command string** to the remote server's interpreter; there is no remote argv protocol, auto-quoting/escaping, local evaluation or safety guarantee against remote shell metacharacters. For example `--command 'printf x; exit 7'` intentionally requests that remote string. It is not reconstructed from separate operands.

All other flags/modes reject, including `-i` raw identity-file reads, `-o`, OpenSSH config/import files, `-F`, `-J`, forwarding `-L/-R/-D`, agent/auth-agent forwarding, scp/sftp, jump/proxy commands, tunnels, X11, remote environment transfer, multiplexing, compression, accept-new/strict-host-key bypass and batch password via stdin/environment/argv. No listening socket, inbound sshd, automatic reconnect/replay, guest control or C2C authority.

Rights: N for exact granted destination+port, D only for DNS names, A for selected credential/auth operation, Vt for exact D03 host-trust lookup/decision; O/base timer/entropy admission; T for PTY or secret/first-trust prompt. Both A and Vt are independent and mandatory for either auth choice. Numeric host literals do not need D. Read-only preprovisioned Vt suffices only for KnownExact; unknown host requires additional scoped trust-create authority within Vt and D02 confirmation, never W or a KMS signing right. No generic R/W grants to key/trust storage.

Trust is evaluated before **any password release, public-key auth attempt/signature or auth-specific secret prompt**. Unknown host follows only D03's 60-second exact-key challenge, trusted foreground confirmation and durable conditional trust commit; no foreground session rejects unknown host. Mismatch always rejects, with no overwrite prompt or CLI replacement mode. Denied/unavailable/indeterminate/visible-only trust persistence rejects without authentication. Trust receipt binds current host+port+algorithm+complete key+connection challenge and cannot be replayed for another connection. Client argv/UI booleans cannot authorize trust.

Auth choice is exclusive, not fallback: password prompts once under D02 no-echo lease after trusted host verification; maximum1,024 UTF-8 bytes, Enter terminates, Escape cancels; no newline/NUL, empty password permitted, no history/log/scrollback/completion. Publickey uses one KMS-owned Ed25519 identity and session-bound SSH userauth signing, no private-key export to common cellbox. Encrypted OpenSSH Ed25519 parser/decryption is a **credential-owner import/unlock path**, not `ssh -i` or an ambient VFS read: at most64 KiB encoded identity, encrypted format `openssh-key-v1`, `bcrypt` rounds1..64 and salt16..64 bytes, supported AES-256-CTR only; unencrypted Ed25519 is also accepted inside owner custody. Other formats/KDFs/ciphers/keys reject before expensive work. Unlock asks at most once under the same secret-entry bound: the actual foreground client captures the secret under its separate no-echo lease and passes it only to the authenticated credential owner for bounded unlock; parsing/decryption/private-key custody remain inside that owner. Failed auth/unlock returns failure without switching methods or retries. No keyboard-interactive, agent, RSA/ECDSA, key generation, import command or secret persistence is added to the CLI. Actual KMS hook/parser/runtime integration remains its named owner prerequisite, not permission for cellbox to hold raw signing material.

### 4.2 Protocol, I/O, timeout and rekey

Select the dependency review's pinned synchronous IO-less Sunset core, defaults off, alloc/openssh-key and owner-contained parser boundary. Exact permitted wire negotiation: KEX `curve25519-sha256`, host/user key `ssh-ed25519`, cipher `chacha20-poly1305@openssh.com` both directions (integrated authentication), compression `none`; strict-KEX extension supported/required by the adapted profile. No `none` cipher, SHA1/DH-group fallback, alternate AES/HMAC or ML-KEM negotiation merely because upstream contains it. Unsupported peer negotiation fails255. Real admitted GetRandom-backed entropy is required before KEX; failure aborts, no deterministic/timestamp fallback. Endpoint server policy must support this intentionally narrow profile; alternatives require a new candidate review, not silent broadening.

PTY shell requests TERM=`cellos-vt1`, SDK initial rows/cols (explicit fallback80x24 with unknown-size provenance), no invented pixel geometry. Resize sends current admitted rows/cols with zero pixel dimensions; unsupported resize reports a control error, not invented success. Remote PTY stdout/extended bytes are one untrusted terminal-output stream, not native records; shell input/control belongs only to the effective foreground lease. EOF closes channel input once; local line-start `~.` disconnects (line start initially and after CR/LF), `~~` sends one literal tilde, every other `~X` forwards both bytes. Pending `~` flushes on EOF. Ctrl-C as input byte is forwarded to remote PTY; explicit SDK operation cancel terminates local connection. No escape opens a local shell or changes trust. Termination restores all local SDK guards/foreground ownership.

Non-PTY command passes stdin bytes unchanged, normal channel data to stdout bytes and SSH extended-data type1 to stderr bytes; unknown extended-data types fail protocol255 rather than merge. No terminal modes, escape parser, prompt bytes on stdout or UTF-8 decoding. Input EOF sends channel EOF exactly once without prematurely closing output; drain stdout and stderr through EOF/channel close, respecting independent backpressure. Closing local consumer cancels the session subtree; no unbounded discard/drain task or remote replay. Window credits advance only as corresponding bytes are consumed.

Connect timeout is one absolute monotonic budget from DNS/start through TCP, KEX and accepted host verification, excluding time exclusively spent in authorized human trust confirmation (which has its own60-second expiry). Auth/unlock has an absolute120-second phase budget, including prompts; channel-open/request budget30 seconds. Each KEX/rekey has30 seconds from first local/peer KEXINIT. Optional overall `--timeout` is absolute from invocation, includes all prompts and never pauses. No idle timeout or silent keepalive; backpressure alone is not failure before an applicable deadline. Cancellation130, session loss125 and timeout124 close stream/channel/resources, zeroize secret scratch and restore guards; timeout after remote dispatch carries unknown completion, never a replay instruction.

Production rekey triggers at the first of one hour since NEWKEYS, 1 GiB encrypted payload per direction or 2^30 packets per direction; checked counters reset only on completed NEWKEYS.
