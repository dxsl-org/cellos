## 2. Options

**S2-K (recommended first; no ABI/kernel/service change).** Secret/trust denial proof plus raw-read closure:
1. Remove the raw-kernel `Open/Read` fallback for `/etc` from cellbox builtins so every file read goes through VFS caller/path policy; keep `/bin` BootFS listing only if the catalog requires it (verify at entry; otherwise route through VFS too). `Open/Read` leave the cellbox ceiling only if no remaining caller needs them (ceiling diff then records a *reduction*).
2. Image denial checks: from the cellbox shell, read/list/write `/srv/cellos/**` → VFS refusal; key fixture (`cluster.key` feature on the private image only) → refusal; KMS IPC request from the shell → KMS `auth` refusal; no key bytes on any stream or UART.
Closure: `cells/tools/cellbox/src/{cmd_fs.rs,commands.rs,main.rs (only if the ceiling shrinks),ledger.rs}`, `scripts/qemu-phase03-pipeline-test.sh` (checks), `scripts/build-phase04-qemu-image.sh` (fixture feature, private only), docs. Effect: K row of criterion 3 met; others unchanged.

**S2-T-min (no ABI; profile attenuation).** Drop `GetProcs2`/`MemInfo` (and `GetProcs`) from the common cellbox ceiling; `ps/top/free` become refusals in the shell and stay available through a **retained telemetry worker** on its own reviewed launch edge (same pattern as S2-lite for kill/shutdown). Closure: `cells/tools/cellbox/src/{main.rs,commands.rs,top.rs,cmd_sys.rs,ledger.rs}`, a worker binary in `cells/tools/sys-tools`, one reviewed row in `kernel/src/loader/launch_profile/targets.rs` (launch-profile delta, no syscall/ABI change), runner checks. Cost: Phase 06 (Cell-centric top) still needs D04; the GUI/serial shell loses in-process `ps/top/free` until then. **Not recommended** if Phase 06 is next: it adds a worker that D04 replaces.

**S2-T (D04 typed scoped telemetry).** Kernel owner + `libs/api` record/paging + `libs/ostd` wrapper; shell gets own-Cell/granted-set rows; legacy global syscalls leave the cellbox ceiling. **Kernel + ABI change**; needs D04 allocation (selector/record layout) in its own annex before CP1. Overlaps Phase 06 — better admitted there.

**S2-N (net-service scoped grants).** Extend `NetRequest` with owner-issued operation refs for DNS, destination+port egress and listen/accept; `service-net` validates before `Resolve/TcpConnect/UdpBind/send/TcpListen`; launch edges for net-tools carry the grant. Closure: `libs/api/src/services/ipc.rs`, `cells/services/net/src/{service-runtime.rs,handlers/tcp.rs,handlers/udp.rs,dns.rs,socket_table.rs}`, `cells/tools/net-tools/src/bin/{curl,wget,nc,httpd,mqtt}.rs`, issuer side (launch profile / caller), tests. **Service wire change; no kernel change** (attestation exists). Needs a numeric annex (variant discriminants, grant record, status codes) before implementation, same discipline as the Phase 02 annex. Grant issuer is an open design point: kernel launch edge vs. a broker Cell.

**S2-W (D03 scoped VFS mutation).** Replace ambient `VfsMutate` with VFS-issued destination observations and staged save (`ObserveDestination/BeginSave/WriteSave/SealSave/CommitSave`, conflict on absent→created / changed). **API + VFS + kernel attestation change**; also the basis of Phase 08 (editor save). Largest; needs its own annex and backend durability evidence (FAT/native replace-on-failure is not established, `abi-vfs-telemetry.md:7-17`).

Recommended order: **S2-K now** (cheap, closes K, removes a real policy bypass) → **S2-N** annex (closes network/DNS, service-only) → S2-T inside Phase 06 and S2-W inside Phase 08, where their consumers are built. Criterion 3 stays unchecked until N, T and W each have image denials.

## Results (2026-10-22, S2-K)
- **Entry finding (step 1 re-scoped).** Raw `Open/Read` resolves only against VIFS1 (`kernel/src/task.rs:2044-2072`): `/bin`, `/etc/cellos/{system,services,autoload}.toml` and private fixtures. VFS reads of `/` are read-all (boot-config protection is write-only, `cells/services/vfs/src/access.rs` `decide`). Removing the fallback would have broken those reads with no gain, so the user chose "step 2 + fail-closed": keep the fallback and gate it.
- **Real bypass reproduced before the fix** ([log](reports/s2k-baseline-before-fix.log)). With a private VIFS1 fixture at `/srv/cellos/p04-secret`, VFS refused the read but the BootFS fallback served it anyway. `cat`, `head` and `sort` printed the token, `cp` copied it to `/tmp/p04-leak`, the token reached the UART, and every one of those commands reported `$?=0`.
- **Fix.** `cmd_fs::bootfs_fallback_allowed`: the raw route is used only when VFS permits the stat or answers "no such entry" (`IO`). A VFS refusal, or no VFS answer at all, never falls through. Applied at every raw reader: `cmd_fs::{read_file_bytes, read_path_bytes_exact}` (wc/head/tail/uniq/sort/awk/cp/cat/`from <`), `commands.rs` cat and `ls` fallbacks, `executor::read_path_bytes`, `text_tools/grep/io/read.rs`, and `applets/sys.rs` (non-default feature). Refusals now report status 1: `cp` (any failed copy), `ls` (cannot access) and the `echo >`/`>>` fast path, which previously left `$?` unchanged.
- **Not gated:** `exec`'s KERNEL-FS ELF load (`commands.rs:47-60`), which loads code and never shows bytes; the `sys_open_cap` app-manifest existence probes in `executor.rs`.
- **Verified.** Host `app-cellbox` 89/89. Private terminal runner exit 0: **327 checks / 68 driver markers**, including `secret-denied-0..8` (cat, grep, head, wc, sort, `from jsonl <`, cp, ls, `echo >` into `/srv/cellos` are all refused with nonzero status), `secret-no-copy`, `secret-never-shown`, `secret-token-not-on-uart` and the positive control `ramdisk-read-still-works`. Cellbox ceiling unchanged (G-S1a PASS; no `Open/Read` removal because the gated fallback still needs them).
- **Not exercised:** a KMS IPC request from the shell (no in-suite command issues one); the `/etc/cellos/cluster.key` RAMFS fixture. Under the current `/` read-all rule that fixture would be **readable by any caller through VFS**; that is a VFS policy finding outside this closure, recorded rather than fixed.
- Criterion 3: the K row is proven for the shell's read and copy paths. N, T and W remain open.
- Regression: Phase03 runner exit 0 (60 PASS), Phase02 runner exit 0. GUI 6x103 runner not rerun.
