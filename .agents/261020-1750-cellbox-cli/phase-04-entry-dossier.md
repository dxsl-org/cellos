## 1. Findings that bound Phase 04
1. **Shared ceiling = union of rights.** `cells/tools/cellbox/src/main.rs:20-53` declares the broad union (MemInfo, GetProcs*, raw Open/Read, VfsMutate, spawn/grant); `dispatch.rs:11-48` is argv-only. A restricted caller edge cannot attenuate in-process applets, so file mutation (VFS `VfsMutate` is an ambient task bit, `kernel/src/task/syscall.rs:2858-2862`), `kill` (ambient `SpawnCap`, `:5581-5647`), `shutdown` (raw syscall 502 with no gate, `:4133-4151,7821-7862`), network and telemetry **cannot join one ELF without widening every invocation** (plan step 3: keep them behind separate workers).
2. **The shell is already the safe union for its builtins.** Today's `/bin/shell` runs its builtins in-process under its own ceiling; renaming that same code to `cellbox sh` with the *same* ceiling widens nothing. Standalone `ps/kill/free/env/uname/date/shutdown/hotswap` and `net-tools` remain separate ELFs spawned through reviewed launch edges.
3. **Boot identity of `/bin/shell` is load-bearing in kernel policy**: `kernel/src/loader/boot_ceiling.rs:92-93`, `kernel/src/loader.rs:61-74`, `kernel/src/policy.rs:632-639`, `kernel/src/loader/early.rs:29-42`, init profile row `profiles.rs:13-53`, user/shell/desktop launch tables `targets.rs:7-109`, init autoload/service table (`cells/tools/init/src/{configuration,service_table}.rs`, `boot-config/autoload.toml:3-7`), selftests (`launch_profile/tests.rs`, `boot_ceiling/selftest.rs`, `elf_tests.rs:211-213`). These must change atomically (plan step 4: one reviewed set).
4. **GUI Terminal cannot attach to a real shell today.** Input `SessionV1` admits only Serial (`cells/services/input/src/session.rs:348-350`), and attach requires `frontend == attested controller` (`:381-392`). The only viable topology is Terminal-owns-session → `spawn_foreground("/bin/cellbox", ["sh"])` → shell `from_own_context`, which needs a **new D02 CP1 delta** (Gui frontend kind, normalized key submit, resize/output routing, liveness) plus a Terminal→cellbox launch edge (`targets.rs:51-57` gives `/bin/terminal` an empty child ceiling) and the Terminal SDK dependency.
5. **Signer/ISO quarantine blocks any cellbox fixture**: `scripts/cellos_sign/signing.py:88-100` refuses the names `cellbox/app-cellbox/terminal`; a private fixture needs a reviewed, narrowly scoped, feature-gated exception (exactly as Part B of A4 did for the filter), never a general lift.
6. **Callers beyond init/kernel**: workspace members (`Cargo.toml:88-91`), sys-tools/net-tools manifests, image/CI recipes (`scripts/build-*-ci.*`, `.github/workflows/ci.yml`, `tools/mkfat32.py` lists), GUI Files inventory (`cells/apps/files/src/main.rs:99-108`), desktop launcher dead paths (`apps.rs`, `main.rs:153-158,225-229,272-275`), Hypha spawn default `/bin/nc` (preserve as independent worker), Terminal fake matcher (`cells/apps/terminal/src/session.rs:16-130,132-159`). Not covered by the suite and therefore **retained outside it**: `httpd`, `mqtt`, `nc -l` workers.
