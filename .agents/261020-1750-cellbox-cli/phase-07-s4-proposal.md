# Phase 07 slice S7-4 — fixture-dependent `rg` runtime proof (CP1 proposal)

Status: **APPROVED (user, 2026-10-24): CP1 per every §4 recommendation (D77-1..6).** Implementation results: §5. Inputs already approved and not reopened here: D75-1 (the fixture generator is kept as a runner fixture), D75-2 (concurrent modification is evidenced by VFS host tests only), D75-3 (a file larger than cellbox's quota). S7-3 is implemented and CP2-approved ([proposal](phase-07-s3-proposal.md) §10). This proposal corrects the fixture location in [entry dossier](phase-07-entry-dossier.md) §9, which cannot run as written, and settles the design details §9 left open.

## 1. Facts

### 1.1 Why "private FAT `/data/rg/`" (§9) cannot work
- **`/data` is not FAT.** It is CellosFS on disk partition P4 (`cells/services/vfs/src/manager.rs:71-86`).
- **`/data/bin/*` is not a VFS tree.** The fixtures under `/data/bin/` (s2tw-probe, top-load) sit in the embedded VIFS1 `kernel_fs.img`, which the kernel loader serves. VFS `/data` does not see them.
- **No disk is attached.** None of the three runners (`qemu-phase0{2,3,4}-*-test.sh`) passes a `-drive`, so `/data`, `/srv` and `/mnt/sd` have no backing volume in those lanes.
- **CellosFS directories are too small.** A CellosFS directory holds at most 7 entries (entry dossier §14.3). Even a provisioned `/data` could never produce a directory larger than one listing page.

### 1.2 What does exist
- **FAT32 volume.** `/mnt/sd` is FAT32 at `PART_FAT32_BASE_LBA` = 2048 with 524,288 sectors (`libs/api/src/abi/disk.rs:20`). It is read through `FatBackend`, including `page_dir` paging (S7-2).
- **Formatting and population.** `tools/mkfat32_inplace.py` formats that volume. Host `mtools` (`mcopy`/`mmd`, `-i IMG@@OFFSET`) is installed and can populate it.
- **NVMe driver.** `/bin/nvme` (`driver-nvme`) is already built and packaged by the terminal runner (`qemu-phase04-terminal-test.sh:319-333`). It registers through the same block-driver surface that AHCI uses in `tests/integration/tests/ahci-x86.rs`, which mounts FAT32 `/mnt/sd` on x86.
- **Access rules** (`access/rules.rs`):
  - `/srv/cellos` is read-denied, both as an exact path and as a prefix; `/mnt/sd/` is readable.
  - Without a P5 volume, `/srv` itself is unbacked, so there is no backed directory whose listing contains a denied child.
- **Handle caps.** VFS allows 32 directory handles per Cell and 32 file handles per caller (S7-3 §1.5).

## 2. Design

### 2.1 Fixture: `scripts/phase07_rg_fixture.py` (D77-1)
- **Image.** The script writes a raw 300 MiB private disk image (sparse). It formats P1 with `mkfat32_inplace.py IMG 524288 2048` and populates `/rg` with `mmd`/`mcopy -i IMG@@1048576`.
- **Expectations.** It also writes `expected.json`. Each expected row is computed from the generated bytes: path, line number, absolute offset and submatch spans. A host run of `/tmp` reference `rg` 15.2.0 is recorded in the evidence only when that binary is present; it is never required.
- **Tree under `/mnt/sd/rg`:**

| Path | Purpose |
|---|---|
| `big.log` (17 MiB) | Larger than the 16 MiB default Cell quota and the 6 MiB cellbox arena. Three `NEEDLE-<n>` lines sit at known offsets: start, about 8 MiB, and last line without a final LF |
| `wide/f000.txt` … `wide/f299.txt` | 300 names of 12+ bytes, so the listing spans ≥ 2 pages. Each file has one `wide-hit` line |
| `ign/.ignore`, `ign/.gitignore`, `ign/sub/.rgignore`, plus `ign/keep.txt`, `ign/drop.txt`, `ign/sub/back.txt` | Competing ignore files: `.rgignore` > `.ignore` > `.gitignore`, and the deeper file wins |
| `.hid/h.txt`, `ign/.dot.txt` | Hidden directory and hidden file |
| `bin/late-nul.bin` | 40 KiB of text, then a NUL. Excluded by default; with `-a`, its text match is found |
| `enc/crlf.txt`, `enc/bom.txt`, `enc/nolf.txt`, `enc/bad-utf8.txt` | CR kept in the line bytes; BOM offset; empty terminator on the final line; `text` Null for invalid UTF-8 |

### 2.2 Runners
- **Disk attachment (D77-2).** The terminal and P03 runners attach the fixture as `-drive file=…,if=none,format=raw,id=rg -device nvme,drive=rg,serial=cellosrg`. This is a private copy in the work directory, never a user disk.
- **Readiness check.** The runner asserts the boot line `[vfs] FAT32 /mnt/sd volume mounted`. [INFERENCE: the NVMe registration reaches the FAT mount on this image; the first private run verifies it. If it does not, stop and report rather than switch to AHCI silently.]
- **Other lanes.** P02 and GUI attach no disk.
- **Terminal driver: new `rg-fx-*` markers.** Each one asserts structure and status, never wording.

| Marker | Command | Asserts |
|---|---|---|
| `rg-fx-big-exact` | `rg NEEDLE /mnt/sd/rg/big.log > /tmp/b.jsonl; from jsonl --typed < /tmp/b.jsonl \| select line_number absolute_offset submatches` | The three rows equal `expected.json`, status 0, and no `OOM:` on the UART. Elapsed time is recorded |
| `rg-fx-wide` | `rg -q wide-hit /mnt/sd/rg/wide; echo $?` and `rg wide-hit /mnt/sd/rg/wide \| take 400 > …` | Status 0, and exactly 300 distinct rows (every page listed) |
| `rg-fx-ignore` | `rg -e keep -e drop -e back /mnt/sd/rg/ign`, then the same with `--no-ignore` | The ignore precedence matches `expected.json` |
| `rg-fx-hidden` | `rg h /mnt/sd/rg` with and without `--hidden` | Hidden entries are absent by default and present with `--hidden` |
| `rg-fx-binary` | `rg text /mnt/sd/rg/bin; echo $?` → 1; `rg -a text /mnt/sd/rg/bin` → 0 | The late-NUL file is excluded without `-a` and searched with it |
| `rg-fx-enc` | Typed rows from `enc/` | CR in `line_bytes`, BOM offset, empty terminator, `text` Null |
| `rg-fx-denied-root` | `rg wide-hit /srv/cellos /mnt/sd/rg/wide \| take 1; echo $?` and `rg -q wide-hit /srv/cellos /mnt/sd/rg/wide; echo $?` | One `rg: /srv/cellos: …` diagnostic, the walk continues to the second root (a row is produced), and both statuses are 2 (D77-3) |
| `rg-fx-take-no-leak` | `rg wide-hit /mnt/sd/rg/wide \| take 1` repeated 40 times | Every run gives exactly 1 row and status 0. 40 > the 32-handle caps, so a leaked handle per run would fail by run 33 (D77-4) |

- **P03 (pipeline) markers.**
  - `rg … | where line_number == 1`;
  - the JSONL round trip over `big.log`;
  - `cat /mnt/sd/rg/enc/crlf.txt | rg -a x -`;
  - `rg | take 1` stopping early, timed against a full walk (recorded only).
- **P02 marker.** Ctrl-C during a long no-match walk gives 130 and the prompt returns. The walk is over `/` with `--hidden --no-ignore` and `-F` on a non-occurring 64-byte literal. P02 has no disk, so the walk covers RamFS, `/bin` and the config tree; it lasts long enough on TCG only if the latch has to fire mid-walk. The driver sends Ctrl-C 300 ms after the command. [INFERENCE: if that walk ends before the interrupt, D77-5 B attaches the fixture to P02 and walks `big.log` instead.]

### 2.3 Bounds and evidence ceiling
- TCG, one vCPU, FAT32 on NVMe. No symlink backend. No partial denial inside a backed directory (D77-3). Concurrent modification is covered by host tests only (D75-2).
- `big.log` at 4,000 B per `read_chunk` is about 4,350 IPC round trips. The time is recorded and no speed claim is made. The size can be cut to just above 16 MiB only if the runner budget forces it.

## 4. Decisions requested (recommendations first)
1. **D77-1 Fixture location.** *FAT32 `/mnt/sd/rg` on a private NVMe disk* (recommended: the only backed volume that pages and holds large files). Alternatives: provision CellosFS `/data`, which caps directories at 7 entries and so cannot test multi-page listings; or a RamFS tree built at run time, which cannot hold a file above the quota.
2. **D77-2 Disk lanes.** *Terminal and P03 only* (recommended). Alternative: all four lanes.
3. **D77-3 Denial proof.** *Denied explicit root (`/srv/cellos`) followed by a readable root: diagnostic, continuation, status 2*; record that partial denial inside a backed directory is not exercised because `/srv` has no volume here (recommended). Alternative: also provision a P5 CellosFS `/srv` holding a `cellos` child.
4. **D77-4 `take 1` handle proof.** *40 repeated runs past the 32-handle caps* (recommended: behavioral, needs no probe). Alternative: a VFS handle-table probe Cell (a new private fixture with a launch row).
5. **D77-5 P02 Ctrl-C.** *A no-disk walk of `/`, falling back to attaching the fixture if the walk is too short* (recommended). Alternative: always attach the fixture to P02.
6. **D77-6** Approve this S7-4 CP1 as written.

### 5.3 Deviations (for CP2)
1. **D77-7 (user, 2026-10-24): `big.log` is 7 MiB, not 17 MiB.** It is larger than the 6 MiB cellbox arena that cellbox actually allocates from, rather than the 16 MiB kernel quota (cellbox is charged 384 B there). This revises D75-3. Reason: about 28 KB/s on TCG made 17 MiB take 1,230 s.
2. **D77-5 fallback taken.** The no-disk walk of `/ /bin` finished before a 1 s Ctrl-C (status 1). P02 therefore attaches the fixture and interrupts `rg -F … big.log` after 3 s.
3. **The fixture carries the lane's `/etc/cellos`.** P1 is the config override volume, and without it init stopped with `configuration failure — /etc/cellos/services.toml: bounded VFS read failed: IO`.
4. **The fixture disk spans the whole partition layout (551 MiB, sparse).** A 300 MiB disk made the P4/P5/cell-store mounts read past the device (`[nvme] out-of-range request`).
5. **Fixture names contain no `-` or `:`.** The text renderer escapes those in paths (`\x2D`, `\x3A`), as the contract requires; escaping is covered by `rg-escape`. `wide/` holds 120 files with 43-character names (two pages) instead of 300, which keeps each full walk to about 20 s.
6. **Ignore precedence asserted.** The fixture asserts only `.ignore` over `.gitignore` and a deeper `.ignore` over its parent, both confirmed with host rg 14.1. Host rg 14.1 handled `.rgignore` inconsistently, and the pinned 15.2.0 binary is no longer present, so `.rgignore` precedence stays covered by vigrep host tests (S7-1 differential).
7. **`rg-fx-denied-root` checks status 2 without `| take 1`.** With `take` after it, the status is `take`'s (D76-8). The check uses plain and `-q` runs instead.
8. **The BOM offset is 9 (original bytes).** Upstream rg reports 6 because it strips the BOM. This is an intentional difference: vigrep does no transcoding (S7-1).

- **P03 kernel-test mode** (`PHASE03_KERNEL_TESTS=1`) always fails at evaluation because it never writes `pipeline-commands.json`. This predates S7-4 and is untouched; the kernel cases are taken from P02's kernel lane.
- **CP2 approved by the user on 2026-10-24**, including deviations §5.3 items 1–8. Phase 07 success criterion 2 stays open (links and partial denial; see §5.4).

### 5.5 Denied-child fixture (user request, 2026-10-24, after CP2)
- **What changed.**
  - `tools/cellos-fs-provision` gains `--seed DIR`, which is `fresh-blank` only. After formatting, it copies a host tree (directories and regular files in byte order; links and other kinds are refused) and syncs. The receipt records the seed.
  - A new provisioner test reads the seeded tree back after a read-only reopen: 5/5 pass.
  - `phase07_rg_fixture.py` provisions P5 `/srv` with `cellos/k.txt`, `pub/a.txt` and `zz.txt`. The VFS access rules read-deny `cellos`.
- **New checks.**
  - Driver marker `rg-fx-denied-child`: `rg SRVTOK /srv` gives exactly `/srv/pub/a.txt:1:SRVTOK a` and `/srv/zz.txt:1:SRVTOK z`, a diagnostic and status 2; `rg -q` also gives 2.
  - Runner check `rg-fixture-srv-cellosfs-mounted`.
- **Observed** (terminal serial log): `rg: /srv/cellos: permission denied`, then `rg: summary: files_scanned=2 … matching_lines=2`. The denied child sits between two readable entries in byte order, so the walk demonstrably continues past it.
- **Runs** (private TCG; the P5 volume now also mounts in P02 and P03):
  - terminal **449/449** (164 markers);
  - P03 67;
  - P02 48, with `rg` Ctrl-C 130;
  - the P02 kernel lane result is recorded in the phase deviation log.
  - Logs are in `reports/s7-4-evidence/denied-child/`.
- **Still open for criterion 2: links.** No VFS backend reports a link kind, so there is nothing to follow on target. The no-follow and cycle behaviour is proven only by vigrep host fakes. Closing it needs either a link-kind backend (out of Phase 07 scope) or an explicit decision to accept host-fake evidence.
