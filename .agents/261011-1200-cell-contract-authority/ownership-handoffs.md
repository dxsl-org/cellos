## Authority separation and evidence vocabulary

- **Observed source:** only the current inspected paths/symbols identified below and E1–E16 in the migration ledger. It establishes what was read, not an exhaustive caller graph, runtime correctness or production qualification.
- **Recorded history:** old plan/artifact results retain their source/profile/ceiling and approval scope. A completed legacy slice is an evidence input; it is not reset and is not rebadged as Spec 25 proof.
- **Target:** normative future contract and named owning phase. Proposed `cells/services/{budget-authority,placement-controller,workload-router}/` are target destinations, not source-confirmed running services.
- **Unknown:** missing exact ABI/layout/capacity, proof producer, source rebase, qualified time/root/hardware or approval. Unknown must not turn into a measured value, successful no-op or hidden fallback.

One Cell incarnation belongs to one node/kernel instance (physical or VM). A cluster contains separate nodes; remote replicas are separate Cells. A request/connection/thread is not implicitly a Cell. No DSM, cross-node thread migration, controller-global scheduler, consensus or timeout-based authority promotion is introduced. Main removed obsolete controller-ledger predecessor paragraphs from Spec 25 §7.1/7.2; the current canonical ownership is Authority-only enforcement, unchanged selected v1.3 semantics.

## Boot/VFS and control bootstrap cycles

### Observed boot surfaces (not new boot proof)

- `kernel/src/fs.rs:11-18,25-32,100-113`: embedded FAT BootFS `VIFS1`, file reader and mount initialize before service use. `kernel/src/loader.rs::spawn_trusted_init` delegates trusted init preparation; `spawn_gated` delegates governed ordinary admission.
- `cells/tools/init/src/service_table.rs::Service::bootstrap_vfs:21-35` fixes VFS as bootstrap prerequisite; `dependencies_available:45-50` checks live dependency availability. `spawn_path:56-78` attempts VFS grant-backed ELF spawn and then raw-path spawn; it republishes argv. This existing observed fallback is **not** target remote operation retry permission; P02/P07 must classify/migrate both local launch paths and preserve authority rather than delete the fallback from documentary inference.
- `cells/services/vfs/src/backend_bootfs.rs:1-13,55-103`: BootFS proxy retains an OpenCap cursor for reads and uses legacy Open/ReadDir/Close for directory lookup. Both cap and fd paths must enter the P07 caller census.
- `cells/tools/init/src/supervisor.rs::run/restart_pending:11-110`: checks independent liveness/attestation before classifying death, holds dependency-blocked restarts and consumes a pending attempt. These source checks are not proof of independent recovery authority for init itself.
- `cells/services/supervisor/src/hotswap.rs:113-116` still permits SnapshotTimeout then continues; old completed hotswap migration does not prove target state-required recovery. P06 owns exact authenticated transaction/cancel/clear/final-watermark remediation, not an isolated timeout symptom fix.

### Required acyclic target handoff

1. **P02:** platform/artifact validation → kernel root mechanisms/BootFS → trusted init with finite explicit grants → dependency-specific driver/service preparation. Bootstrap-only rights seal/revoke after handoff, preserving only named recovery grants. Kernel root is nontransferable.
2. **P05:** VFS becomes authoritative for service directory/file resources after its own preparation; bootstrap reads cannot depend on a service that is not yet ready. ELF bytes carry proved provenance and stay within scoped launch authority; privileged label does not promote caller-supplied bytes.
3. **P07:** retain a minimum native bootstrap reader or prove approved replacement before removing legacy fd implementation. Boot/VFS, direct kernel fd users, generated C bindings, mlibc/sysdeps and SDK consumers migrate together. Optional POSIX is not a reason to remove neutral native stream/TLS/futex enforcement or the pre-VFS filesystem mechanism.
4. **P06:** VFS/supervisor recovery reacquires new issuer resources and restores required committed state before ready publication. No live handle deserialization, unlabelled empty state, assumption that VFS can boot itself via its own unavailable IPC, or warm-kernel-snapshot prerequisite.
5. **P08-C:** application issuer precommits genesis/control vectors → one-use bootstrap grant → scoped supervisor/keyed kernel publication → independent Authority claims/reconciles original genesis → charged controller/router publication → Authority-reserved/live-destination-claimed workload children → issuer Ready → B routing. No Authority bootstrap through its own routed workload, fixture allowances or controller-created initial balance.
6. **P08/P10 failure:** uncertain bootstrap/create remains charged; same key reconciles publication/result. Node reboot says old incarnation Gone, not automatic replay-create. No timeout Authority promotion/home movement; unavailable recovery closes mutation/admission.

P01 must freeze exact parser/publisher/storage ownership, units/bounds/rejection/version and public/persistent approval revision for these handoffs before implementation. This document specifies relationships, not ledger bytes, queue sizes, CPU periods or measured capacity.
