## 6. Preserve neutral stream/TLS/futex mechanisms

`libs/api/src/abi/syscall.rs:192–219` declares PipeCreate/Read/Write/Close/Share; `libs/ostd/src/syscall.rs:364–445` exposes typed PipeHandle wrappers. `kernel/src/task/pipe.rs` owns bounded endpoint rings, `tcb.rs:248–250` task endpoint ownership, syscall.rs:4973–5128 copy/blocking handling and scheduler.rs:1665–1674 deadline wakes. These are **not** Unix fd table entries. Read zero/deadline versus EOF, partial writes/backpressure, writer close, target-thread sharing and retirement need explicit P05/P03 semantics and P07 mapping; no renumbering or silent return reinterpretation is approved here. C spawn witness relies on these native endpoints independent of POSIX process semantics.

Likewise P03 owns SetTlsBase/futex context and wait/wake; P07 may adapt errno/pthread objects locally but may not remove neutral primitives because mlibc uses them. Spec 26:65 explicitly accounts long-running streams as active load; extracting POSIX must not erase their budget/lifetime accounting.
