## Selected proposal and representation boundary

PROPOSED: the authorized application budget issuer is the **only genesis creator**. Before publishing any Authority/controller/router, it durably precommits exactly one logical application ledger identity, immutable maximum, assigned fixed Authority home/principal/fence and separate controller home/epoch, with exact charged control envelopes, measured artifacts, destinations and stable creation keys. Supervisor consumes a scoped one-use bootstrap grant; it never creates a new ledger or maximum. The control roles start independently of the managed workload.

The genesis semantic record must distinguish immutable ledger identity/maxima and per-role bootstrap key/vector/artifact/destination from mutable consumed/claimed/publication-result state. A bootstrap grant binds the exact issuer, application/ledger, Authority home/fence, role, destination, artifact/tier, key and complete vector. The Authority's initial own bootstrap consumption is rooted in the issuer precommit, not an impossible self-issued live reservation; **after** its own keyed publication/reconciliation it adopts that existing charge and enables ordinary C04 claims for controller/router. This is a genesis-only issuer path, not a reusable offline allowance for workload replicas.

PROPOSED representation: separate versioned durable genesis and consumption/result records. Exact encoding, key/fence widths, bootstrap issuer API, proof carrier, transaction/flush primitive and retention bounds remain blocker-bound. No backend, signer or reserved opcode is invented.

## State transitions, ordering and recovery

| Transition | Required ordering / refusal boundary |
|---|---|
| `NoGenesis -> Precommitted` | Issuer atomically establishes unique ledger identity plus maximum/control reservations and durability barrier **before** emitting any bootstrap grant. Failure/uncertain flush does not permit spawn or a second initialization. Query/reconcile the same issuer key. |
| `Precommitted -> BootstrapConsumed` | Assigned supervisor/destination checks authentic issuer, exact key/home/artifact/vector/role and independent local admission; serializes one-use consumption with keyed publication. A copied grant cannot publish at another node/key. |
| `BootstrapConsumed -> Published/PublicationUnknown` | Kernel keyed publication outcome refers to the same control incarnation. Lost reply retains precommitted charge; no new control key or uncharged replacement. Exact consume/publication cross-owner protocol requires I2. |
| `AuthorityPublished -> GenesisReconciling -> LedgerActive` | Authority recovers durable maximum/balance/fence and reconciles all bootstrap records against keyed kernel publication before ledger mutations/controller admission. Already-consumed same-key lookup returns original result, not another spend. |
| `LedgerActive -> Recovering -> LedgerActive` | Restart preserves logical ledger/maxima and all reserved/live/unknown charges; durably advances/reestablishes qualified monotonic enforcement fence before fresh grants. Controller remains mutation-closed until Authority recovery and its own intent reconciliation. |
| `Unknown -> Closed` | Only authentic authoritative absence/Gone, durable key closure and local quiescence permit the fixed-home Budget Authority's durable idempotent ReleaseOnce for the exact original debit and closure evidence. Genesis issuer settlement retains provenance but never credits/refunds the application allowance. Uncertain ReleaseOnce reconciles its original stable key; no replacement release key. Timeout, empty lookup, task restart or partition is insufficient. |

Home relocation, automatic promotion, second empty genesis and reinitialization on corrupt/unavailable storage are prohibited. Controller/router bootstrap is charged ordinary management work after genesis adoption; no managed-replica request is needed to start the authority that would admit it.

## Errors, outputs, lifetime and side effects

PROPOSED semantic outcomes: invalid/wrong-home grant, consumed key with changed binding, unauthorized issuer, local capacity rejection, incomplete genesis, stale fence and unavailable persistence refuse before new publication. A proven same-key completed result is returned idempotently without reminting. Uncertain precommit/consume/publication returns reconciliation-required with the stable original key and charge, not success/absence. Exact public errors/status/output bytes and short-buffer rules await CP1; rejected paths must publish no usable grant, and ambiguous output must never authorize another key.

Genesis/maxima/fence survive all control process restarts. Consumption/result/closed-key records cannot expire while delayed publication or replay remains possible. Artifact rollback cannot roll back ledger state or free unknown control Cells. Close mutation, recover the same ledger and retain charges; don't restart with an empty application allowance. Local quota deregistration is not global bootstrap release evidence.

## Units, bounds and charge owners

Control vectors use C02 counts/bytes/CPU entitlement; one bounded ledger, finite Authority/controller/router count, bootstrap keys, pending results and closure/history slots. All control envelopes debit the application before first spawn; storage and recovery metadata are part of those envelopes. Issuer owns immutable debit provenance and precommit custody until durable acceptance by the assigned fixed-home Budget Authority. Acceptance transfers sole effective custody even when issuer settlement/reply is lost; issuer retains nonspendable provenance/redirect only. Supervisor consumes; destination owns keyed local publication. The recovered fixed-home Budget Authority alone enforces balance and commits ReleaseOnce; issuer settlement is no-credit. P01/P03/P08 provide measured control and durable high-water/retention bounds; no numerical profile selected.

## Required negative scenarios

Crash before/after issuer precommit flush, grant emission, one-use consumption, kernel publish and reply; duplicate copied grant/wrong destination/artifact/key; supervisor reboot; Authority restart with previously live and unknown controls; unavailable/corrupt/rolled-back ledger; controller starts before genesis adoption; control shares omitted; second bootstrap maximum; stale home/fence and timeout promotion. Oracle: at most the original keyed control publication, unchanged logical allowance, all unknown charged, no controller mutation before recovery.
