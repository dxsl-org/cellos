## Selected proposal and representation boundary

PROPOSED route snapshot binds application/workload/C01 policy/schema/effect/affinity revision, controller epoch/revision/sequence, C08 challenge and C06 independently validated Ready members. Members have stable exact identities and **positive integer weights from admitted concurrency allocation**, never instantaneous load. Precompute normalized slot cycle outside hot path: stable identity order; gcd all weights; repeat each member by `weight/gcd`; reject zero/negative/missing/overflow/oversized member or cycle policy. A:2/B:1 is A,A,B, but this is an algorithm oracle, not a selected production limit.

Authority preallocates static ingress-generation/replica shares such that their sum fits the destination concurrency envelope; workload/node/application subshares remain within C02. No automatic borrowing, restart reset or per-request durable transaction. Router owns counters within its existing share; destination independently enforces final cap and live authority.

PROPOSED bounded FIFO stores authenticated original operations, canonical payload/retained input, original deadline and admitted subject/byte/slot reservation. Route/member/share/queue descriptors have separate versioned carriers. Exact stable-identity encoding, public fields/version, weights/concurrency/share profiles, error/output records and bounded FIFO representation remain blocker-bound; no V1 reinterpretation or request-path policy allocation.

## State transitions and exact selection algorithm

1. `Uninstalled -> Validating -> Installed(revision,cursor=0)`: validate C01/C06/C08, admitted share ownership/generations and checked normalized cycle size; build preallocated cycle/counters off hot path; atomically install complete snapshot. New revision resets cursor for new decisions only. Submitted targets do not change; same revision changed bytes rejects and repeated snapshot does not reset cursor/validity.
2. `RequestReceived -> Refused/Queued/Selecting`: authenticate original operation and scope, reserve finite queue bytes/slots/subject allowance. Linearize queue/selection ownership so no newer request overtakes an already queued eligible FIFO head. Expired/cancelled predispatch head is removed, not later executed. Ineligible affine work reports unavailable/unsatisfied, never selects another owner.
3. A decision inspects **at most one entire installed cycle**. Read slot at cursor, advance cursor after **every inspection**, wrap, then test Ready/live freshness, schema/subject/affinity, drain/suspect and local remaining share. Skip ineligible entries. Atomically reserve eligible local in-flight share; if that local reservation loses a race, continue only within remaining inspection count **before any target seal or submission**. No cluster scan, per-candidate allocation or controller hop.
4. `Selecting -> LocalShareHeld -> TargetSealed`: C07 origin issuer seals exactly one target from that decision. Seal failure releases only proven unsubmitted local share and returns refusal/uncertainty as appropriate; never reseals a different target for the same origin operation. No eligible slot after full cycle means bounded wait in already reserved FIFO if policy/deadline permits, else explicit overload/unavailable.
5. `TargetSealed -> Submitted -> Terminal/Unknown`: exactly one selected submit. Definite destination refusal returns to caller, **not another selection**. Accepted/ambiguous handoff, timeout/disconnect/cancel/reconnect is retained uncertain when required; no retry/hedge/fallback. Share/operation charge remains until authoritative completion/reconcile.
6. `ShareGenerationOld -> AdmissionFenced -> RetainedWorkReconciled -> ShareGenerationNew`: Authority owns reassignment only after old destination/router generation admission fence and all retained requests are settled. Router restart does not reset old counts, steal old share or automatically merge it. Route removal/C05 destination cutoff precedes drain; cache expiry is not Gone/release.

## Errors, outputs, lifetime and side effects

PROPOSED refusal classes: invalid route/Ready/share/schema/affinity, zero/oversized weights, queue/subject/byte/share exhaustion, deadline expiry, origin sealing failure and live destination refusal. Exact ABI codes/output bytes remain CP1 inputs. Refusal before dispatch produces no effect/target grant and preserves caller output; after dispatch preserve exact uncertain or terminal correlation, never mislabel NotSubmitted. A queue-exhausted caller cannot donate uncharged payload/work to a later cold replica.

Queue residence subtracts original request budget; route update/late Ready never extends deadline. Pre-dispatch queue reservation releases on proven removal; in-flight/unknown share and result storage only on authoritative terminal consume/reconcile. Long streams hold active share/state/resources. Same-incarnation captured provider reply remains legal; result consumption ownership stays P04 contract. No controller outage or missing telemetry is a share-reassignment grant.

## Units, bounds and charge owners

Finite member count, normalized weighted slots, affinity entries, queue operations/payload+metadata bytes, subjects, in-flight shares and original deadline bounds. Router preallocates cycle/tables/counters inside charged C02 envelope; Authority owns static share allowance and fence; destination enforces cap; origin owns attempt/result lifetime. Weights are concurrency ratios, not throughput claims. Actual numeric capacities/weight maximum/queue residence and checked arithmetic widths require [profile ledger](../profile-budgets.md#required-parameter-ledger); existing local 16/4/32 are baseline only.
