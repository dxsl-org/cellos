## Exact old representation — source-observed

### Manifest bytes

[CellManifest](../../../libs/api/src/abi/manifest.rs#L11-L64) is repr(C),16-byte v2, parsed field-by-field LE by [manifest_parse](../../../libs/api/src/abi/manifest_parse.rs#L13-L87):

| Byte range | Existing field/value | Validation/default |
|---|---|---|
| 0..4 | magic:u32 `0x56494345` | wrong magic rejects |
| 4 | version:u8 =2 | unsupported version rejects |
| 5 | tier:u8 / protection floor | class0 trusted-core,1 standard,2 FFI,3 untrusted,255 LEGACY; other values reject. This is **not runtime selection**. |
| 6..8 | flags:u16 LE | defined bits0..11: block,network,spawn,gpio,uart,hypervisor,part_data,part_lfs,can,adc,i2c,spi; unknown bits reject |
| 8..12 | cap_args_off:u32 LE =0 | reserved; nonzero rejects; no budget/runtime offset allocation |
| 12..16 | reserved:u32 LE =0 | nonzero rejects |

v1 is exactly8 bytes: magic0..4, version1 at4, flags:u8 at5, zero padding6..8; parser upcasts to v2 with tier255 and zero reserved words. Native v2 tier-less constructors also choose255. No unknown/trailing bytes accepted. [Constants](../../../libs/api/src/abi/manifest_flags.rs#L7-L81) are baseline, not new profile ceilings.

[declare_manifest!](../../../libs/api/src/abi/manifest_macro.rs) emits `VICELL_MANIFEST` into `__ViCell_manifest` with used retention. [kernel classifier](../../../kernel/src/loader/manifest_section.rs) distinguishes Absent/Valid/Malformed and rejects malformed/duplicate/NOBITS/size/version cases before task creation. [governed_spawn](../../../kernel/src/loader/governed_spawn.rs#L115-L173) derives requested/path capabilities and intersects root/spawner ceiling before policy; absent manifests use legacy path caps. Artifact signature/protection request does not itself mint rights.

### Allowlist bytes and loader behavior

[SyscallSet(pub u64)](../../../libs/api/src/abi/syscall.rs#L859-L949); EMPTY0, ALL=`u64::MAX`; macro emits one native u64 `VICELL_SYSCALLS` in `__ViCell_syscalls`, loader reads first8 bytes as LE. Bits0..62 already assigned syscall positions/classes; bit63 is `VfsMutate`, not spare. Always-permitted syscall entries can have no bit; multiple calls share bits, e.g. WaitForEvent217/WaitCompletion242 share42. This table is authority grouping, not a new syscall opcode space.

Current [section_u64](../../../kernel/src/loader/governed_spawn.rs#L14-L21) reads a first8-byte prefix and falls back to ALL when unreadable/absent; it does **not** enforce exactly8 bytes in that helper. Therefore do not report strict allowlist length rejection simply because manifest parsing is strict. [Zig manifest](../../../libs/zig-syscall/src/manifest.zig) intentionally publishes v1, not v2; [cell linker](../../../libs/cell-build/src/cell.ld.in) retains manifest/syscall sections via KEEP. Neither used nor KEEP proves final LTO/release ELF survival by source inspection.

## Proposed contract shape — design-proposed

1. Preserve the exact v1/v2 and allowlist representations/occupied bits while designing the replacement. Do not squeeze runtime selection, receive policy, budgets, cluster proofs or immutable ceilings into cap_args_off/reserved/tier or bit63.
2. Select a **separately versioned canonical admission metadata carrier** alongside the existing protection request, rather than silently overloading it. Exact ELF section/type/name/version and byte layout remain unselected. One authoritative admission record must bind the measured artifact, runtime declaration, immutable rights/resource maxima and receive/delegate ceilings. It must not become a second resource ACL/ledger; mutable current admitted limits live in enforcement state, not writable ELF bytes.
3. Immutable incarnation ceilings are installed atomically with authority/publication. Request/attestation/provenance narrows against spawner/issuer ceiling; signatures never automatically grant rights. Growth cannot exceed immutable maxima; beyond-max replacement is separately budgeted. Unknown/missing/malformed required metadata for a **selected new profile** refuses admission. Preserve old artifact semantics until an explicit clean release decision; do not silently change missing old allowlist ALL into EMPTY.
4. New profile metadata has explicit version/length/canonical endian, duplicate/unknown field, absent/default, overflow and unsupported-target rules shared by kernel and host tools. Proposed safe rule is exactly one supported record, reject ambiguity/unknown required policy before reservation or publication. This is a proposed **new-carrier** rule, not a claim about current permissive allowlist prefix parsing.
5. Syscall policy replacement, if required for D01–D10, uses a separately reviewed representation with explicit occupied-opcode mapping. Do not widen u64, reclaim a bit or grant old artifacts new operations by implication. CP1 decides whether existing allowlist remains an independent intersection or is removed in the clean release; no permanent alias/default adapter that recreates retired authority.
6. P08 policy/Ready/origin/lifecycle records remain distinct carrier owners. Artifact can declare permitted schema/export/policy references and immutable ceilings but cannot embed a live remote capability, manufacture authenticated Ready or supply an Authority live claim. D12/C01–C11 identify those missing trusted producers.

## Units, bounds and dependencies

New fields need counts/bytes and approved exact aggregate CPU unit; no inferred scaling of per-task64 operations/32 threads/16MiB into a profile. P02 reserves parsed/CSpace metadata; P03 threads/stacks/CPU; P04 operation/completion storage; P05 mappings/streams/resources; P08-C global immutable envelope/current shares. Finite record/set/section bytes and parse scratch limits must be selected from measurements and issuer policy. D01–D10 depend on approved carriers; D09 supplies provider/bootstrap closure; D12/C01/C02 supply policy scope rather than reserved-field shortcuts.

## Blocking inputs

1. **P01/P02 exact schema owner:** canonical separate-carrier proposal (record/section/version/field bytes, parse/error/absence rules) and allowlist continuation/removal decision. Evidence: old/new byte table and kernel/host acceptance corpus. Blocks exact new layout and checkpoint candidate; r1 selects separation, not Manifest v3.
2. **P03/P04/P05 measurement owners and authorized profile issuer:** immutable finite bounds, aggregate CPU unit/period/burst/overshoot, combined charge dimensions and supported subsets. Evidence: generation-complete footprint/charging data plus issuer-selected maxima. Blocks field widths/defaults and activation.
3. **P02/P07 artifact/provider owner:** all macro/custom linker/generated header/provider/archive/final ELF/sign/image inputs tied to exact target/profile artifacts. Evidence: candidate-specific closure tuple and actual winning providers; D09 mlibc pin gap remains. Blocks claiming publication/parse/profile closure or native-only.
4. **P08 authorized policy issuer:** application/workload/schema/child/receive/export policy identity and trust contract. Evidence: C01/C02 canonical records and issuer→destination consumers. Blocks policy reference/ceiling encoding; routing hash/manifest signature cannot supply this input.
5. **P01 governance/release owner:** exact stability/legacy-v1/v2/absent-allowlist admission and clean removal release decision, including external SDK consumers. Evidence: complete caller/test/doc/artifact migration and frozen-contract amendment. Blocks reinterpreting/removing old carriers; no permanent shims.
