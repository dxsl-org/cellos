## Selected proposal and representation boundary

PROPOSED versioned required-source set `G` contains exact owning ingress **generations**, policy/domain and retired-share fence/reconciliation status. Each admitted operation contributes **once at ingress** from eligible queue acceptance through terminal reconciliation: eligible queued plus in-flight counts, never again at worker. Affine/ineligible/noninterchangeable work reports unsatisfied/non-scalable separately, not useful pooled demand.

Each homogeneous scaling domain declares one interchangeable measured template/artifact/resource/concurrency class, positive target `T`, finite min/max, nonoverlapping window identity/duration, C08 challenge lifetime, consecutive up/down windows, cooldown, bounded step/replicas-per-window rates, pending create/intents and wake/queue caps. Heterogeneous weighted route pools may remain manual; automatic formula requires explicitly approved independent homogeneous domains whose budgets still fit the same application. Resize/class/template change removes a member from domain until approved reclassification; no implicit reinterpretation of T.

PROPOSED complete-demand formula `D = sum_g(eligible_queued_g + eligible_inflight_g)` from exactly one accepted C08 sample for **every required generation in one window**, checked before `desired_candidate = clamp(ceil(D/T), min, max)`. Use overflow-safe quotient/remainder ceiling, not unchecked D+T-1. Exact scalar widths/window timing/threshold values and canonical telemetry/source-set/domain/intent/wake bytes are blocked inputs, not guessed wire layout.

## State transitions, decision ordering and generation replacement

1. `PolicyUnadmitted -> DomainAdmitted`: validate C01 effect/interchangeability/class, all finite positive/ordered parameters, C02 effective allowance and always-on C03 Authority/controller/router capacity. Min-zero without real charged control/wake/queue path refuses.
2. `Observing -> CompleteWindow/Frozen`: controller opens C08 receiver-start round for exact G/policy/domain/window. Authenticate all expected generation samples produced after challenge; reject missing/stale/duplicate/wrong-generation/noneligible/mixed-window/reset counts. **Any incomplete or uncertain coverage freezes both scale-up and scale-down** at current desired state; reset consecutive decision evidence so gaps cannot count as complete adjacent windows. A fresh successor zero cannot replace old unresolved work.
3. `CompleteWindow -> Candidate`: sum D exactly once; compute formula; update consecutive up/down windows only for nonoverlapping complete windows under same domain/policy/G. Apply approved hysteresis, cooldown, per-step/window rate, finite pending/instance maximum and budget/local admission gates. Preparing+Ready count once for addition calculations; Draining/Unknown still consume budget/max-instance slots but are not usable Ready capacity.
4. `Candidate -> IntentRecorded`: reconcile prior unknown create/resize first. Controller durably records bounded decision identity linking policy/G/domain/window/desired count to stable reservation/create keys before dispatch; restart queries that intent, not new children from repeated sample. Persistence ordering and exact intent transaction are I2.
5. `Intent -> Reserve -> LiveClaim -> Preparing -> RestoredFencedReady -> Published`: C04 management path and C06 destination Ready; preparation timeout/lost reply remains unknown charged and cannot trigger unlimited replacement. Failed preparation never routes. A proven closed/absent old intent may permit a later bounded independent decision, never relocate an ambiguous key.
6. Downscale: select only safe non-affinity-violating members, remove future route, close destination admission/ack cutoff, drain admitted operations/grants/outcomes and writer state, prove Gone/key closure, then Authority release. Lower desired count is not kill/revoke permission; partitioned unsafe drains remain charged.
7. `G_old -> ReplacementPending -> G_new`: old generation remains required while any operation/share is unresolved. Obtain authoritative operation reconciliation **and** retired-generation destination admission/share fence, then atomically replace old with approved new generation exactly once and advance source-set version. New zero is accepted only under a fresh complete round for new G; no mixed old/new windows, double counting or erasure by restart. Storage pressure cannot drop old G.
8. `MinZero + AuthorizedColdQueue -> WakePending -> OneInitialIntent`: ingress emits bounded per-workload wake; controller coalesces same workload wakes into one keyed initial create, then ordinary loop/rate gates apply. Caller never directly spawns. Queue deadline expiry removes request; later Ready cannot execute/replay it. Wake replay/exhaustion cannot create duplicate children.
9. Controller restart recovers policy/intent state and Authority fence before mutations; Authority outage closes reserve/claim/resize/share changes. Existing routing additionally requires still-valid C08 membership and destination live authority; no offline budget lease.

## Errors, outputs, lifetime and side effects

PROPOSED explicit outcomes: frozen-telemetry/authority/reconciliation, unsatisfied-domain/budget/capacity/state/preparation, overload/wake-cap exhaustion, malformed/unauthorized sample/domain and stale policy/source-set. Missing data never yields D=0 or a mutation in either direction. Exact error/status/output bytes remain CP1 inputs. Invalid/incomplete telemetry changes no desired count, create intent, allowance or writer; bounded diagnostic state must not fabricate demand/success.

Intent/wake keys, old-generation counts, queued/in-flight ownership, terminal outcomes and share fence proof remain retained through authoritative reconciliation. Unknown preparations and drains keep charge. No telemetry TTL/down-window/cooldown releases work or promotes controller/Authority home. Binary rollback preserves durable intent/key/ledger rather than restoring old desired state with duplicate keys.

## Units, bounds and charge owners

Demand/replicas/T are integer operation/concurrency counts for one approved domain. Windows/lifetimes/cooldown use receiver-local monotonic units with checked arithmetic; exact values/widths unselected. Finite domains, G generations, samples/proof bytes, consecutive windows, pending/intents/wakes, queues/outcomes and reconciliation work consume C02 control/ingress envelopes. Ingress owns demand once; controller owns policy/durable decision; Authority alone owns allowance; destination/state issuer owns live effect/fence. [Profile budget ledger](../profile-budgets.md#required-parameter-ledger) and actual runtime measurements must choose bounds. P08-E's T=4/min=1/max=4 example is an illustrative future oracle, not production parameter selection.
