## Proposed change — design-proposed

1. Keep a kernel-owned bounded byte stream independent of Unix fd policy. Adopt D01/D03 shared-Cell typed handle validation for a read-end versus write-end, issuer/object/holder incarnation and local rights. Do not expose the current shifted ID as a new authority carrier. Exact slot/generation bytes come from D01; this package does not choose them independently.
2. Create reserves ring bytes, two handle slots and metadata before publication. Commit both endpoint installation and successful result publication as one admission transaction; rollback on output or holder failure releases all reservations. No successful half-created stream and no usable failure token.
3. New reviewed result semantics distinguish **Progress(n)**, **EOF**, **Deadline**, **BrokenPipe**, **Denied/stale/revoked**, **InvalidBuffer** and **CapacityRefused**. These are conceptual outcome names, not allocated discriminants. For a nonzero request, progress is exact copied byte count, `0 < n <= requested`; read EOF only after queued bytes drain and no live writer reference remains. No implicit retry by the SDK.
4. After normal handle/rights admission, a zero-length read/write succeeds as **Progress(0)** without accessing a data buffer or changing ring/refcount state; this is the only request for which Progress(0) is valid. Close is explicit. This deliberately removes write-empty-as-close, so every existing caller needs a migration row. The old return value/zero-write meaning stays intact until governed clean cutover, not an alias to the replacement.
5. Share/delegate binds target **Cell incarnation** through D02/D03 receive policy and immutable ceilings; same-Cell threads share authority, but an operation still owns its waiting thread. Copying an integer cannot install a reference. C spawn still performs explicit grant then token delivery, and still reports child-created grant failure separately.
6. Preserve finite capacity/backpressure and old locking invariant until an approved replacement lock protocol is supplied. Use checked ID/generation/refcount/deadline arithmetic; exhaustion refuses admission without reuse or endpoint-count mutation.
7. Close drops one reference; revoke cuts future admission and wakes/terminates denied waits, then quiesces active copies before reclamation. Already committed byte progress is reported, not rolled back or hidden by timeout. Whole-Cell retirement closes its references only after P03's cutoff/quiescence protocol; issuer charge persists while foreign live ends or copy pins retain storage.

**Unselected exact carrier:** syscall entry/signature, output record byte length/endian/version, tag/error integers, deadline unit conversion, typed target receipt, and ring/waiter/handle profile bounds. No changes to occupied 19/22/23/24/25, reserved fields or allowlist meanings are selected. Final old-artifact admission/removal decision must be part of CP1, not permanent compatibility shims.

## Units, bounds and charge owners

- Old 4096/64/65536 capacity and 512-byte copy chunk are observed bytes, not selected replacement budgets. Old timeout ticks are not CPU quota units.
- P05 charges physical ring bytes and object/waiter metadata once to the creating/admitted stream owner; P02 charges holder/lineage slots to each receiving Cell's approved vector; P04 charges any retained operation/completion. No double allowance from multiple threads or fd entries.
- Required finite dimensions: streams/ends, ring bytes, blocked waits, copy pins, handle/lineage metadata and retained outcomes. Revoke/unknown/quarantine remain charged until proven quiescent; D06 supplies buffer pin lifetime, D07 retirement integration, and the [profile ledger](../profile-budgets.md) supplies measurements/issuer-selected maxima.

## Blocking inputs

1. **P02/P03 local authority owner:** D01/D03 exact typed slot/generation/issuer/holder/receive and lock protocol. Evidence required: pinned representation and admission/close/revoke linearization table. Blocks stream token/share bytes, not the decision to retain native streams.
2. **P05/P04 syscall/output owner:** exact replacement result/signature and output-copy commit policy, deadline unit/conversion and overflow refusal. Evidence required: complete byte/error/output table and failure/race oracles. Blocks allocation of endpoint/result carriers and numeric errors.
3. **P05/P03 measurement owner and authorized profile issuer:** finite stream/end/wait/pin/metadata limits and charge/release attribution. Evidence required: complete generation-attested live/high-water/retained footprint, not ring capacity alone. Blocks capacity/slot defaults and activation.
4. **P07 binding/release owner:** pinned C/SDK/architecture word-width/generated/external consumer closure and explicit old-artifact retirement policy. Evidence required: actual headers, archive/provider and caller tuple tied to replacement artifacts. Blocks removal of old public paths; old opcodes remain reserved rather than reassigned.
