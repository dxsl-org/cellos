## Proposed decision and unresolved representation

**DESIGN-PROPOSED:** introduce an internal principal sum type `Kernel` versus `Cell { id:u64, generation:u64 }`; an internal thread diagnostic TID is separate. Kernel is a singleton minted only by kernel bootstrap context, never by payload parsing or by accepting `CellId(0)` through the old trailer. Cell generations are checked nonzero u64 with exhaustion returning admission failure before publication, rather than panic/reset. Kernel-root authority must itself have live typed bindings; a `Kernel` tag is not a universal bypass.

Retain the old trailer, binding and owner meanings until a reviewed clean version cutover; old zero rejection stays. Select the new standalone local principal bytes below rather than defer Kernel encoding. These proposal tags/version do not consume any frozen trailer field, opcode, magic or reserved word. Authenticated remote node/boot identity still requires a real P08 producer; boot-local generations and host labels cannot fill that external prerequisite.

Bound endpoint admission must atomically compare expected `(tid,Cell,generation)` against live target at submit; no registry lookup followed by unchecked TID send. Proposed TID-only constructor disposition: remove it from authority-bearing endpoint SDK and migrate callers to explicit bound lookup or a separately reviewed non-authority diagnostic route. Never reinterpret the old constructor as logical balancing. A pinned failed endpoint remains failed until explicit caller re-resolution; neither replacement service nor hidden retry receives accepted work.

## Selected r1 local records and error/output proposal

**DESIGN-PROPOSED, unapproved:** a separately selected new local receive contract writes a **40-byte LE** principal record: version:u32=1 at0; kind:u32 at4 (`Unknown=0, Kernel=1, Cell=2`); flags:u64 at8; Cell:u64 at16; generation:u64 at24; sender-TID:u64 at32. For Cell all three identity words are nonzero, flags only bit0 (VFS mutate) accepted. For Kernel identity words/flags must all0: the kind denotes the kernel singleton, never an ordinary Cell-zero. Unknown requires all fields except version0; it denies authorization. Unknown kind/version/noncanonical fields reject. These are proposal values only, not amendment of VICI32 bytes.

Producer choice: Kernel branch is emitted only from the explicit internal kernel-bootstrap principal context which owns the D03 Kernel authority object, not merely `current_cell_id == 0` allocation attribution or a user-supplied record. Cell branch comes from a live scheduler incarnation and actual sending task. Service parser relies on that trusted kernel publication path; a correctly shaped caller payload is never evidence.

Retain bound descriptor encoding exactly24 bytes `(tid,Cell,generation)` and owner response exactly32 bytes with reserved0 in their **existing** APIs. New full-binding submission consumes the complete descriptor in the D04 standalone submit record and validates it under the scheduler authority lock in the same transaction as queue/reservation publication. Cache liveness polling is advisory only. New Kernel record does not grant authority to old owner/binding APIs.

| Path/condition | Selected result and writes |
|---|---|
| New receive output shorter than40 or unwritable | Reject before dequeue/payload copy; no new identity publication |
| New receive starts with valid output | Clear version word0 before receiving/copying; snapshot kernel sender identity; write payload and full identity, publish version1 **last** on success |
| Receive fails after output validation | Version remains0, so stale/partial tail cannot parse as current attribution; payload may be partial, never authorized from it |
| New lookup absent/stale target | [D01 standalone header](D01.md#selected-r1-carrier-status-and-linearization-proposal) Stale2, no descriptor, required bytes32 |
| New lookup success | Success0 header + unchanged24-byte descriptor; required bytes56; snapshot and publication under scheduler lock |
| Header writable but descriptor output insufficient | Small7 header, required bytes56, no live descriptor or authority mutation |
| Noncanonical principal/input/unknown version | Invalid8 header where a control result is applicable; receive parser returns unknown/denial |
| Cell generation counter exhausted | Exhausted5, no owner/task publication or reset; prior incarnations unaffected |
| Provider binding changes before atomic submit | Stale2/no token/no queued work; no retry or retarget |

New control calls use D01 native pointer/length entry shape; legacy206/429 remain untouched until explicitly retired, not silently mapped to these new results. Watch/owner observation remains distinct from D07 scoped lifecycle power. Local principal bytes are selected; numerical **receive/control opcode assignments and release consent** remain gated. Remote principal record is intentionally not claimed complete without its authentic issuer.

## Lifetime, errors and output side effects

- Attestation derives from live scheduler identity and receive context. Missing/malformed/zero Cell/generation/TID in the **new** Cell branch refuses before service effects; payload identity never authenticates. This tightens the old parser and therefore requires review, not a claimed existing invariant.
- Keep output tail kernel-owned when requested; payload bounds account for the reserved tail. New receive invalidates version before copying and commits version last as selected above; failed receive never authenticates stale identity. No new policy rights derive merely from a flag.
- Bound lookup/owner lookup publish all-or-absent records, with short/invalid output rejected before descriptor writes according to the selected table. Cached binding grants no rights and expires immediately for admission when provider generation retires.
- Owner watch is cleanup attribution/observation, not close/revoke/quiescence or transferable lifecycle power. Preserve actual policy difference: VFS refuses stateful traffic when owner watch cannot be established; NET treats watch refusal as cleanup optimisation failure, not live-request denial. New enforcement must still use live owner checks.
- Watch cancellation and provider replacement must match exact generation/token. KMS/Silo maintain protected local binding checks and explicit rebind; node reboot cannot turn saved local integers into authority.

## Units, bounds and charge owners

IDs/generations/TIDs are dimensionless u64 counters; owner/watch/binding metadata measured in bytes, retained watches in counts. P02 owns live principal publication, P06 watch reservation/retention and release, P03 one-incarnation charge. Maximum watches, cache/retention tables and counter exhaustion policy need [profile basis](../profile-budgets.md); existing24/32-byte binding/owner records and proposed40-byte principal layout specify carrier size, not aggregate storage budgets. Remote freshness units and authenticated node/boot publisher are P08 obligations.

## Negative scenario obligations

Forged Kernel tag/Cell-zero, zero generation/TID, short tail and sender-padded forged trailer, same Cell slot/new generation, old watch cancellation, retired provider TID/binding race, lookup absent/invalid output, RV32 upper bits, cached provider replacement without retry/retarget, VFS versus NET watch refusal behavior, KMS/Silo subject mismatch and explicit rebind. Capture identity+operation before deferred/nested receives. Test source existence is not execution or protected proof.
